### 1. In-Context VLA: Endowing Vision-Language-Action Models with Language via In-Context Post-Training and Agentic Tool Use

- **作者**: Jiarui Yang, Wen Huang, Jiale Zhang, Maowei Hu, Hang Guo 等
- **机构**: 未知（论文未披露机构信息）
- **链接**: [arXiv](https://arxiv.org/abs/2608.05738) | [PDF](https://arxiv.org/pdf/2608.05738)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [[VLA-Talker]]

![](https://arxiv.org/html/2608.05738v1/x1.png)

- **核心方法**: In-Context VLA 把 in-context learning 搬进 VLA 的后训练阶段。输入端在原有图像+语言指令之外加入了"工具调用"接口——模型可以请求查询外部知识、历史轨迹或环境状态，然后再生成动作。训练分两阶段：先做 SFT 让模型学会调用工具接口（基于 [[CoT]] 推理）再用 [[GRPO]] 做 RL fine-tuning 强化语言推理。与只做 behavior cloning 的标准 VLA 相比，核心区别是显式的 in-context post-training loop，让模型有"想一想"再决策的空间，而不是强制端到端映射。
- **对比方法/Baselines**: 对比了 [[OpenVLA]]、TwinBrainVLA、JoyAI RA-0 等；测试平台覆盖 [[LIBERO]]、[[RoboCasa]]、SimplerEnv 和 AgiBot 真机。
- **借鉴意义**: 给 VLA 加 in-context reasoning 的后训练范式值得复用，特别是 long-horizon manipulation 和需要语义推理的场景。工具调用接口的设计思路可以直接参考。
- **锐评**: 方向是对的，VLA 一直缺少显式推理通道，这篇填了一个口子。但"in-context post-training"的本质还是在 SFT+RL 层面加 CoT，与 OpenVLA-OFT 那类工作的距离没有标题暗示的那么大。真机实验覆盖了 AgiBot 平台，还算有底气。最大疑问是工具调用接口在不同任务域的泛化性——测试台种类多但每个台的任务数量和难度细节值得看原文核实。👀
- **关联笔记**: [[VLA]] — in-context learning 方向在 VLA 上的落地

### 2. ω-0: A Latent Predictive World Action Model for Concurrent Humanoid Loco-Manipulation

- **作者**: Zhe Li, Zhenzhe Zhang, Yangyang Wei, Wenjie Zhang, Xichen Yuan, Peiyuan Zhi, Gen Li, Xinying Guo 等
- **机构**: PKU（shanghang 组），NTU（Jianfei Yang），HKUST(GZ)
- **链接**: [arXiv](https://arxiv.org/abs/2608.06375) | [PDF](https://arxiv.org/pdf/2608.06375)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [[Omega0]]

![](https://arxiv.org/html/2608.06375v1/x2.png)

- **核心方法**: ω-0 的核心问题是：humanoid 在家庭场景中同时需要走路、保持平衡、调整姿态、操作物体——现有方案要么切成两段（locomotion + manipulation 分开），要么用 VLA 但忽略全身协调。ω-0 提出统一的 latent predictive world action model（WAM），把全身运动和手臂操作的未来状态一起预测，再用预测的潜在状态条件化动作生成。架构借鉴 [[JEPA]] 的 latent 预测思路，用 [[DiT]] 做主干，[[RoPE]] 处理时序。关键设计：同时预测低频 locomotion token 和高频 manipulation token，避免两个时间尺度的冲突。
- **对比方法/Baselines**: 对比了 [[EgoVLA]]、[[SONIC]]、[[ACT]]、[[FAST]] 等；HOME 环境下有真机实验。
- **借鉴意义**: 这是目前少数认真处理 concurrent loco-manipulation 的 WAM 论文。做 humanoid whole-body control 的，multi-scale temporal token 设计和 WAM 框架值得深看。
- **锐评**: 把 loco-manipulation 统一进一个 latent predictive WAM 是真正有技术贡献的方向，不是简单拼接两个模型。has_real_world=True 说明做了真机，但分 task 的成功率细节要去原文确认。唯一存疑点：JEPA 风格的 latent 预测在 manipulation 精度上够不够——手部操作对 latent 的信息丢失更敏感。整体今天最值得看的一篇。🔥

💡 **想精读？** 运行：`读一下 ω-0: A Latent Predictive World Action Model for Concurrent Humanoid Loco-Manipulation`

### 3. DyPES-VLA: Learning Shared Dynamics Priors and Embodiment-Specific Control for Cross-Embodiment Manipulation

- **作者**: Junfeng Li, Junjie He, Zhide Zhong, Yangyang Zheng, Pingyue Sheng, Jiayu Dong, Ruixin Li, Haodong Yan 等
- **机构**: HKUST(GZ)
- **链接**: [arXiv](https://arxiv.org/abs/2608.06374) | [PDF](https://arxiv.org/pdf/2608.06374)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2608.06374v1/x1.png)

- **核心方法**: DyPES-VLA 针对跨机体 VLA 的老问题：如何让不同机器人共享视觉和动力学知识，同时保留各自的运动控制差异。方法分两层：Shared Dynamics Prior——用 [[MoE]] 结构在多机体数据上学习跨机体共通的物理规律；Embodiment-Specific Control——用 [[AdaLN]] 将机体特定信息注入 [[DiT]] 的动作解码器，每个机体有自己的归一化参数。与 [[OpenVLA]] 相比，DyPES-VLA 明确把共享部分和机体特定部分解耦。
- **对比方法/Baselines**: 在 [[RoboTwin]]、[[RoboCasa]]、[[LIBERO]] 上对比了 [[GR-1]]、[[OpenVLA]] 等；真机测试在 AgileX 上。借鉴了 EgoDex 数据。
- **借鉴意义**: 跨机体 VLA 训练是做 foundation model for robotics 的必要路径，shared prior + embodiment-specific decoder 架构可以直接参考。
- **锐评**: 技术路线清晰，MoE shared prior + AdaLN specific control 是合理的分解方式，跨机体实验覆盖了三个测试台加真机，规模够。弱点：MoE 的 expert 数量和路由机制从摘要看不到，这些设计细节对性能影响很大。跨机体混合训练容易出现"混合不如单机体专训"的尴尬，ablation 需要核实。👀

💡 **想精读？** 运行：`读一下 DyPES-VLA: Learning Shared Dynamics Priors and Embodiment-Specific Control for Cross-Embodiment Manipulation`

### 4. DFM-VLA: Iterative Action Refinement for Robot Manipulation via Discrete Flow Matching

- **作者**: Jiayi Chen, Wenxuan Song, Jiaxin Fang, Ruiqing Yin, Jingbo Wang, Shuai Chen, Jieyuan Pei, Yikai Qin 等
- **机构**: ShanghaiTech University、Tsinghua AIR、HKUST(GZ)
- **链接**: [arXiv](https://arxiv.org/abs/2603.26320) | [PDF](https://arxiv.org/pdf/2603.26320)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2603.26320v4/x1.png)

- **核心方法**: 现有 VLA 在 action decoding 上要么是 AR（慢，必须串行）要么是并行 mask diffusion（快但精度差）。DFM-VLA 用 Discrete Flow Matching（DFM）解决这个 trade-off：把 action token 的生成建模为从随机 token 到目标动作的流，允许多步迭代精化——每步全 attention 同时 refine 所有 action token，而不是 AR 逐 token 生成。关键是迭代次数可在 inference 时动态调整，精度和速度可以 trade-off。对比方法包括 [[FAST]]、EditFlow、[[UniVLA]] 等。测试台：[[LIBERO]]、[[CALVIN]] ABCD。有真机实验。
- **对比方法/Baselines**: 对比了 [[OpenVLA]]、[[UniVLA]]、FAST、MAAT、PD-VLA 等；借鉴了 CTMC 和 EditFlow 的理论框架。
- **借鉴意义**: 如果你用 token-based VLA 且对速度有要求，DFM 的 iterative refinement 框架值得认真看。比 DDPM 快，比纯 AR 准，步数还可以在推理时调节。
- **锐评**: 方向是解决 token-based VLA 速度与精度 trade-off 的正确姿势。Discrete Flow Matching 在 NLP 里已有理论基础，搬到 action token 上有一定新意。CALVIN ABCD 的成功率数字要和 Metric-Aligned 评估标准对齐，不然和之前的论文对比没意义。真机实验覆盖了，但任务难度从标题看不出来。👀

💡 **想精读？** 运行：`读一下 DFM-VLA: Iterative Action Refinement for Robot Manipulation via Discrete Flow Matching`

### 5. VLAff: Vision-Language-Affordance Model for Unified Actionable Affordances

- **作者**: Jihoon Oh
- **机构**: University of Tokyo
- **链接**: [arXiv](https://arxiv.org/abs/2608.05215) | [PDF](https://arxiv.org/pdf/2608.05215)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2608.05215v1/x1.png)

- **核心方法**: VLAff 的出发点是"人类视频是最大的机器人学习数据源，但 embodiment 差异让直接迁移困难"。解决方案：学 object-centric actionable affordance，这些 affordance 是 embodiment-agnostic 的——不管是人手还是机械臂，抓一个杯子的有效接触区域是类似的。用 VLM 解析语言指令，输出 affordance mask 和接触点预测，再由下游控制器执行。用到了 [[LISA]]、[[MANO]] 等基础模型做人手解析，[[EgoAffordance]]、[[VRB]] 作为 baseline 对比。
- **对比方法/Baselines**: 对比了 [[EgoAffordance]]、VRB、[[VidBot]]、UAD 等 affordance 学习方法；基于 EPIC-Kitchens 等数据集。有真机实验。
- **借鉴意义**: 做 human-to-robot transfer 的研究者可以参考这套 affordance 框架，但如果已有真机 action 数据，这条路的必要性下降。
- **锐评**: Affordance learning from human video 是个已经相当拥挤的赛道（VRB、EgoAffordance 都在做）。VLAff 把 vision-language 接口统一进来，但单作者 + 东大独立 + IROS 投稿来看，规模和数据量可能是局限。Zero-shot 部分的评估覆盖面要认真看，不能只靠漂亮的定性结果。💤

### 6. World-to-Wrist: Task-Conditioned Future Wrist Modeling for Fine-Grained Robot Manipulation

- **作者**: Pan Yuhao, Peng Haosong, Zhang Zhengshen, Yan Zhengyang, Dai Yalun, Huo Fushuo, Wang Chujie 等
- **机构**: HKUST、NUS、NTU、Southeast University
- **链接**: [arXiv](https://arxiv.org/abs/2608.05369) | [PDF](https://arxiv.org/pdf/2608.05369)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2608.05369v1/x1.png)

- **核心方法**: 标准 VLA 把 main-view 和 wrist-view 相机当成平等的视觉输入，忽略了它们角色的本质差异：主相机看全局，腕相机看接触细节。World-to-Wrist 在 VLA 里加了一个辅助预测头：在生成动作之前，先预测 task-conditioned 的腕部未来图像（[[JEPA]] 风格的 latent prediction），把预测的腕部状态注入 VLA 的动作解码器。训练是 multi-task：主 VLA loss + wrist future prediction loss。测试在 [[RoboTwin]]、[[LIBERO]] 和真机（StarVLA 平台）上。
- **对比方法/Baselines**: 对比了 [[OpenVLA]]、[[DreamVLA]]、StarVLA 等；真机任务覆盖 fine-grained 精细操作。
- **借鉴意义**: 做精细操作任务（小零件、精确接触）的研究者有参考价值。wrist-view 单独建模的思路比直接拼多视角更有针对性。
- **锐评**: 腕部未来状态确实是精细操作的信息瓶颈之一，直觉上合理。但"预测腕部未来图像然后注入动作解码器"这一链路的延迟和误差累积是潜在问题：wrist prediction 不准会直接伤害动作质量。HKUST + NUS + NTU 合作，资源有保障，从 section headers 看有 ablation，RoboTwin 上的数字要认真核。👀

### 7. Beyond Flat Policies: Hierarchical Post-Training for Embodied Agents in Robotic Manipulation

- **作者**: He Kong 等
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2608.05999) | [PDF](https://arxiv.org/pdf/2608.05999)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2608.05999v1/x1.png)

- **核心方法**: HiRoC（Hierarchical Robot Control）在 VLA post-training 阶段加入层级结构，区别于 flat policy（直接从观测到动作）。方法分两层：high-level planner 用 [[CoT]] 生成子任务分解；low-level controller 执行每个子任务的动作序列。Post-training 策略是 SFT + [[GRPO]] RL：high-level 部分用语言监督，low-level 部分用执行成功率反馈。对比 flat policy 的优势是 long-horizon 任务的分解能力更强。
- **对比方法/Baselines**: 对比了 [[OpenVLA]]、[[RoboBrain2]]、GRAPE、TGRPO、ActionX 等；SFT baseline 是 flat VLA；测试台 LIBERO，有 DexMimicGen 数据，有真机测试。
- **借鉴意义**: 对 long-horizon 操作任务有价值，特别是 5 步以上的复杂任务。层级 RL post-training 框架可以直接复用。
- **锐评**: 层级策略的思路不新，但在 VLA post-training 阶段统一做 SFT+GRPO 是有系统性的。疑点：LIBERO 本身的任务难度有没有复杂到需要 hierarchical planning——简单任务上层级结构是过度工程。机构信息缺失，实验规模需要去原文确认。👀

### 8. XEWorld: Can Action-Conditioned World Models Generalize to Unseen Robot Embodiments?

- **作者**: Chen Yixiang, Yang Jiabing, Xu Yuan, Ma Qisen, He Keji, Li Peiyan, Wang Kai, He Ziheng, Wu 等
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2608.05799) | [PDF](https://arxiv.org/pdf/2608.05799)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2608.05799v1/x1.png)

- **核心方法**: XEWorld 是一个测试台/基准，专门评估 action-conditioned world model 对未见机体的泛化性。协议是 LOEO（Leave-One-Embodiment-Out）——训练时遮住一个机体，测试时用这个机体评估。评估维度包括：像素重建质量（FVD 等）+ 物理合理性（PCK 关键点对齐）+ CoTracker3 轨迹追踪准确率。对比了 [[FlowWAM]]、EnerVerse、Ctrl-World 等现有 WAM。使用了 AgileX 机器人的真实数据。

- **借鉴意义**: 如果你做 cross-embodiment world model，这是第一个有系统性 LOEO 评估协议的工作，可以直接用作基准。
- **锐评**: 做基准论文有价值，跨机体 WM 评估标准确实混乱。但 has_real_world=False——全是仿真实验，LOEO 协议在真机上的有效性待确认。FVD+PCK 的指标组合能不能真实反映"是否学到了物理"是个哲学问题。💤 基准论文，需要时查

### 9. GeniWorld: A Generalizable Interactive World Model for Robotic Manipulation via Visual Actions

- **作者**: Chenghao Gu 等
- **机构**: Tsinghua（深圳）、Tencent Robotics X、HKUST
- **链接**: [arXiv](https://arxiv.org/abs/2608.06332) | [PDF](https://arxiv.org/pdf/2608.06332)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2608.06332v1/x1.png)

- **核心方法**: GeniWorld 的主张是：现有 action-conditioned WAM 在 OOD 场景泛化差，因为用的是 proprioceptive 或 delta-EE action（在新环境下不对齐）。解决方案：用 visual action 替代 low-level action——把机器人末端执行器的像素位移轨迹作为控制信号，embodiment-agnostic。用 [[ControlNet]] 结构把 visual action 注入视频扩散模型，训练时用 [[RoboTwin]] 和 RoboTwin2 的多场景数据。推理时，visual action 可以由更高层规划器提供。
- **对比方法/Baselines**: 对比了 Ctrl-World、EnerVerse、WorldArena 等；使用 RoboTwin 系列测试台；有真机实验。
- **借鉴意义**: Visual action 作为 embodiment-agnostic 控制信号的设计值得借鉴，特别是跨机体或 sim-to-real 场景。
- **锐评**: Visual action 的思路不是这篇首创（Ctrl-World 等已有类似设计），但 GeniWorld 在泛化性角度的系统阐述和 OOD 实验设计上有自己的贡献。弱点：visual action 依赖高质量的末端执行器轨迹标注，而这标注本身在 OOD 场景下也未必准确——潜在循环依赖。FVD 和策略成功率的相关性也被多篇论文质疑过。👀

💡 **想精读？** 运行：`读一下 GeniWorld: A Generalizable Interactive World Model for Robotic Manipulation via Visual Actions`

### 10. Robust-WAM: Bridging Generative Pretraining and Semantic Foresight in World-Action Models

- **作者**: Haodong Yan, Junfeng Li, Junjie He, Zhide Zhong, MingMing Yu, Wenxuan Song, Jiaguan Zhu, Yangyang Zheng 等
- **机构**: HKUST(GZ)、Beihang University、Huawei Foundation Model Department
- **链接**: [arXiv](https://arxiv.org/abs/2608.05903) | [PDF](https://arxiv.org/pdf/2608.05903)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2608.05903v1/x1.png)

- **核心方法**: 主流 WAM 把预训练视频生成模型（VGM）的 VAE latent space 直接用于动作预测，问题是 VAE latent 为图像重建优化，不一定保留了对控制重要的语义信息。Robust-WAM 加了一个 Semantic Foresight 头：在 VAE latent 之上额外预测高级语义特征（用 [[DINO]] 作为语义监督），让 WAM 的 latent 同时满足生成质量和语义辨别力。训练时 VAE loss + semantic distillation loss 联合优化。
- **对比方法/Baselines**: 对比了 FastWAM、[[LingBot]] 系列等；基础架构来自 [[DiT]]；在 [[LIBERO]]、[[RoboTwin]] 上测试；有真机实验。
- **借鉴意义**: VAE latent 不携带足够语义是 WAM 领域的共识痛点，用 DINO 蒸馏补语义的方法简单有效，可以作为 WAM 训练的辅助损失参考。
- **锐评**: 问题诊断准确，解法直接，用 DINO 蒸馏补语义有理论支撑。HKUST GZ + Beihang + Huawei 三家合作，资源充分。但和 FastWAM 的对比数字是否公平（超参对齐）需要核实，真机实验规模也要看原文。👀

💡 **想精读？** 运行：`读一下 Robust-WAM: Bridging Generative Pretraining and Semantic Foresight in World-Action Models`

### 11. LAWM-3D: Learning 3D-Aware Latent Actions from Human Videos for Generalizable Robot World Models

- **作者**: Yang Jiarui, Zhang Jiale, Li Jiawei, Guo Hang, Huang Wen, Wang Jinpeng, Liu Peidong, Xia Shihao 等
- **机构**: 未知（论文未披露机构信息）
- **链接**: [arXiv](https://arxiv.org/abs/2608.05706) | [PDF](https://arxiv.org/pdf/2608.05706)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [[LAWM-3D]]

![](https://arxiv.org/html/2608.05706v1/x1.png)

- **核心方法**: 从人类视频学 latent action model（LAM）是个有吸引力的方向，但现有 LAM 通常在 2D 像素空间学，泛化到新相机视角或新场景时脆弱。LAWM-3D 的核心贡献：用 [[VGGT]]（视觉几何通用 Transformer）先从视频帧重建 3D 点云，然后在 3D 空间里学习 latent action，用 [[Depth-Anything]] 补深度。3D latent action 在不同相机视角下是一致的——这是关键的 invariance 性质。下游：把 3D latent action 注入 [[DiT]] 视频生成模型做 action-conditioned world model rollout。
- **对比方法/Baselines**: 对比了 UniLACT、[[DreamDojo]]、CoMo 等 LAM 方法；对比世界模型 [[GigaWorld]]、WorldArena 等；测试在 [[LIBERO]]、EgoDex 上，有真机实验。
- **借鉴意义**: 把 3D 几何引入 LAM 的少数工作之一。做从人类 egocentric 视频学习机器人策略的研究者，LAWM-3D 的 3D-aware latent 是一个值得认真实现的 baseline。
- **锐评**: 方向新颖，3D latent action 的 camera-invariance 理论上能解决 2D LAM 的视角脆弱问题。弱点：VGGT 的 3D 重建质量在杂乱场景下不稳定，LAM-3D 的鲁棒性直接依赖于 3D 重建质量——论文里有没有评估 3D 重建失败时的 degradation 要看原文。但整体思路在今天的论文里算最有原创性的之一。🔥

💡 **想精读？** 运行：`读一下 LAWM-3D: Learning 3D-Aware Latent Actions from Human Videos for Generalizable Robot World Models`

### 12. JoyAI-RA 0.5: Scaling Robot Manipulation Learning via Dual Action Alignment

- **作者**: JoyAI-RA Team
- **机构**: Joy Future Academy, JD（京东）
- **链接**: [arXiv](https://arxiv.org/abs/2608.05674) | [PDF](https://arxiv.org/pdf/2608.05674)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2608.05674v1/x1.png)

- **核心方法**: JoyAI-RA 0.5 的出发点是"机器人数据稀缺，要用 human egocentric video + sim + real robot 三种数据混合训练，但这三者的 action 格式完全不兼容"。提出 Dual Action Alignment（DAC）：第一重对齐是 Latent-Action-Conditioned（LAC）——用 [[LAM]] 把 human video 映射到 latent action 空间；第二重对齐是用 [[VGGT]] 的 3D 表示做跨模态对齐，让 latent action 能和机器人 proprioception 对齐。使用了 EgoLive 数据集 + AgiBot 真机数据评估。
- **对比方法/Baselines**: 对比了 PnP-based VLA、基础 VLA 等；使用 AgiBot 平台真机评估。
- **借鉴意义**: 做 human-video + robot 混合训练的研究者，LAM + 3D 对齐的 DAC 框架值得参考。
- **锐评**: JD 的 JoyAI-RA 系列在系统性地做数据 scaling，这篇延续了这个路线。双重对齐框架工程量不小，但学术贡献清晰度不够——LAM + 3D 对齐分别不新，组合的增益要靠 ablation 来确认。"0.5 版本"命名暗示这是系列的过渡报告，不是里程碑。💤

### 13. SkillMemo: Expert-guided Skill Memory Framework for Compositional Embodied Manipulation

- **作者**: Wang Changyuan, Zhang Chubin, Wu Zhenyu, Li Runhao, Ma Angyuan, Chao Ke, Liang Yinan, Xu Xiu 等
- **机构**: Tsinghua（深圳）、NTU、Tsinghua 自动化系
- **链接**: [arXiv](https://arxiv.org/abs/2608.05970) | [PDF](https://arxiv.org/pdf/2608.05970)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2608.05970v1/x1.png)

- **核心方法**: SkillMemo 的问题是：组合操作任务（多步序列）时，[[Diffusion Policy]] 和 VLA 都因为轨迹数据稀缺而泛化差。解法：把专家演示分解为独立 skill 存入记忆库；推理时检索相关 skill，用 [[MoE]] 方式组合多个 skill 权重来生成动作。训练数据扩充：用 [[IMLE]]（隐式最大似然估计）生成多样化的 skill 轨迹。
- **对比方法/Baselines**: 对比了 MemoryVLA、UniAct、[[UniVLA]]、DP 等；LIBERO + 真机双平台测试。
- **借鉴意义**: 做组合操作（compositional）和 few-shot 泛化的研究者有参考价值，IMLE 数据增强是个有趣工具。
- **锐评**: Skill memory 的概念在机器人学里已经被翻来覆去做了很多年。IMLE 生成 skill 轨迹是这篇相对新的技术点，但整体 incremental 程度较高。LIBERO 测试台对于验证组合泛化是否够复杂也是个问题——LIBERO-Long 的任务序列长度有限。💤

### 14. Dream-MPC: Gradient-Based Model Predictive Control with Latent Imagination

- **作者**: Jonathan Spieler, Sven Behnke
- **机构**: 未知（Behnke 组通常在波恩大学）
- **链接**: [arXiv](https://arxiv.org/abs/2605.04568) | [PDF](https://arxiv.org/pdf/2605.04568)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.04568v3/x1.png)

- **核心方法**: Dream-MPC 把 latent imagination（[[DreamerV3]] 风格的 world model rollout）和 gradient-based MPC 结合：用 world model 在 latent 空间做 k 步预测，然后直接对这个 latent rollout 求梯度优化动作序列。与 [[BMPC]] 和 [[MPPI]] 等无梯度 MPC 方法的区别：利用可微世界模型的梯度信息加速搜索，比随机采样收敛快。测试台：HumanoidBench、[[Meta-World]]，有真机测试。
- **对比方法/Baselines**: 对比了 BMPC、MPPI、[[SAC]]、TD-MPC 等；基于 PlaNet 的 world model 架构。
- **借鉴意义**: 做 model-based RL 和 MPC 的研究者可以看，但与当前 VLA/WAM 主流方向有距离。
- **锐评**: DreamerV3 + gradient MPC 的合理组合，没有大的新意，也没有明显硬伤。latent imagination 的精度在长 horizon 下降很快，gradient MPC 对 world model 准确性要求比无梯度方法更高——这个 trade-off 的 ablation 在论文里有没有详细分析要看原文。整体 💤，RL 理论研究者可以看

### 15. GAUGE: A Measurement-Grounded Benchmark for Physical Fidelity in Simulation Engines and Video World Models

- **作者**: Wang Shuai, Feng Yaxin, Jiang Xuekun, Tian Shihan, Yan Ningyu, Shen Xing, Lyu Chaoyang 等
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2608.05948) | [PDF](https://arxiv.org/pdf/2608.05948)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2608.05948v1/x1.png)

- **核心方法**: GAUGE 是"物理保真度"基准，同时评估传统物理仿真引擎（[[IsaacSim]]）和视频世界模型。评估维度覆盖刚体、柔性体、流体等物理现象，用真实传感器数据作为 ground truth，计算 RMSE、DTW、QFI 等物理指标。目标是给出统一的量化数字：这个仿真器/世界模型在物理上有多准。
- **对比方法/Baselines**: 评估了 IsaacSim + 多个视频世界模型；VBD、PokeFlex 等柔性体基准作为参考。
- **借鉴意义**: 对做 sim-to-real 和评估 video world model 物理合理性的研究者有直接参考价值，这类基准工作不性感但有用。
- **锐评**: 有多少人真的需要一个专门的"物理保真度基准"？IsaacSim 的物理准确性学界基本有共识，视频 WM 的物理不准也是共识——GAUGE 的价值在于给出量化数字让比较成为可能。但如果只是确认了"物理引擎比视频 WM 更物理准确"这个结论，contribution 就有点尴尬。要看原文里有没有反直觉发现。💤
