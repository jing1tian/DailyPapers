## World Model

### 1. Masked Visual Actions for Unified World Modeling

- **作者**: Hadi Alzayer 等
- **机构**: Stanford University, University of Maryland, Harvard University
- **链接**: [arXiv](https://arxiv.org/abs/2607.19343) | [PDF](https://arxiv.org/pdf/2607.19343)
- **来源**: 🔥 HF Trending，⬆️ 4
- 📒 **笔记**: [[MaskedVisualActions]]

![](https://arxiv.org/html/2607.19343v1/x1.png)

- **核心方法**: MVA 把机器人动作编码为"掩码视觉补丁"而非低维 action token。具体做法：用 [[AprilTag]] 或 [[CoTracker3]] 追踪末端执行器位置，把末端执行器轨迹所经过的图像区域 mask 掉，让视频模型预测这些 masked patch——视频模型在生成过程中隐式学会了动作控制。逆向时（推理阶段），通过 inverse dynamics model 从被遮盖区域还原机器人运动。整套流程使动作完全在视觉空间内表达，消除了 action token 与 image token 的对齐鸿沟。在 [[DROID]] 和 [[RoboCasa]] 上均做了 real world 验证。
- **对比方法/Baselines**: 对比 [[ACT]]（低维 action token）、[[DreamGen]]（text-conditioned action）、[[SmolVLA]]（action tokenization），展示 MVA 在可控视频生成和动作精度上的优势。借鉴 [[DROID]] 数据集做大规模 real world 测试。
- **借鉴意义**: 对做 VLA 和 embodied world model 的人极其直接——这个方案解决了为什么 video-pretrained model 很难被用来做 robot action prediction 的核心问题：action 空间和 image 空间天然不对齐。Masked Visual Actions 是一个实现上干净、理论上成立的解法。
- **锐评**: Stanford+UMD+Harvard 三方合力，4 个 HF upvotes——这就是好论文没有流量的典型。方法的核心洞察是对的：用图像空间内的掩码来表示动作，比 action token 更自然地利用了视频模型的预训练知识。real world 上的 inverse dynamics model 能恢复有竞争力的行为这个结论值得认真对待。唯一值得挑剔的：mask 区域的定义依赖 AprilTag 或视觉追踪，在杂乱场景下准确率存疑；另外 inverse model 的精度上限尚不清楚。总体来说，这是 2026 年 VLA 方向少有的真正有新意的工作。🔥
- **关联笔记**: [[VLA]]（动作表示对比）、[[DROID]]（数据集）、[[DreamGen]]（基线对比）
- 💡 **想精读？** 运行：`读一下 Masked Visual Actions for Unified World Modeling`

### 3. DWM: Separating World Effects from Actions in Latent World Models

- **作者**: Zhang Yi-Ge, Du Tianqi, Zhang Qi, Wang Yisen
- **机构**: Peking University
- **链接**: [arXiv](https://arxiv.org/abs/2607.18715) | [PDF](https://arxiv.org/pdf/2607.18715)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [[DWM]]

![](https://arxiv.org/html/2607.18715v1/Figs/fig1.png)

- **核心方法**: DWM 的出发点是：现有 latent world model 在 transition 预测时只用一个 monolithic target，把"动作引起的变化"和"环境自身动态"混为一谈。DWM 在 latent 空间中显式分解两个分量：world effect（与 action 无关的环境动态）和 action effect（action 带来的增量）。训练时用两个解耦头分别预测，合并后作为 next latent 的监督信号。用 [[InfoNCE]] loss 强制两个分量不相关。规划时用 [[CEM]] 在只包含 action effect 的子空间中搜索，降低规划复杂度。在 [[PushT]] 和 [[DMC]] 的多个 OOD gravity 条件下验证了泛化性。
- **对比方法/Baselines**: 对比了 [[LeWM]]（latent 分离的一种先前尝试）、标准 DreamerV3 风格模型，以及 MPC+CEM 的 ablation。指出 [[LeWM]] 的分离依赖 causal masking 而非显式解耦，不够干净。
- **借鉴意义**: 对做 model-based RL 和 latent WM 的人：action effect 和 world effect 的分离是长期被忽视的问题，DWM 提供了有理论支撑的分解方式，且规划效率确实提高了。可以直接插到其他 WM 框架里。
- **锐评**: Peking 出品，理论部分扎实——diagnosing monolithic transition supervision 这一节写得很清晰，切中了当前 latent WM 的一个真实缺陷。实验选在 PushT 和 DMC（没有 real robot），评估范围偏窄，OOD 只测了重力扰动，对 object mass / friction 等其他 OOD 没有覆盖。但方法本身可以直接插到其他 WM 框架里，实用性有加分。🔥
- **关联笔记**: [[LeWM]]（基线对比）、[[MPC]]（规划方法）
- 💡 **想精读？** 运行：`读一下 DWM Separating World Effects from Actions`

### 4. WorldScape Policy 2.0: Empowering Steerable World Action Modeling with Reasoning-Augmented Memory

- **作者**: Su Haisheng, Liu Zongdai, Jin Xin 等
- **机构**: 未知（缺少机构信息）
- **链接**: [arXiv](https://arxiv.org/abs/2607.18840) | [PDF](https://arxiv.org/pdf/2607.18840)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.18840v1/x2.png)

- **核心方法**: WorldScape Policy 2.0 在 [[WAM]]（World Action Model）范式上，引入双层记忆系统：Short-Term Memory (STM) 存最近几帧视觉状态，Long-Term Memory (LTM) 存 event-level 文字摘要（每个操作阶段结束后自动生成）。规划时做 Latent Subgoal Reasoning (LSR)：基于 LTM 事件历史，用 VLM 生成中间子目标的 latent representation，再条件化到 [[DiT]] 结构的 action generator 上。Fine-grained prompts（ManipEvent）替换 episode-level 语言标注，提升语言-视觉-动作对齐精度。在 [[RoboTwin]] 2.0 上做了 component analysis。
- **对比方法/Baselines**: 消融了 STM、LTM、LSR 三个组件的贡献，对比了 [[LingBot]] 和 [[DreamZero]] 作为 WAM baseline。
- **借鉴意义**: 对做 long-horizon manipulation 的人：LTM 的 event-level 摘要是工程上可行的 long-context 方案，能把之前的步骤压缩到 token 预算里。
- **锐评**: 方向对，但机构信息缺失令人怀疑。ManipEvent 的生成质量有多可靠、LTM 的摘要会不会引入噪声——摘要没有提及。RoboTwin 2.0 是自家评测平台，外部泛化性未验证。消融结果显示 STM+LTM+LSR 缺哪个都掉分，但各自贡献量级没有清晰解释。中规中矩的工程改进。👀
- **关联笔记**: [[WAM]]、[[LingBot]]、[[RoboTwin]]（测试平台）
- 💡 **想精读？** 运行：`读一下 WorldScape Policy 2.0`

### 5. Generative World Renderer at the Speed of Play (AlayaRenderer-Flash)

- **作者**: Guixu Lin, Zheng-Hui Huang, Siqi Yang, Ming-Hsuan Yang, Kaipeng Zhang, Zhixiang Wang
- **机构**: University of California, Merced; Shanda Group
- **链接**: [arXiv](https://arxiv.org/abs/2607.18703) | [PDF](https://arxiv.org/pdf/2607.18703)
- **来源**: 🔥 HF Trending，⬆️ 64

![](https://arxiv.org/html/2607.18703v1/x1.png)

- **核心方法**: AlayaRenderer-Flash 是 G-buffer 条件化的生成渲染器，接收游戏引擎导出的结构化 G-buffer（深度、法线、实例 ID）和文字 prompt，输出光照真实的 RGB 帧。技术上做了三件事：(1) G-buffer-conditioned latent rendering（ControlNet 式条件注入）；(2) 自回归流式生成（chunk-by-chunk，保持时序一致性）；(3) Distribution-matching distillation，把 30 步压到 4 步，配合 distilled tiny codec 达到实时速度。在 SuperTuxKart 上做了定量评测。
- **对比方法/Baselines**: 在 AlayaRenderer 家族内做 ablation（Base → Flash → 不同步数）；对比外部 G-buffer 渲染 baseline [[DiffusionRenderer]]。
- **借鉴意义**: 对做 sim-to-real 的人：G-buffer 条件化 + 实时速度让游戏引擎直接作为 policy training 环境成为可能，不需要单独训练逼真度极高的 video WM。
- **锐评**: 64 个 HF upvotes 说明社区已经注意到了。实时速度让这个工作有实际工程价值，不只是 demo。但测试平台只有 SuperTuxKart 一个游戏，泛化到其他场景的 G-buffer 格式能不能 work 没有验证。Shanda + UC Merced 的工业背景明显，能 release 多少细节存疑。方法本身是对 AlayaRenderer 的工程优化，solid improvement 而非范式突破。👀
- **关联笔记**: [[DiT]]（架构基础）
- 💡 **想精读？** 运行：`读一下 Generative World Renderer at the Speed of Play`

### 6. Agentic Real2Sim: Physics-based World Modeling with Vision-Language Agents

- **作者**: Guanxiong Chen, Qianjun Xia, Jiawei Peng 等
- **机构**: National University of Singapore, Johns Hopkins University, University of California
- **链接**: [arXiv](https://arxiv.org/abs/2607.19190) | [PDF](https://arxiv.org/pdf/2607.19190)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.19190v2/figures/figs/compressed/droid_results.png)

- **核心方法**: 用 VLM agent 驱动自动化 real-to-sim 转换流水线，覆盖三个阶段：(1) 视觉重建——用 [[FoundationPose]] + [[SAM]] 从视频中提取物体姿态和几何；(2) 物理参数推断——VLM 根据材质外观猜测摩擦系数、质量等物理属性；(3) 场景组装——在 [[MuJoCo]] 中自动生成可运行的仿真。整套流程对 [[DROID]] 和 [[PhysTwin]] 数据集的 episodes 做了系统评测，用 EMPM 指标衡量仿真与真实轨迹的对齐程度。
- **对比方法/Baselines**: 与手工调参的 real2sim baseline 对比，展示自动化流水线的接近度。
- **借鉴意义**: 对做 sim-to-real 的人：自动化 real2sim 流水线能把真实机器人 demo 批量转换为仿真训练数据，大幅降低数据采集成本。
- **锐评**: NUS+JHU 联合，方向非常有价值。但 "VLM 猜物理参数"这一步是最大的 weak point——目前 VLM 对材质和质量的感知远不可靠，会引入系统性误差，摘要对此没有深入讨论。另外没有 end-to-end 验证：只证明了 sim 和 real 轨迹对齐，没有证明用这个 sim 训练的 policy 能 transfer 回真实环境。👀
- **关联笔记**: [[MuJoCo]]（仿真器）、[[FoundationPose]]（姿态估计）、[[DROID]]（数据集）

### 7. Lifting Embodied World Models for Planning and Control

- **作者**: Alex N. Wang, Trevor Darrell, Pavel Izmailov 等
- **机构**: New York University, UC Berkeley, Imperial College London
- **链接**: [arXiv](https://arxiv.org/abs/2604.26182) | [PDF](https://arxiv.org/pdf/2604.26182)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2604.26182v2/x1.png)

- **核心方法**: 针对复杂 embodiment 的高维 action space 导致 world model 难以规划的问题，提出"lifting"：把低层 joint-level action 提升到高层 waypoint action space。具体：(1) 高层动作定义为关键关节（手腕、胯部等）的目标位姿，投影到当前 RGB 帧上作为 visual waypoint；(2) 训练 lifted world model，输入当前图像 + waypoint annotation → 预测下一帧；(3) 用 [[CEM]] 在 waypoint 空间规划，低层 policy 追踪 waypoint。在人体 locomotion（视频数据训练）上做了 goal-conditioned policy 评测。
- **对比方法/Baselines**: 对比了 [[NoMaD]]（navigation world model），以及 base policy without lifting，消融了 CEM 搜索的贡献。
- **借鉴意义**: 对做 humanoid 和 dexterous manipulation 的人：waypoint-in-image 的表示方式是把 VLM 视觉空间和 action space 对齐的自然方案，和 MVA 的思路有共鸣，值得对比学习。
- **锐评**: NYU+Berkeley 出品，概念干净。但 waypoint = "关键关节的目标位姿"，这需要 ground truth 关节姿态标注，在 wild video 上怎么获取摘要里没说清楚。另外只在 locomotion 上测试，manipulation 还没有；CEM 在高维 waypoint 空间里的搜索成本需要评估。更像是一个有价值的 vision 而非完整系统。👀
- **关联笔记**: [[NoMaD]]、[[CEM]]（规划方法）
- 💡 **想精读？** 运行：`读一下 Lifting Embodied World Models for Planning and Control`

### 8. Guide, Think, Act: Interactive Embodied Reasoning in VLA Models (GTA-VLA)

- **作者**: Yiran Ling, Qing Lian, Jinghang Li 等
- **机构**: Futian Laboratory; Harbin Institute of Technology
- **链接**: [arXiv](https://arxiv.org/abs/2605.13632) | [PDF](https://arxiv.org/pdf/2605.13632)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [[GTA-VLA]]

![](https://arxiv.org/html/2605.13632v2/x1.png)

- **核心方法**: GTA-VLA 把 VLA 推理拆成三阶段：(1) Guide：用户通过点击/框选提供空间 visual cue（点、框、区域），作为显式空间 prior 注入；(2) Think：基于 spatial prior 生成结构化 CoT（SUBTASKS → CURRENT → 物体位置描述），而非自由文本 CoT；(3) Act：基于 CoT 做异步 [[Flow-Matching]] 动作生成（推理和执行解耦，推理更慢但不阻塞执行）。在 SimplerEnv 的 OOD 条件下（视觉扰动、robot 状态扰动、语言扰动、物体扰动）做了系统评测，并有 [[WidowX]] 真机验证。
- **对比方法/Baselines**: 对比 [[OpenVLA]]、[[MolmoAct]] 和 free-form CoT 版本。结构化 CoT 相比 free-form CoT 在 OOD 上有显著提升，消融明确。
- **借鉴意义**: spatial visual cue + 结构化 CoT + 异步 flow-matching 三件套可以独立借鉴。interactive guidance 使 policy 在 distribution shift 下更鲁棒，无需重新训练。
- **锐评**: Futian Lab + HIT，方法设计合理，OOD 评测的四个扰动维度覆盖比较全面。但 spatial cue 依赖用户输入——实际部署时谁来给这个 cue？如果是自动检测的话，检测失败时的 fallback 没有讨论。异步 flow-matching 在真机上的延迟表现如何，摘要未提及。总体来说，今天 VLA 里做得比较扎实的工作。🔥
- **关联笔记**: [[OpenVLA]]（基线）、[[SimplerEnv]]（评测平台）、[[Vision-Language-Action]]
- 💡 **想精读？** 运行：`读一下 Guide, Think, Act GTA-VLA`

### 9. AnchorRefine: Synergy-Manipulation Based on Trajectory Anchor and Residual Refinement for VLA Models

- **作者**: Tingzheng Jia, Kan Guo, Lanping Qian 等
- **机构**: Beijing University of Technology; Nanjing University of Science and Technology
- **链接**: [arXiv](https://arxiv.org/abs/2604.17787) | [PDF](https://arxiv.org/pdf/2604.17787)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2604.17787v1/x1.png)

- **核心方法**: AnchorRefine 的核心洞察：VLA 的 action 空间里，"全局轨迹运输"和"局部精细修正"由同一个目标函数优化，大运动主导梯度导致精细操作学不好。解法：(1) Trajectory Anchor Planner：预测粗粒度 anchor trajectory（方向和 waypoint，在原始 action 空间）；(2) Residual Refine Module：在 anchor 的残差空间里学习精细修正量。两个模块联合训练，残差模块只需学习小的 delta，有效降低学习难度。在 [[CALVIN]]、[[LIBERO]] 和真实 WidowX 上做了测试。
- **对比方法/Baselines**: 对比了 [[OpenVLA]]、[[AtomicVLA]]、[[GR-1]] 等。LIBERO-Long 上的接触敏感任务有定性对比图。
- **借鉴意义**: coarse-to-fine decomposition 在 manipulation 里是经典思路，AnchorRefine 把它做到 VLA action space，工程上直接可用，有 real world 验证。
- **锐评**: BIT + NJUST 出品，方法直观，实验覆盖较全。残差修正在 robotics 里并不新鲜（delta-policy、refinement networks 早有前例），但用在 VLA action space 的分解上确实对的时机。更大的疑问是：如果 anchor trajectory 本身偏差过大，残差能纠正多少？实验里没有单独做 anchor 精度的分析。👀
- **关联笔记**: [[GR-1]]、[[CALVIN]]、[[LIBERO]]（评测平台）
- 💡 **想精读？** 运行：`读一下 AnchorRefine`

### 11. STeP: Signal Temporal Logic for Precise Specifications for Action Generation with VLMs

- **作者**: Kasra Torshizi, Anukriti Singh, Sidharth Mathur 等
- **机构**: University of Maryland
- **链接**: [arXiv](https://arxiv.org/abs/2607.18580) | [PDF](https://arxiv.org/pdf/2607.18580)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.18580v1/x1.png)

- **核心方法**: STeP 把 [[STL]]（Signal Temporal Logic）作为 VLA 的中间规范层。流程：自然语言 task → VLM 生成 STL formula（时序逻辑约束，如"在 t∈[2,5] 内 EE 的 x 坐标满足 ρ > 0.3"）→ 在线验证轨迹满足性（robustness score）→ 当检测到 STL violation 时，[[MPC]] 触发纠偏动作。整体框架形成可解释的"if VLA 违约，则 MPC 介入"的安全层。对比 [[ReKep]]、[[VoxPoser]]、[[ProgPrompt]]——这些方法的约束是语言级别，缺乏形式化保证。
- **对比方法/Baselines**: 与 ReKep、VoxPoser、ProgPrompt 的定性对比，STeP 的差异化在于 STL 的时序逻辑可验证性。
- **借鉴意义**: 对做 VLA 安全性的人：STL robustness score 可作为在线监控信号，在 safety-critical 场景（精密组装、surgical robot）里有真实价值。
- **锐评**: Maryland 出品。STL + robot 不是新想法（形式化方法社区早就在做），但 VLM 自动从自然语言生成 STL 是有意思的新接口。关键问题：VLM 生成的 STL formula 的正确率有多高？一个错误的 STL spec 比没有 spec 更危险——这个 failure mode 没有系统讨论。MPC recovery 的计算开销也没有评估。理论框架有意思，工程落地未完整验证。👀
- **关联笔记**: [[VoxPoser]]、[[ReKep]]（基线对比）、[[STL]]
- 💡 **想精读？** 运行：`读一下 STeP STL VLA`

### 12. Evaluating Uncertainty and Quality of Visual Language Action-enabled Robots

- **作者**: Pablo Valle, Chengjie Lu, Shaukat Ali, Aitor Arrieta
- **机构**: Mondragon University (Spain)
- **链接**: [arXiv](https://arxiv.org/abs/2507.17049) | [PDF](https://arxiv.org/pdf/2507.17049)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2507.17049v3/Figures/VLA-enabled_robot.png)

- **核心方法**: 一个 VLA 评测框架，提出不依赖任务成功率的质量指标体系。分两类：(1) 不确定性指标（token entropy、action variance 等），衡量 VLA 推理时的置信度；(2) 轨迹质量指标（TCP-PI：轨迹位置不稳定性、TCP-VI：速度不稳定性），衡量执行质量。在 [[WidowX]] 上用 [[OpenVLA]] 和 [[SpatialVLA]] 做测试，建立了 web-based 人工标注工具获取 ground truth quality labels。
- **借鉴意义**: 做 VLA 部署的工程师有用——token entropy 和 trajectory instability 作为 online health monitor 是实用的，但没有方法创新。
- **锐评**: 西班牙 Mondragon 大学，工作有工程价值——任务成功率作为唯一指标确实不够。但只测了 2 个 VLA 模型，soft 质量指标（token entropy）和 actual task performance 的相关性多强没有系统验证。做评测 paper 能做到这个规模已经不容易，但不会改变任何人的研究方向。🫠

## 3D Gaussian Splatting

### 13. ZeroSplat: Generalized Referring Segmentation in 3D Gaussian Splatting

- **作者**: Jiayu Ding, Meilu Song, Xiaoyi Zhang 等
- **机构**: Peking University; North China Electric Power University; InkMind
- **链接**: [arXiv](https://arxiv.org/abs/2607.18801) | [PDF](https://arxiv.org/pdf/2607.18801)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.18801v1/x1.png)

- **核心方法**: ZeroSplat 解决 3DGS 中的 Generalized Referring 3D Segmentation（GR3DGS）——给定自然语言 query，同时分割多个目标（数量不定）。方法：(1) Geometry-Guided VLM Semantic Parsing：用 3DGS 的几何先验（depth、normal map）引导 VLM 分解 query，得到每个候选目标的 2D mask；(2) 2D mask → 3D lifting（投影到 Gaussian 上）；(3) Multi-view verification：从多视角一致性过滤 false positive；(4) Spatial refinement：用 KNN 在 3D Gaussian 邻域做精化。对比了 [[LERF]]、[[LangSplat]]、[[OpenGaussian]]、[[ReferSplat]]。
- **对比方法/Baselines**: 在 GR-LERF 和 GR-ScanNet 上用 mIoU 做定量评测，multi-view verification 是关键提升点。
- **借鉴意义**: 对做 robot 3D scene understanding 的人：GR3DGS 比单目标 R3DGS 更接近真实 robot 交互场景。几何引导的 VLM parsing 是个实用设计。
- **锐评**: PKU 出品，任务定义有价值——现实场景里 multi-target 指代是常态，原有 R3DGS 方法只处理单目标确实是缺陷。但"ZeroSplat"暗示 zero-shot 能力，摘要里没说明是否真的 zero-shot（还是在 GR 数据集上 fine-tune 的？）。multi-view verification 需要已经渲染好的 3DGS 场景，在真正的 robot 在线感知场景里能否实时用还不清楚。👀
- **关联笔记**: [[LangSplat]]、[[OpenGaussian]]、[[LERF]]（基线对比）
- 💡 **想精读？** 运行：`读一下 ZeroSplat 3DGS`

## RL / Planning

### 14. Planning as Emergent Behavior in Reinforcement Learning with Relational Hidden States

- **作者**: Armin Sommer
- **机构**: ETH Zurich
- **链接**: [arXiv](https://arxiv.org/abs/2607.18589) | [PDF](https://arxiv.org/pdf/2607.18589)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.18589v1/x1.png)

- **核心方法**: 用 Sokoban 作为测试床，研究 planning 在 model-free RL 中如何"涌现"。核心想法：用 Slot-based LSTM（每个 slot 对应棋盘一格）替换标准 [[ConvLSTM]]，让 hidden state 有明确的 relational binding（格子→slot）。分析了"load-bearing slot"（真正用于规划的 slot）和"free slot"的比例，可视化展示规划行为确实在 hidden state 里出现。对比了 [[DRC]]（Deep Repeated ConvLSTM）、ConvLSTM、AttnLSTM 等架构。
- **借鉴意义**: 对做 planning 和 world model 基础研究的人：relational hidden state 和 planning 涌现的关系是有意思的理论问题。但 Sokoban grid world 和真实 embodied AI 的 state/action space 差距巨大。
- **锐评**: ETH 单人 PhD 工作，研究问题本身有价值，但 Sokoban 离真实机器人太远，结论是否能推广存疑。Section title "Emergent Planning" 有点夸大——更像是"结构化 hidden state 有助于规划行为"。💤
