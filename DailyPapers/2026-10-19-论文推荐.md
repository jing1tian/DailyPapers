## Game Agent

### 3. Player-1: Learning to Play from Synthetic Experience
- **作者**: Mingyu Ouyang, Yiran Wang, Siyuan Hu, Xingyilang Yin, Huiqiang Sun, Guangzhi Wang, Junfu Pu, Cheng Cheng, Honghao Chen, Ying Shan, Mike Zheng Shou, Hwee Tou Ng
- **机构**: National University of Singapore ARC Lab, Tencent IEG, Nanyang Technological University
- **链接**: [arXiv](https://arxiv.org/abs/2610.20584) | [PDF](https://arxiv.org/pdf/2610.20584)
- **来源**: 🔥 HF Trending，⬆️ 334

> ⏪ **再推提醒**：这篇在 2026-10-17 推荐过

![](https://arxiv.org/html/2610.20584v1/overview.png)

- **核心方法**: 输入是游戏截图 + 任务指令，输出是键鼠动作序列。三阶段流水线：（1）SFT on 6,044 条 curated gameplay trajectories，扩展动作空间加入 relative pointer motion、sustained inputs 和 composite actions；（2）构建 Player-1-Gym，16 个 synthetic 2D/3D 环境，programmatically verifiable rewards + 随机化 observation/control dynamics；（3）[[PPO]] 强化学习跨环境训练。核心思路是用 synthetic experience 替代 large-scale demo，让模型通过可验证奖励学习泛化控制策略。
- **对比方法/Baselines**: 对比 [[TARS-1]]、[[JARVIS]]、[[GameWAM]]（world model for games）等 game/computer-use agents。基于 [[VLA]] 架构 fine-tune，评测在 [[MineDojo]]-300、[[ViZDoom]]-10、[[GameWorld]] 三个 benchmark。
- **借鉴意义**: "Synthetic environment + programmatic rewards + RL"这条路对 sim-to-real 有直接参考价值——不依赖大量真实 demo，靠仿真环境 bootstrap RL 泛化。Composite action design（多键组合 + 持续输入）的思路在 dexterous manipulation 里也有对应问题。
- **锐评**: 334 upvotes，NUS + Tencent 合作，工程味浓。Player-1-Gym 的 16 个合成环境是核心贡献，但都是 2D/3D 简单游戏，MineDojo 和 ViZDoom 离真实游戏的复杂度还有距离。SFT 阶段 6,044 条数据不多；PPO 提升 27.8% 好看，但 baseline 是自己的 SFT 策略，没有和专家级 agent 横向对比。摘要说 `has_real_world: True`，但在游戏语境下"真实"是游戏真实执行而非物理世界，不要误读。往 embodied AI 方向看：curriculum design 和 programmatic reward 有借鉴意义，动作空间迁移性存疑。 👀

### 4. Urbex: Agentic Spatial Grounding for City-Scale 3D Scenes
- **作者**: Yu Wang, Rui Dai, Wei Chen, Yi Wang, Bo Dang, Kaikui Liu, Xiangxiang Chu, Yansheng Li
- **机构**: 未知（affiliations 提取失败，需自行查看 PDF）
- **链接**: [arXiv](https://arxiv.org/abs/2610.18356) | [PDF](https://arxiv.org/pdf/2610.18356)
- **来源**: 🔥 HF Trending，⬆️ 133

> ⏪ **再推提醒**：这篇在 2026-10-17 推荐过

![](https://arxiv.org/html/2610.18356v1/intro.png)

- **核心方法**: 输入是自然语言描述 + city-scale 3D 场景，输出是目标物体的 3D bounding box。把 grounding 重表述为 active spatial search——VLM agent 主动 query landmarks、zoom 局部区域、render oblique views，最后 commit bounding box，而不是对预计算 instance proposals 做 ranking。用 [[GRPO]] + smooth localization reward + lightweight shaping reward 优化 tool-use policy，在 [[CityRefer]] 上训练。
- **对比方法/Baselines**: 对比 [[CityAnchor]]、[[InstanceRefer]]、[[EDA]] 等 city-scale grounding baselines。场景预处理依赖 [[SoftGroup]]（instance segmentation），但推理阶段声称 candidate-free。
- **借鉴意义**: [[GRPO]] 优化 VLM spatial reasoning 的框架对 embodied AI 导航任务有参考价值。"Active search"范式——让 agent 主动探索而不是一次性回归——与 exploration-based planning 的思路对接。
- **锐评**: 133 upvotes，问题定义干净。但 affiliations 完全为空是个警示——富化脚本提取失败，机构信息需要手动确认。Candidate-free 是个好 claim，不过 STPLS3D-Refer zero-shot 结果摘要只说"improved cross-scene robustness"，没报具体数字，margin 大小需要看全文。City-scale 3D grounding 离 embodied manipulation 有一段距离，和城市级导航（outdoor mobile robot）更近。有真东西但离你的核心方向不是最近的一篇。 ⚠️
