### 2. Enfold: Folding World Model Imagination into Predictive Representations for Ultra-Efficient Embodied Control

- **作者**: Weili Zeng, Yitong Xing 等
- **机构**: Shanghai Jiao Tong University（通讯：yanyichao@sjtu.edu.cn）
- **链接**: [arXiv](https://arxiv.org/abs/2607.26657) | [PDF](https://arxiv.org/pdf/2607.26657)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [[Enfold]]

![](https://arxiv.org/html/2607.26657v2/related_work.png)

- **核心方法**: 传统 WAM 用生成出来的未来帧/视频来辅助 action prediction，计算开销极大。Enfold 的洞察是：WM 真正有价值的不是它生成的内容，而是它生成过程中积累的内部预测表征。Enfold 把这些预测表征直接 fold 进 VLA 的 action decoder，不需要渲染输出帧。用 [[JEPA]] 风格的自监督预测目标训练 predictor，用 [[DINO]]/[[ViT]] 特征作为目标。"Enfold-Flash" 是极致效率变体，用 TensorRT 加速。输入是当前视觉观测 + 任务语言，输出是动作序列。
- **对比方法/Baselines**: 对比 [[WAM]]（GigaWorld 系列）、[[FastWAM]]、[[LingBot]] 等 generative WAM 方法；借鉴 [[JEPA]] 表征学习范式。在 [[LIBERO]]、[[RoboTwin2]] 上测试，覆盖 simulation benchmark。
- **借鉴意义**: 对做 WAM 的人是直接挑战——如果 predictive representation 够用，何必生成？对 VLA 侧的人：这是目前把 WM 知识注入 VLA 开销最低的方案之一。
- **锐评**: 思路干净，这才叫找到了问题的本质。"WM 的价值在于它知道什么，而不在于它产出什么"——这句话值得所有 WAM 研究者反复读。有 LIBERO + RoboTwin2 双 benchmark 实验，且 has_real_world=True，结果可信度高。唯一值得盯着看的是：预测表征的表达力上限在哪？强泛化能力是 generative WM 的优势，Enfold 是否在 OOD 场景下会掉点，摘要没说。🔥

### 3. LiLa-WAM: Lightweight Latent Reasoning World-Action Model for Robotic Manipulation

- **作者**: Fan Yang, Yuting Su, Xiaobo Wang, Yuncheng You, Fugui Fan 等
- **机构**: Tianjin University, Shenzhen University of Advanced Technology, Mininglamp Technology
- **链接**: [arXiv](https://arxiv.org/abs/2608.03701) | [PDF](https://arxiv.org/pdf/2608.03701)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2608.03701v1/x1.png)

- **核心方法**: 与 Enfold 同天发，解法不同。LiLa-WAM 仍做视频生成，但把生成过程压在 latent 空间而非 pixel 空间，用 lightweight latent reasoning 替代重型 video diffusion。核心是 "Foresight-Aware" latent prediction，用 [[DiT]] 架构在 latent 空间做条件生成，再解码给 policy。对比 [[GigaWorld]]、[[LaWAM]]、[[SmolVLA]]、[[StarVLA]] 等已有 WAM 方案。
- **对比方法/Baselines**: 对比 [[GigaWorld]]、[[OpenVLA]]、[[LingBot]] 等；在 [[RoboTwin]]、[[LIBERO]] benchmark 上测试，有 real-robot 实验。
- **借鉴意义**: 如果你在用 GigaWorld 类的 WAM 但被推理延迟卡脖子，LiLa-WAM 是值得尝试的轻量替代。
- **锐评**: 和 Enfold 的差别在于：Enfold 放弃生成，LiLa-WAM 把生成做得更轻。两条路都合理，但 Enfold 的逻辑更彻底。LiLa-WAM 的问题是 latent 生成的质量上限取决于 VAE 的压缩比，高压缩下是否还能提供有效 foresight 需要消融证明。方法名 "VTT"（视觉任务标注？）在 method_names 里，但摘要没解释——要看全文才知道这是什么。👀

### 4. DriftWorld: Fast World Modeling through Drifting

- **作者**: Susie Lu 等
- **机构**: Massachusetts Institute of Technology, Harvard University
- **链接**: [arXiv](https://arxiv.org/abs/2607.15065) | [PDF](https://arxiv.org/pdf/2607.15065)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.15065v2/x1.png)

- **核心方法**: 现有 action-conditioned world models 用迭代去噪（DDPM/DDIM 类），rollout 慢。DriftWorld 提出 "drifting"——用单次前向传播（single forward pass）生成高质量未来帧预测。核心思路是训练模型直接预测 "drifted" 状态，而非逐步去噪。用 [[FiLM]] 层注入动作条件。在 [[WorldGym]]、[[MuJoCo]] 环境测试，并与 [[AVDC]]、[[GAIA-1]]、[[Ctrl-World]] 对比。
- **对比方法/Baselines**: 与 iterative denoising WM（[[VDM]]、[[LVDM]]）对比；借鉴 [[MagicDrive]] 的条件生成框架。FVD 作为主要生成质量指标。
- **借鉴意义**: 做 model-based RL 需要大量 rollout 的场景（如 [[WorldGym]] 式训练）直接受益。比 consistency distillation 更简洁。
- **锐评**: "Drifting" 是个聪明的叫法，但本质上是 one-step prediction 训练，与 consistency distillation 的哲学差别有多大？还是需要全文确认技术差异。MIT/Harvard 出品，实现细节应该到位。FVD 指标好看，但动作条件下的长时序一致性是 one-step 方法的硬伤——摘要未提及这一点。👀

### 8. ValueFormer: A Causal Transformer Value Function with Stage-Aware Labels for Semi-Autonomous Vision-Language-Action Policies

- **作者**: Inkyu Sa, Konstantin Stulov, Rajat Bhageria
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2608.02958) | [PDF](https://arxiv.org/pdf/2608.02958)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2608.02958v1/figures/front-page_fig.png)

- **核心方法**: 痛点是 behavior cloning VLA 无法从 action stream 判断任务是否在悄悄崩溃。ValueFormer 在 [[π0]]-family flow-matching VLA 上挂一个 causal transformer value head，用 stage-aware labels 标注每帧的进度（按任务完成阶段打标，而非 binary success）。value function 用 Monte Carlo 回报估计（MC return），同时提供半自主模式：value 低于阈值时触发人工接管（HIL）。用 [[LeRobot]] 框架实现，AUROC 作为评估指标。
- **对比方法/Baselines**: 借鉴 [[LIV]]（language-image value learning）；对比 [[RECAP]]（failure detection baseline）；在 [[LIBERO]] 上测试。
- **借鉴意义**: 做 deployment 的人直接有用——加一个 value head 就能做实时故障检测和半自主接管，比重新训 policy 省事多了。对 [[HIL]]（Human-in-the-Loop）应用场景尤其适合。
- **锐评**: 思路务实，站得住脚。Stage-aware labels 的设计比单纯用 binary success 聪明，能区分"刚开始就失败"和"快成功时突然崩"。问题是：打 stage 标签需要人工定义 stage 边界，在新任务上有多少 annotation 成本？另外摘要声称"从 action stream 里什么都看不出来"，但 VLA 的 confidence score 没有做过对比——claim 稍显过强。👀

### 9. Unified Visuomotor Targets: Supervising VLAs Beyond Physical Actions

- **作者**: Zhenyang Feng（with Unnat Jain）
- **机构**: University of California, Irvine
- **链接**: [arXiv](https://arxiv.org/abs/2608.03563) | [PDF](https://arxiv.org/pdf/2608.03563)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [[UVT]]

![](https://arxiv.org/html/2608.03563v1/x1.png)

- **核心方法**: VLM backbone 学了大量视觉语义，但 VLA fine-tuning 只用 action loss 监督——大量视觉表征能力被浪费甚至被覆盖。UVT 提出统一视觉运动目标监督：在动作预测之外，同时预测视觉侧的辅助目标（scene state、object pose 等）。UVT 的关键设计是 [[MVAE]]（Multimodal VAE），把多个视觉目标编码为统一 latent，和动作 latent 共同训练。对比 [[ACT]]、[[UniVLA]]、[[DYN]] 等多头监督方案，在 [[LIBERO]] 上做消融，有 real-robot 实验。
- **对比方法/Baselines**: 对比 [[UniVLA]]（多任务监督）、[[ACT]]（action chunking）；借鉴 VLA 中的 auxiliary loss 思路。
- **借鉴意义**: 对做 VLA fine-tuning 的人是低成本改进——加辅助监督 loss，不改架构，就能更好保持 VLM 原有的视觉理解能力。
- **锐评**: 诊断准确——VLA 训练确实会部分破坏 VLM 的视觉语义能力，这在已有工作（如 [[RoboVLMs]] 消融）里有迹可循。MVAE 的设计让多目标监督统一化而不用手调各 loss 权重，这是亮点。weaknesses：辅助目标怎么选？选不好反而引入噪声。而且在 LIBERO 上测试的 sim 泛化性不等于真机泛化性。但作为思路，比单纯增大数据更有原则性。🔥

### 10. How Should Vision-Language-Action Models Use Proprioceptive State?

- **作者**: Yiren Zhao, Ziyang Chen, Ziyang Rao, Pengteng Li, He Zhang, Weiyu Guo, Yandong Guo, Dami Rush 等
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2608.03052) | [PDF](https://arxiv.org/pdf/2608.03052)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2608.03052v1/x1.png)

- **核心方法**: 纯消融研究。现有 VLA 把 robot proprioceptive state（joint angles、end-effector pose）用三种不同方式注入：① 序列化成文本 token ② 投影进 VL token 空间 ③ 条件化 action decoder。本文系统对比这三种方案，在 [[RoboCasa]] 上跑大规模消融（365 个任务），提出 DeltaSR（差值 state 表示）作为最佳编码策略。
- **对比方法/Baselines**: 对比 [[OpenVLA]]、[[OFT]] 等不同 proprio 处理方案；在 RoboCasa 上测试，has_real_world=False。
- **借鉴意义**: 如果你在做 VLA 且 proprio 处理方案还没定，这篇能帮你省一轮消融。DeltaSR 的直觉也合理——delta 比 absolute 更紧凑。
- **锐评**: 做消融研究没问题，但全在 simulation，结论在真机上是否 hold 不确定。而且 RoboCasa 任务的多样性覆盖面和真实操作任务的分布差别较大。作为参考好用，但不要把这个结论当铁律用。🫠

### 11. Track4Action: Distilling World-Centric 3D Tracker into Vision-Language-Action Policies

- **作者**: Chenyi Wang, Xinkai Wang, Bokai Lin, Jialin Tian, Fucheng Zhang, Cewu Lu, Lixin Yang
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2608.03727) | [PDF](https://arxiv.org/pdf/2608.03727)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2608.03727v1/x1.png)

- **核心方法**: action label 只告诉 VLA 要做什么动作，但不告诉它动作如何改变 3D 世界。Track4Action 用 [[Track4World]]（冻结的 world-centric 3D tracker）作为 teacher，提取 scene/motion/camera token，通过 knowledge distillation 把 3D 空间理解能力注入 VLA 的 hidden states。引入 "track queries" 从 VLA hidden state 提取，与 3D tracker target 匹配。在 [[LIBERO]]、[[RoboTwin]] 上测，有 real-robot（[[AgileX]]、[[ALOHA]]）实验。
- **对比方法/Baselines**: 对比 [[WorldVLA]]、[[TraceVLA]]、[[SpatialVLA]]、[[UniVLA]]、[[FlowVLA]] 等空间感知 VLA；借鉴 [[OpenVLA]]、[[FAST]] 基础架构。
- **借鉴意义**: 对做 manipulation 的人：3D 空间理解是 VLA 的长期痛点，distillation 路线比直接用 3D input 更轻量。Track4World 作为 teacher 的选择也值得注意。
- **锐评**: 用 teacher-student distillation 把 3D 空间知识注入 VLA，比直接在输入加 3D 特征更巧妙——后者需要 3D 传感器，前者训练时用、推理时免。ALOHA/AgileX 实机实验有说服力。问题：Track4World 本身的质量是上限，摘要没说它在新场景下有多 robust。蒸馏质量也高度依赖 alignment 好不好。整体是今天 VLA 里最有工程价值的工作之一。👀

### 12. Continue or Replan? Bernoulli-Continuation Policy Learning for Adaptive Horizon Execution

- **作者**: Weichen Xu 等
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2608.03483) | [PDF](https://arxiv.org/pdf/2608.03483)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2608.03483v1/x1.png)

- **核心方法**: chunk-based VLA 执行固定步数 action chunk 再 replan，这很蠢——简单任务不需要频繁 replan，复杂任务又可能 replan 太晚。BCP 学一个伯努利策略（Bernoulli policy），每步决定"继续当前 chunk"还是"立刻重规划"。用 [[GRPO]]（Group Relative Policy Optimization）做 RL 训练 Bernoulli head，比直接用 BC 的阈值方案更自适应。实验在 [[LIBERO]]、[[RoboTwin]]、[[LingBot]] 上，有真机。
- **对比方法/Baselines**: 对比 fixed-horizon 执行（[[ACT]] 默认方案）；对比 fixed-threshold replan 策略；借鉴 [[GRPO]] RL 训练范式。
- **借鉴意义**: 对所有在跑 chunk-based VLA 的人直接有用。加一个 Bernoulli head + GRPO 训练，不改底层架构，就能让执行更智能。
- **锐评**: 问题定义清晰，解法合理。GRPO 用在这里比 PPO 省事，这个选择也说得通。质疑点：Bernoulli 这个 label "continue/replan" 是怎么定义的？如果用成功率回报，稀疏信号会让 RL 收敛很慢；如果用 value-based dense reward，又引入 reward shaping 的 bias。摘要没说清楚。另外 LIBERO 任务简单，Bernoulli head 的收益在复杂长时任务上是否更显著？👀

![](https://arxiv.org/html/2608.03231v1/x1.png)

- **核心方法**: 物理对抗 patch 通过劫持 VLA 的 attention map 来攻击机器人——让模型 "看" 贴纸而忽视目标物体。SARF（Structure-Aware Robust Fine-Tuning）通过 attention-guided structure-preserving 正则化来防御：在 fine-tuning 时约束 attention 分布不被 patch 劫持。引入 AGSD（Attention-Guided Structure Distillation）损失。对比 [[EDPA]]、[[UADA]]、[[UPA]] 等攻击方法，以及 [[EOT]] 鲁棒性训练基线。在 [[LIBERO]]、[[PiPER]] 机械臂上测，has_real_world=True。
- **对比方法/Baselines**: 与 [[EDPA]]、[[UADA]]、[[UPA]] 等攻击配对测试；[[OpenVLA]] 为基础模型。
- **借鉴意义**: 做 VLA 部署安全的人必须看。物理 patch 攻击是现实威胁，SARF 是目前较系统的防御方案之一。
- **锐评**: 攻击向量分析准确，attention hijacking 是真实的漏洞。但论文说 has_real_world=True——需要看全文确认是否在真实物理环境而非仅用渲染图模拟 patch。防御方法的核心 trade-off 是：AGSD 正则化是否会降低正常场景下的 task performance？摘要没给 clean accuracy 对比。另外只在 OpenVLA 一个 base model 上测试，对 pi0 这类 flow-matching 架构是否同样有效？⚠️

### 14. DRIFT: Derailing Denoising Trajectories of Flow-Matching VLAs with Adversarial Patch Attack

- **作者**: Hoseong Tae, Jong-Seok Lee
- **机构**: School of Integrated Technology, Yonsei University
- **链接**: [arXiv](https://arxiv.org/abs/2608.03207) | [PDF](https://arxiv.org/pdf/2608.03207)

![](https://arxiv.org/html/2608.03207v1/figures/figures_teaser_final.png)

- **核心方法**: pi0 等 flow-matching VLA 被宣传为对传统对抗攻击（如 FGSM、PGD）更鲁棒。DRIFT 证明这个说法不成立——flow-matching 的 ODE 积分过程可以被攻击，只要在 ODE 轨迹早期扰动方向向量，就能把整个 action sequence "derail"（偏轨）。DRIFT 设计 trajectory-level 攻击损失，对比 [[EDPA]]、[[NAD]]（现有 VLA 攻击）。在 [[LIBERO]] 上验证，对比 JPEG 压缩等防御。has_real_world=True。

- **锐评**: 攻击论文做得扎实——反驳了一个流行但未经充分验证的 claim。ODE 轨迹层面的攻击思路有意思，比 gradient-based pixel perturbation 更有针对性。Yonsei 两人完成，资源有限但逻辑清晰。弱点：LIBERO 是 simulation，物理 patch 在真机上的 transfer 能力如何？攻击成功率是否对 patch 面积高度敏感？👀

### 17. ActQuant: Sub-4-bit Action-Guided Quantization for Vision-Language-Action Models

- **作者**: Arash Akbari, Arman Akbari, Masih Eskandar, Qitao Tan, Yixiao Chen, Jingwu Luo, Bertha Pangaribuan 等
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2605.24011) | [PDF](https://arxiv.org/pdf/2605.24011)

![](https://arxiv.org/html/2605.24011v3/x1.png)

- **核心方法**: VLA 的 LLM backbone 量化到 sub-4bit 会破坏 action-critical 权重。ActQuant 用 HSIC（Hilbert-Schmidt Independence Criterion）度量每个权重矩阵和 action output 的统计相关性，据此做自适应 bit allocation：action-relevant 权重保留更高精度，其他可以更激进压缩。基于 [[OpenVLA]] 和 [[OmniModel]] 实现，对比 [[GPTQ]]、[[GGML]]、[[GGUF]] 等通用量化方法，在 [[LIBERO]] 上测 task success rate。has_real_world=True。

## 今日趋势判断
