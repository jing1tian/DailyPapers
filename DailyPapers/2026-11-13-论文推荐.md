## Embodied AI

### 1. World In-Context Learning for Agentic Robot Manipulation
- **作者**: Fang, Heng, Guo, Zehui, Zhang, Yuehan, Du, Mingyang, Liang, Dingkang, Bai, Xiang
- **机构**: Huazhong University of Science and Technology
- **链接**: [arXiv](https://arxiv.org/abs/2611.12885) | [PDF](https://arxiv.org/pdf/2611.12885)
- **来源**: 🔥 HF Trending，⬆️ 58
- 📒 **笔记**: [[RoboScript]]

- **核心方法**: 提出 WICL（World In-Context Learning）范式，核心思路是把"用 gradient 更新权重"换成"把 world feedback 写进 context"。具体实现叫 [[RoboScript]]：输入单个演示，在模拟器中排练任务，把排练过程中学到的知识固化成 Task Memory，推理时把 Task Memory 注入 frozen 模型的 context。部署时有数据隔离机制，确保每个部署输入在真实机器人上都是可获取的。为了跨形态迁移，另有 cross-embodiment memory adaptation 模块
- **对比方法/Baselines**: 在 [[RoboTwin]] 2.0 的 50 个任务上测试，超越了最强 trained action policy（包括使用梯度更新的方法）20+ 个百分点。系统依赖 foundation model 能力，会随着 foundation model scaling 而提升
- **借鉴意义**: 对做 embodied AI 的人来说，这个"不更新权重、只写 context"的思路值得认真对待——如果模拟器足够好，或许真的可以绕过 policy fine-tuning 的工程痛苦。但核心依赖是：**你有没有一个足够好的 world model / simulator**
- **锐评**: 83.4% mean success across 50 RoboTwin 2.0 tasks with zero gradient updates 是实打实的数字，不是 cherry-pick。思路也清晰——把 world feedback 写进 context 而非权重，逻辑自洽。但问题在于：这套东西的上限完全取决于你用的 simulator 质量。摘要说"transfers to a physical dual-arm robot"，但没给出真实机器人的具体成功率数字，只说了"cross-embodiment memory adaptation"——这个细节值得在全文里挖。另外 Task Memory 是怎么表示的？是 token 序列还是别的结构？这直接影响可扩展性。方向对，但 sim-to-real 的鸿沟没有在摘要层面被诚实面对。🔥

## 量化 / 推理加速

### 5. MACaQ: Fast, Model Agnostic Calibrated Quantization for Low-Precision Weights and Activations
- **作者**: Lorenz K. Muller, Philippe Bich, Chiara Boretti, Hyun-Min Chang, Jiawei Zhuang, Lukas Cavigelli
- **机构**: HUAWEI
- **链接**: [arXiv](https://arxiv.org/abs/2611.10649) | [PDF](https://arxiv.org/pdf/2611.10649)
- **来源**: 🔥 HF Trending，⬆️ 30

> ⏪ **再推提醒**：这篇在 2026-11-12 推荐过

![](https://arxiv.org/html/2611.10649v1/Figures/flux_3way_bf16_macaq_nvfp4.png)

- **核心方法**: MXFP4 W4A4 的 post-training 量化，每层独立处理，不跨层传播变换。对 activation 做 per-channel scale + block-Hadamard 在线变换，对应的逆变换吸收进权重。量化改进策略叫 Flip-Refinement：Hessian-aware 的坐标下降，贪心地把 FP4 编码移到相邻可表示值
- **借鉴意义**: 和 embodied AI / diffusion policy 关系不大——只是顺带在 image diffusion model 上验证了方法的通用性
- **锐评**: 量化方法本身技术扎实，layer-local 设计的工程好处（streaming、低 VRAM）确实是实际痛点。但对 robotics 团队来说，这篇的价值仅限于"万一你想在端侧部署大模型"的边缘场景。122B 模型 64 分钟量化、只用 32.5GB GPU RAM 是个好看的数字，但真正能用到这个的 embodied AI 场景还很少。💤
