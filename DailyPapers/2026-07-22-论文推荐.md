### 1. FM-VLA: Force-based Memory for Vision-Language-Action Models in Contact-Rich Manipulation
- **作者**: Ruicheng Li 等
- **机构**: Tsinghua University · Microsoft Research · Fudan University · USTC
- **链接**: [arXiv](https://arxiv.org/abs/2607.18231) | [PDF](https://arxiv.org/pdf/2607.18231)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.18231v1/x1.png)

- **核心方法**: FM-VLA 在标准 VLA（基于 [[PaliGemma]]）上引入力觉记忆模块，以接触力的时序信号替代采样历史帧做时序上下文推理。输入：视觉观测 + 语言指令 + 力传感器历史序列；输出：机器人动作。关键组件：Force Memory Bank（EMA 更新的力信号压缩表示）+ temporal attention cross-attending 到 memory bank；训练时用 DKL 蒸馏旧力记忆，防止灾难性遗忘。与视觉记忆 VLA 的核心区别：力觉在视觉模糊场景（如多次小幅按键）下携带视觉无法提取的时序信息。
- **对比方法/Baselines**: 与视觉记忆 VLA baseline 对比，以及无记忆 [[PaliGemma]] finetune；借鉴工业接触力控文献中的力信号处理范式。
- **借鉴意义**: 做接触丰富操作任务（精密装配、重复按压、插拔）的必看。力觉作为 VLA 记忆模态是被忽视的方向，比采样历史帧更轻且信息更丰富。
- **锐评**: 思路干净，解决的是真实存在的问题。力觉确实能抓住视觉抓不到的时序事件，真实机器人实验也有。唯一的 concern：力传感器不是所有平台标配，论文没讨论 force-free 平台上如何降级处理；跨平台部署时这个假设很重。 🔥

### 2. Closing the Loop in Humanoid VLA: Persistent 3D Object Tokens for Verifiable Loco-Manipulation
- **作者**: Peng Ren, Haoyang Ge 等
- **机构**: (机构信息未在摘要中完整列出)
- **链接**: [arXiv](https://arxiv.org/abs/2607.18016) | [PDF](https://arxiv.org/pdf/2607.18016)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.18016v1/pot_vla_system.jpg)

- **核心方法**: POT-VLA 提出 Persistent Object Tokenization（POT），为 humanoid 全身 loco-manipulation 持续维护 role-indexed 的 3D 物体记录（从 RGB-D 观测实时更新），并将这些物体 token 同时用于动作生成和执行后验证。输入：RGB-D + 自然语言 + 历史物体状态；输出：全身动作 chunk + 每个物体角色的 predicate 状态（是否达成目标空间关系）。核心创新：不只生成动作，还做 verifiable execution——比较执行前后物体状态，必要时触发 replanning。
- **对比方法/Baselines**: 整合 VLM、[[DiT]] 动作生成、全身 humanoid 执行；物体跟踪部分借鉴 object-centric 3D grounding 文献。
- **借鉴意义**: Humanoid loco-manipulation 的核心难题（移动中物体状态跑丢）这篇给出了系统性回答。做具身 AI 任务闭环/执行验证方向的必看 reference。
- **锐评**: "Object-state divergence"是真问题，humanoid 上尤其严重（移动中遮挡概率高）。Persistent token + verifiable execution 组合设计扎实，有真实机器人实验。遗憾是摘要没给出任务种类和成功率数字，泛化性需全文验证。 🔥

### 3. TempoVLA: Learning Speed-Controllable Vision-Language-Action Policies
- **作者**: Dong Jing 等
- **机构**: (摘要未列出机构)
- **链接**: [arXiv](https://arxiv.org/abs/2606.06491) | [PDF](https://arxiv.org/pdf/2606.06491)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.06491v2/x1.png)

- **核心方法**: TempoVLA 核心洞察：VLA 预测的动作幅度本身就决定了机器人执行速度，因此速度控制可以直接通过缩放动作幅度实现。训练时用 Variable-Speed Trajectory Augmentation（SpeedAug）在演示数据上增广不同速度版本，加 speed token conditioning；推理时用 VLM Scheduler 判断当前子任务是高风险接触（减速）还是低风险移动（加速）。在 [[OpenVLA]]、[[SmolVLA]]、[[TinyVLA]]、[[EfficientVLA]] 等多个 backbone 上验证，真实机器人实验有。
- **对比方法/Baselines**: [[OpenVLA]] KV-cache 加速、RL 速度调节等既有方案——本质上都是从一个固定速度换到另一个固定速度，不能动态调节。
- **借鉴意义**: 速度控制是 VLA 落地的实际需求，SpeedAug 极轻量，直接在数据增广阶段解决，值得直接采用。
- **锐评**: 洞察真实，方案干净。但 VLM Scheduler 的延迟呢？需要快速减速的时刻 VLM 判断是否来得及？论文有相关章节但 latency 数字未在摘要体现。v2 版本说明还在迭代。 👀

### 6. Foresight Residual RL for Long-Horizon Robot Manipulation with Vision-Language-Action Models
- **作者**: Yuhan Liu, Xinyu Zhang, Litao Liu, Abdeslam Boularias
- **机构**: Department of Computer Science, Rutgers University
- **链接**: [arXiv](https://arxiv.org/abs/2607.16506) | [PDF](https://arxiv.org/pdf/2607.16506)
- **来源**: 📄 arXiv 关键词检索

- **核心方法**: ForesightRL 在冻结 VLA（base policy）上训 residual RL，核心创新是 Foresight Value Function：不只评估当前 step 的 reward，而是评估当前 terminal state 对下游技能的好坏（预测后续子任务成功率）。用 Sequential Semi-MDP 建模多技能串联任务，Local Foresight Value Function 减小状态空间维度。有项目网站（jaysparrow.github.io/foresight-residual-rl）。

- **锐评**: 冻结 VLA 假设合理，residual RL 是成熟范式，foresight value 的创新点清晰。主要疑问：Foresight Predictor 怎么训——用什么数据学"下游子任务成功率"？这是个 bootstrap 问题，全文需要仔细看。真实机器人实验有，加分。 👀

### 12. Test-Time Scaling for World Action Models via Zero-Shot Geometric Evaluation
- **作者**: Zesen Zhao, Minkyoung Cho, Hui Shen 等
- **机构**: University of Michigan · NVIDIA
- **链接**: [arXiv](https://arxiv.org/abs/2607.17454) | [PDF](https://arxiv.org/pdf/2607.17454)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.17454v1/x1.png)

- **核心方法**: GeoBoN 是一个 training-free 的 WAM 推理时筛选框架。WAM 每次 rollout 同时暴露动作 chunk + 预测未来帧；GeoBoN 用跨视角深度重投影一致性（cross-view depth reprojection consistency）打分，从 Best-of-N 中选最高分动作。用冻结的几何基础模型（[[VGGT]]）做深度估计，无需额外训练。扩展版 GeoBoN-gated 自适应决定是否需要额外采样。在 RoboCasa、LIBERO、RoboTwin 上验证。
- **对比方法/Baselines**: 基于 [[LingBotVA]]（causal video-action WM）；对比无 scaling 的 WAM、随机 Best-of-N、以及其他 ranking 方法。
- **借鉴意义**: Training-free Best-of-N scaling 对任何 WAM 都可以直接接上，门槛低实用性强。几何一致性作为 rollout quality proxy 是有原则的 inductive bias。
- **锐评**: 没有真实机器人实验（全在 sim），是最大短板。但 Michigan + NVIDIA 做的几何 proxy 评分思路本身有意思，是 test-time scaling 用于机器人的 principled 尝试。几何一致性在真实环境（噪声深度、运动模糊）下是否成立，是最大的未知。 🔥

## 🌟 3D Gaussian Splatting

### 18. Exploration Matters for Escaping the Blur Trap in 3D Gaussian Splatting
- **作者**: Chengbo Wang, Guozheng Ma, Jinhong Wu 等
- **机构**: Hunan University · Nanyang Technological University
- **链接**: [arXiv](https://arxiv.org/abs/2607.17965) | [PDF](https://arxiv.org/pdf/2607.17965)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.17965v1/x2.png)

- **核心方法**: 论文指出 3DGS 优化中存在"Blur Trap"（模糊陷阱）：梯度偏向屏幕空间大梯度区域导致非凸优化陷入局部次优解。根本原因：屏幕空间梯度主导 + 深度梯度不足 + blending 诱导致密化失败。解法：引入 [[SGLD]]（Stochastic Gradient Langevin Dynamics）在优化中添加随机扰动作为"exploration"，帮助跳出局部极小。在 OMMO、NeRF360 等室外数据集上验证。
- **对比方法/Baselines**: 与 [[HoGS]]、[[AbsGS]]、[[MCMC]]（另一个加噪方式）对比；评估 PSNR/SSIM/LPIPS。
- **借鉴意义**: Blur Trap 理论分析有价值，SGLD 引入 3DGS 是 novel 角度。做 3DGS 场景重建的人，这是解决室外大场景模糊问题的实用技巧。
- **锐评**: 问题定义清晰，解法的理论 motivation 充分（SGLD 是有原则的探索方法）。缺的是：SGLD 超参（噪声温度）对不同场景的敏感性没有系统分析；只测了室外，室内复杂场景和动态物体影响未提。 👀

- 💡 **想精读？** 运行：`读一下 Exploration Matters for Escaping the Blur Trap in 3D Gaussian Splatting`

### 19. TopoGS: Planar Reconstruction via Topology-aware 3D Gaussian Splatting
- **作者**: Shanshan Pan, Jiale Chen 等
- **机构**: Shenzhen University · Autodesk Research
- **链接**: [arXiv](https://arxiv.org/abs/2607.16838) | [PDF](https://arxiv.org/pdf/2607.16838)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.16838v1/x1.png)

- **核心方法**: TopoGS 将平面作为有拓扑连接的结构体（而非离散集合）在 3DGS 框架中引入平面间 adjacency graph。两阶段：(1) 几何 + 拓扑初始化（深度图估计平面 + 建图）；(2) 联合优化（平面约束下 Gaussian 优化 + 平面分组）；(3) 结构拼接（边界对齐）。在 [[ScanNet]] 上评估，使用 [[SAM]] 做平面分割辅助，[[Depth-Anything]] 做初始深度。
- **对比方法/Baselines**: 与 [[PlanarGS]]、[[PlanarSplatting]]、[[NeuralPlane]]、[[PGSR]]、[[AirPlanes]] 等对比。
- **借鉴意义**: 结构化平面重建对室内机器人导航和场景理解有直接用途，拓扑图保持了平面间空间关系，对下游规划有帮助。
- **锐评**: ScanNet 室内重建是实用场景，与 Autodesk Research 合作有工业设计应用价值。但 SAM + Depth-Anything 都是外部依赖，资源受限平台上的端到端能力如何？拓扑连接在物体密集/遮挡场景的鲁棒性没有说明。 👀

- 💡 **想精读？** 运行：`读一下 TopoGS: Planar Reconstruction via Topology-aware 3D Gaussian Splatting`
