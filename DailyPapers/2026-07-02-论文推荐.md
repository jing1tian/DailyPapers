### 1. E-VLA: Event-Augmented Vision-Language-Action Model for Dark and Blurred Scenes
- **作者**: Jiajun Zhai, Hao Shi, Shangwei Guo, Kailun Yang, Kaiwei Wang
- **机构**: Zhejiang University, Ant Group, Hunan University
- **链接**: [arXiv](https://arxiv.org/abs/2604.04834) | [PDF](https://arxiv.org/pdf/2604.04834)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2604.04834v2/x1.png)

- **核心方法**: E-VLA 在 [[SmolVLA]]（[[SmolVLM]] backbone）基础上引入事件相机数据流作为辅助感知通道。输入是 RGB 帧 + 事件帧（高动态范围、无运动模糊），通过融合模块将事件特征注入 VLA 的视觉编码器。核心创新是"退化感知融合"：在低光/模糊条件下提高事件流的权重，在正常光照下退化为原始 [[OpenVLA]]-style VLA。测试时无需人工切换，自适应权重由图像质量指标驱动。
- **对比方法/Baselines**: 对比了 [[RetinexNet]]（图像增强）、[[EvLight]]（事件相机去噪）等图像复原前处理方案；基于 [[SmolVLA]] 基线，测试平台 [[LeRobot]] + [[RDT]]。
- **借鉴意义**: 做 manipulation 的人在真实工厂/夜间场景会遇到完全相同的感知退化问题。事件相机 + VLA 的融合路线比图像增强前处理更端到端、更低延时。值得重点关注。
- **锐评**: 真实机器人实验做了，数据集用 DAVIS event camera，实验覆盖了 pick-place 任务在低光和运动模糊两种退化下的表现。问题是 event camera 本身的工程成本高，而且论文没有说清楚"退化感知融合"的权重是如何自动校准的——如果需要提前标定退化程度，那这个方法的泛化性要打问号。但方向对，切入点实际。 🔥

### 5. Z-1: Efficient Reinforcement Learning for Vision-Language-Action Models
- **作者**: Zioneer Robot Team
- **机构**: 未知（Zioneer Robotics，商业公司）
- **链接**: [arXiv](https://arxiv.org/abs/2606.31846) | [PDF](https://arxiv.org/pdf/2606.31846)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.31846v1/x1.png)

- **核心方法**: Z-1 把 [[GRPO]]（Group Relative Policy Optimization）应用到 VLA RL 训练，解决 VLA 做 RL 时的效率瓶颈。关键创新是 Shared-Prefix KV Cache：GRPO 需要对同一 prompt 采样多个 rollout，Z-1 共享 prefix 的 KV 缓存，避免重复计算，显著降低显存和计算开销。配套 Tree-Structured Decoding（并行解码多个候选动作序列）和 Success-Aware Reward 设计。在 [[RoboCasa]] benchmark 上测试，与 [[OpenVLA]] 和 [[OpenPI]] 对比。
- **对比方法/Baselines**: 对比 SFT 微调（无 RL）、标准 GRPO（无 shared-prefix）、[[OpenVLA]]。
- **借鉴意义**: VLA RL 是当前最重要的研究方向之一。Shared-Prefix KV Cache 的工程优化是实用的，很多人做 VLA GRPO 都会遇到显存爆炸问题，这个解法直接可以复用。
- **锐评**: 来自商业公司（Zioneer），代码和数据不一定开源，要注意这点。没有 real-world 实验，has_real_world=False，只在 RoboCasa（模拟器）上测。但工程贡献（Shared-Prefix KV Cache）是扎实的。如果只是把 GRPO 套到 VLA 上但不解决 token 开销问题，这篇就很平庸；这篇的核心贡献确实在效率优化这个点上，值得重点看。🔥

### 6. LaMP: Learning Vision-Language-Action Policy with 3D Scene Flow as Latent Motion Prior
- **作者**: Xinkai Wang, Chenyi Wang, Yifu Xu, Mingzhe Ye, Fucheng Zhang 等
- **机构**: Southeast University, Shanghai Jiao Tong University, Shanghai Institute
- **链接**: [arXiv](https://arxiv.org/abs/2603.25399) | [PDF](https://arxiv.org/pdf/2603.25399)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2603.25399v2/x1.png)

- **核心方法**: LaMP 是一个双专家 VLA 框架：一个"场景流专家"在 latent 空间里预测 3D 场景流（刚体轨迹 + 流场），作为动作生成的隐先验；一个"动作专家"以此为条件输出最终关节/末端执行器轨迹。关键设计是 FlowVLA——把 3D 稠密场景流的光流信息压缩进 latent code 而不是在像素级别监督，避免 3D 监督的标注成本。在 [[SimplerEnv]]、[[BridgeV2]]、[[WidowX]] 真实机器人上测试。
- **对比方法/Baselines**: 对比 [[TraceVLA]]（2D 轨迹引导）、[[UniVLA]]、[[OpenVLA]]；借鉴 [[TraceForge]] 的轨迹合成方法。
- **借鉴意义**: 3D 运动先验的思路比 2D 轨迹更物理，对非平面操作任务（倒水、抬起、旋转）可能优势明显。FlowVLA 的 latent 压缩设计避免了稠密 3D 标注，这是真正的工程贡献。
- **锐评**: Real-world 实验有，在 WidowX 上做了实际操作。3D scene flow 作为 latent 先验的想法很清晰，比直接预测点云省事。但问题是：3D 场景流需要深度传感器或立体相机，单目 RGB 怎么办？摘要没有说清楚深度来源。如果用 RGB-D 就限制了部署环境，如果用单目估计深度那精度堪忧。需要看全文确认。 👀

### 11. Delta-JEPA: Learning Action-Sensitive World Models via Latent Difference Decoding
- **作者**: Zhenghao Zhang, Yuanxiang Wang, Zhenyu Guan
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2606.31232) | [PDF](https://arxiv.org/pdf/2606.31232)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.31232v1/framework.png)

- **核心方法**: Delta-JEPA 解决 [[JEPA]]-style 世界模型的核心缺陷：重建-free 的 joint-embedding 方法容易退化为"动作无关表示"（action-insensitive collapse）。解决方案：不直接预测下一帧 latent z'，而是预测 latent 差值 Δz = z' - z。差值天然对动作敏感，因为无动作时 Δz ≈ 0，有动作时 Δz 体现动态变化。在 [[DreamerV3]]、[[PLDM]]、[[LeWM]] 等基线上对比，在 DMC（DeepMind Control Suite）和真实机器人上验证。
- **对比方法/Baselines**: 对比 [[DreamerV3]]（重建型世界模型）、[[PLDM]]（基于预测的latent模型）、[[LeWM]]（[[LeWorldModel]]）。借鉴 [[DINO]] 编码器 + [[ViT]] backbone。
- **借鉴意义**: Delta 预测的思路优雅简洁，可以直接移植到现有 JEPA 框架里。对做 model-based RL + manipulation 的人来说这是一个值得实验的 inductive bias。
- **关联笔记**: [[LeWM]] — Delta-JEPA 在 LeWorldModel 基础上改进，解决其动作敏感性不足的问题。
- **锐评**: 想法简洁是真简洁——预测差值而不是绝对值，这个改动很小但理论动机清晰。有真实机器人实验（has_real_world=True）。问题在于：差值预测在动作幅度很小时（精细操作）信噪比会不会很低？这个边界条件论文应该讨论但摘要没提。机构信息缺失，需要看全文确认规模。 🔥
- 💡 **想精读？** 运行：`读一下 Delta-JEPA: Learning Action-Sensitive World Models via Latent Difference Decoding`

## 今日趋势

VLA 技术已经进入"堆感知模态"阶段——event camera、tactile、3D flow、4D history 轮番上阵，说明社区普遍认为 RGB 单模态的天花板已经被碰到了。World Model 方向出现了两个值得关注的技术路线：差值预测（Delta-JEPA）和解耦生成（DVG-WM），都在用"结构归纳偏置"而不是"更大模型"来解决效率问题。今天最值得担忧的趋势：大量 VLA 论文只在 LIBERO 仿真上测，没有真机实验，这个门槛正在被系统性地降低。
