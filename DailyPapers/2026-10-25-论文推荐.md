### 2. SANA-Video: Efficient Video Generation with Block Linear Diffusion Transformer
- **作者**: NVIDIA 团队
- **机构**: NVIDIA
- **链接**: [arXiv](https://arxiv.org/abs/2509.24695) | [PDF](https://arxiv.org/pdf/2509.24695)
- **来源**: 🔥 HF Trending，⬆️ 56

> ⏪ **再推提醒**：这篇在 2026-10-23 推荐过

![](https://arxiv.org/html/2509.24695v2/teaser.png)

- **核心方法**: SANA-Video 用自回归扩散框架（block-wise chain rule）生成长视频。两个关键设计：(1) Linear DiT——把 attention 的二次复杂度降到线性，让长序列变得可行；(2) [[DCAE]]（Deep Compression AutoEncoder）——极高压缩比的 VAE，把视频 token 数压到可接受范围。训练用 SFT + 对齐策略，支持 720×1280 分辨率和分钟级时长，单卡 RTX 5090 可跑。
- **对比方法/Baselines**: 对比了 [[SkyReelv2]]、MAGI-1、Self-Forcing；借鉴了 [[HunyuanVideo]] 的架构思路和 [[RoPE]] 位置编码，基于 DiT 基本结构。
- **借鉴意义**: Linear DiT + 高压缩比 VAE 的组合对做视频 world model 的人有直接参考价值——长时序视频 token 压缩方案值得借鉴。
- **锐评**: NVIDIA 出品，工程扎实。Linear attention 降复杂度不是新思路，关键是真做到了分钟级长视频，且能跑在消费级 GPU 上。但 method_summary 里充满 LaTeX 公式，没有展示真实场景下的语义一致性上限。视频生成赛道太卷，56 upvotes 说明即使是 NVIDIA 也很难破圈。价值在工程实现，不在理论突破。 👀

### 3. Has GPT-6-Astra Achieved Embodied Intelligence?
- **作者**: SenseNova 联合团队（Zhongang Cai, Ziang Cao, Limin Wang, Ziwei Liu 等）
- **机构**: SenseTime / SenseNova Research，南京大学，香港中文大学，NTU 等
- **链接**: [arXiv](https://arxiv.org/abs/2610.22471) | [PDF](https://arxiv.org/pdf/2610.22471)
- **来源**: 🔥 HF Trending，⬆️ 473
- 📒 **笔记**: [[GPT6Astra-EmbodiedEval]]

> ⏪ **再推提醒**：这篇在 2026-10-20 推荐过

![](https://arxiv.org/html/2610.22471v2/teaser.png)

- **核心方法**: 把 GPT-6-Astra 当作 zero-shot embodied agent，在 12 个机器人基准（tabletop manipulation、humanoid、household、navigation）上统一测试。固定模型权重，不做任何 fine-tuning。两个关键设置：(1) [[ICL]]——给模型与 fine-tuned policy 相同数量的训练集示例作为 in-context prompt；(2) 扩展执行步数——允许更多次尝试纠错。还探索了 GPT-6-Astra（高层 System 2）+ [[π0.5]]（低层 System 1）的 agentic harness 架构。
- **对比方法/Baselines**: 基准涵盖 LIBERO、RoboDojo、BEHAVIOR（家务）、RxR（VLN 导航）、DexJoCo（灵巧手）；对比 baseline 是各 benchmark 的专用 fine-tuned policy；层级架构部分对比了 π0.5 standalone 和 GPT-6-Astra standalone。
- **借鉴意义**: 给做 embodied AI 的人提供了一个强 zero-shot baseline 的上界参考。ICL from demo 如果真的 work，意味着通用 VLM 的 embodied 能力已到临界点。"System 2 + System 1"层级架构是个值得认真看的设计方向。作者提出的下一代 benchmark（真实任务来源 + 零 in-domain demo + 世界时钟计时）也值得关注。
- **锐评**: 473 赞，圈内讨论最多，因为问题直接——GPT-6 能打败专用 robot policy 吗？答案是：某些 benchmark 上能，但 real-world 部署还有严重缺口（robot demo 采集成本高、执行时间长、物理约束下无法以量换质）。最有价值的是 gap 分析本身：benchmark 过 ≠ practical intelligence。但有个公平性问题：ICL 用了和 fine-tuning 相同数量的 demo，这个对比条件给了 GPT-6 相当大的信息优势，结论的泛化性需要审慎。 🔥
- **关联笔记**: [[GPT-6-Astra 再推]] 第一次推荐是 10-20，有进一步讨论可参考

### 4. F2G-Pose: Geometry-Aware Foundation Feature Lifting for Direct RGB-D Category-Level Object Pose Estimation
- **作者**: Jinyu Zhang, Haitao Lin, Jiashu Hou, Xiangyang Xue, Yanwei Fu
- **机构**: Fudan University
- **链接**: [arXiv](https://arxiv.org/abs/2610.31623) | [PDF](https://arxiv.org/pdf/2610.31623)
- **来源**: 🔥 HF Trending，⬆️ 11

![](https://arxiv.org/html/2610.31623v1/pipeline.png)

- **核心方法**: 单次前向直接预测类别级 6D 位姿 + 尺寸 + 相机空间完整形状，输入是单帧 RGB-D。核心是把 frozen [[RADIO]] 提取的密集视觉特征"提升"（lift）到稀疏点云上，用 [[DGCNN]] 编码局部几何，再过 Mixture-of-Experts Transformer 整合全局结构。联合形状补全强制几何一致性监督。不需要 CAD 模型，不需要参考视图，28 FPS 实时推理。
- **对比方法/Baselines**: 在 SOPE 和 ROPE 数据集上对比 [[FoundationPose]]、[[GenPose++]]、[[RegDiff]]、[[AdaPoinTr]]；借鉴了 NOCS 的 canonical space 思路；骨干用 frozen RADIO（外部预训练，不更新权重）。
- **借鉴意义**: 对做 manipulation 的人很实用——类别级位姿估计不依赖 CAD 模型且实时，可以直接接入机器人控制循环。foundation feature + 几何编码的特征提升思路可以迁移到其他需要几何感知的任务。
- **锐评**: 只有 11 个 upvotes 说明还没破圈，但技术含量实打实。单次前向 + 无 CAD + 28 FPS 三合一，在 manipulation pipeline 里是硬刚需。`has_real_world` 字段抓到是 False，但摘要明确说有 real-world manipulation experiments——这是富化脚本的误判，摘要可信。MoE 的实际加速比摘要没说清楚；类别泛化能力受限于 SOPE/ROPE 训练分布，out-of-distribution 类别表现未知，需要看正文。 👀

- **机构**: Southern University of Science and Technology

> ⏪ **再推提醒**：这篇在 2026-10-17 推荐过

- **核心方法**: Instant + AutoThink 双模式：Instant 用双向 attention 单次推理；AutoThink 在置信度低时触发显式推理链（按需 chain-of-thought）。三阶段训练：基础 decision 能力 → 任务适应 → RL 强化推理监督（DecisionPivot）。

- **锐评**: "AutoThink"这名字就透着营销感。双向 attention 是老技巧，按置信度触发推理链也不算新。VLN 和 BEHAVIOR 放进评估更像是贴 embodied 标签，不是这篇的核心。81 upvotes 来自推出时的热度，现在三推没有新增价值。 🫠
