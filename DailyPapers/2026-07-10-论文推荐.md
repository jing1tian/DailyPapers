### 1. HiMoE-VLA: Hierarchical Mixture-of-Experts for Generalist Vision-Language-Action Policies
- **作者**: Zhiying Du 等
- **机构**: Fudan University, Microsoft Research Asia, Xi'an Jiaotong University, Tsinghua University
- **链接**: [arXiv](https://arxiv.org/abs/2512.05693) | [PDF](https://arxiv.org/pdf/2512.05693)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [[HiMoE-VLA]]

![](https://arxiv.org/html/2512.05693v2/x1.png)

- **核心方法**: 针对跨 embodiment 异构数据导致的负迁移问题，HiMoE-VLA 用分层 MoE 替换传统的 dense action 模块。架构分三层：边界用 Action-Space MoE（AS-MoE）层专门处理不同动作空间的输入/输出；邻近层用 Heterogeneity-Balancing MoE（HB-MoE）吸收 observation/scene/embodiment 的剩余差异；中间层是 dense Transformer 做共享表征。额外加了两个 auxiliary objective：对比性的 Action-Space Regularization 确保边界专家真正分化，load-balancing loss 稳定专家利用率。输入是多模态观察+语言指令，输出是机器人动作。
- **对比方法/Baselines**: 对比了 [[OpenVLA]]、[[RT-2]]、[[π0.md]]（借鉴/基础），以及在 [[CALVIN]] 和 [[LIBERO]] 上与当前 SOTA 比较
- **借鉴意义**: 如果你在做跨 embodiment 的泛化训练，HiMoE 的分层 MoE 设计给了一个可以直接借用的思路，尤其是 AS-MoE 的边界分层这个 idea 很干净
- **锐评**: CALVIN 3.98、LIBERO 98.0%，数字是今天最硬的。思路也对——用 MoE 做异构对齐比暴力混训合理。硬伤是实验主要在仿真 benchmark 上，没有跨具身真机实验，不知道 AS-MoE 对真实的异构数据集（如混合 DROID+Bridge+OXE）效果如何。另外 2512 的版本 ID 说明这篇 12 月就挂了，今天才被检索到，说明不是今天的 fresh work，注意时间。 🔥

### 2. WAM-TTT: Steering World-Action Models by Watching Human Play at Test Time
- **作者**: Yusen Feng 等
- **机构**: Peking University, Galbot, CASIA, Tsinghua University
- **链接**: [arXiv](https://arxiv.org/abs/2607.06988) | [PDF](https://arxiv.org/pdf/2607.06988)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.06988v1/x1.png)

- **核心方法**: 不用额外机器人 demo，WAM-TTT 在测试时从人类玩游戏/演示的原始视频中调向 World-Action Model（WAM）。核心是把人类视频当 self-supervised video prediction 任务——用视频预测 loss 更新 WAM 内部一个轻量的 adaptive memory（frozen base model 不动）。推理时用这个更新后的 memory 条件化动作生成。本质上是把 [[MANO]] 之类的人体动作先验注入 WAM，而不是直接做 trajectory imitation。
- **对比方法/Baselines**: 基于的框架是 World-Action Model（WAM），对比了直接 fine-tuning 和 ICL（In-Context Learning）方案
- **借鉴意义**: 测试时自适应 + 不需要机器人 demo 这个方向非常实用。如果你有 WAM 或类似的 video prediction 基础模型，这套 test-time adaptation 框架可以直接迁移
- **锐评**: 想法很对——人类视频数量远超机器人 demo，测试时不需要额外标注是大优点。问题是 adaptive memory 的容量和泛化范围没有理论保证，如果任务分布和人类视频差太多效果存疑。另外 `VLM`、`ICL` 在方法名列表里排得很靠前，说明依赖 VLM 理解的程度不低，对 domain gap 敏感。摘要没提具体任务成功率数字，有必要看正文。 👀
- 💡 **想精读？** 运行：`读一下 WAM-TTT: Steering World-Action Models by Watching Human Play at Test Time`

### 3. Dual Latent Memory in Vision-Language-Action Models for Robotic Manipulation
- **作者**: Hongyu Qu 等
- **机构**: Nanjing University of Science and Technology, National University of Singapore
- **链接**: [arXiv](https://arxiv.org/abs/2607.07608) | [PDF](https://arxiv.org/pdf/2607.07608)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.07608v1/figs/motivation.png)

- **核心方法**: 现有 VLA 做记忆增强要么扩 observation window，要么用 external memory bank 做 retrieval，共同问题是历史信息在 VLA 原生 latent 空间之外。LaMem 把 dual memory 做进 VLA latent：一个 episodic memory 捕捉跨步骤的历史 token，一个 semantic memory 捕捉指令级别的语义依赖，两路 memory 通过 cross-attention 与当前 VLM token 深度交织，不是简单拼接。输入是观察+历史，输出是动作 token。
- **对比方法/Baselines**: 在 [[SimplerEnv]] 和 [[LIBERO-90]] 上对比了原始 VLA baseline
- **借鉴意义**: 如果在做长程操作任务（需要记住前几步做了什么），这篇的 dual-memory 接入 latent 空间的设计比 RAG 式的外挂 memory 要更 principled
- **锐评**: 问题提得对，memory in latent space 比外挂 bank 更优雅。但 `LIBERO-90` 这个 benchmark 任务相对短，不确定真正长程任务（30+ 步）上效果如何。has_real_world=True，有真机实验是加分项。摘要中 claim 了"fluid interleaving"，但 cross-attention 做多少层、memory 容量多大都没在摘要里说，细节需要看正文。 👀
- 💡 **想精读？** 运行：`读一下 Dual Latent Memory in Vision-Language-Action Models for Robotic Manipulation`

### 4. Pelican-VLA 0.5: Attending Before Acting Benefits Generalization
- **作者**: Beijing Innovation Center of Humanoid Robotics (X-Humanoid)
- **机构**: X-Humanoid (北京人形机器人创新中心)
- **链接**: [arXiv](https://arxiv.org/abs/2607.06655) | [PDF](https://arxiv.org/pdf/2607.06655)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.06655v2/x1.png)

- **核心方法**: Pelican-VLA 0.5 把 vision-language understanding、future-frame generation 和 action prediction 做进一个统一架构。关键发现是：action pathway 在没有任何 attention 监督、无标注的情况下，会自动关注指令相关的物体和接触区域（attention-level generalization）。这个特性在 unseen scenes 和 unseen embodiments 上都保持。用 [[MoT]]（Mixture of Tokens）风格做 [[BotTokens]] 的路由。评估在 [[RoboTwin]] benchmark 和 TienKung 人形机上做了真机实验。
- **对比方法/Baselines**: 与当前 SOTA VLA 在 RoboTwin 和 LIBERO 上对比
- **借鉴意义**: "先注意再动作"的涌现现象如果可复现，说明大模型 VLA 的 attention 机制本身就有一定程度的语义 grounding，不需要额外的 affordance 标注。这对数据效率有重要意义。
- **锐评**: 最有意思的 claim 是"attention-level generalization is emergent"，但这种现象是否真的来自 future-frame generation 的加持，还是 VLM backbone 本来就有，目前摘要没有 ablation 支撑。TienKung 人形真机实验加分。版本 v2 说明已经改过一轮，相对成熟。 👀
- 💡 **想精读？** 运行：`读一下 Pelican-VLA 0.5: Attending Before Acting Benefits Generalization`

### 5. NativeMEM: Native Memory Compression for Long-Horizon Robotic Manipulation
- **作者**: Ziye Wang 等
- **机构**: The University of Hong Kong, The Chinese University of Hong Kong, Horizon Robotics
- **链接**: [arXiv](https://arxiv.org/abs/2607.06678) | [PDF](https://arxiv.org/pdf/2607.06678)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.06678v1/x1.png)

- **核心方法**: NativeMEM 在 VLA 内部原生做记忆压缩，核心是 Native Memory Compression（NMC）：复用 VLA 自身的 attention 机制来动态压缩历史 visual token，而不是依赖外部 memory manager。这样历史可以高频更新同时保持效率。输入是当前观察+压缩后的历史序列，输出是动作。与 [[HAMLET]] 等方案不同，NativeMEM 不需要单独的 memory module，完全在 pretrained VLA 的结构内操作。
- **对比方法/Baselines**: 与 [[OpenVLA]]、[[π0.md]]、HAMLET 等对比
- **借鉴意义**: 长程操作（洗碗、做饭等多步骤任务）的关键问题就是 context 管理，NMC 这个"借 VLA 自己的 attention 做压缩"的思路有一定的工程价值
- **锐评**: has_real_world=True，有真机实验。"Native"这个词用得妙——强调不引入额外模块。但"复用 VLA 自身 attention 做压缩"具体是什么操作（pooling？gating？pruning？）摘要没说清楚，有点卖关子。效率数字（多少 token 减多少延迟）也没在摘要里给，需要看正文才能判断实用价值。 👀
- 💡 **想精读？** 运行：`读一下 NativeMEM: Native Memory Compression for Long-Horizon Robotic Manipulation`

### 6. VOTE: Vision-Language-Action Optimization with Trajectory Ensemble Voting
- **作者**: Juyi Lin, Amir Taherin, Arash Akbari, Arman Akbari, Lei Lu, Guangyu Chen, Taskin 等
- **机构**: EmbodyX (San Mateo), Northeastern University
- **链接**: [arXiv](https://arxiv.org/abs/2507.05116) | [PDF](https://arxiv.org/pdf/2507.05116)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2507.05116v5/x1.png)

- **核心方法**: 两个问题：VLA 推理时生成太多 token 导致延迟高；生成的 action token 利用率不足。VOTE 的解法是 training framework：先 finetune VLA 生成更精简的轨迹 token 集合，再用 Trajectory Ensemble Voting（多条候选轨迹投票选最优）来提升鲁棒性。基于 [[OpenVLA]] 和 [[SpatialVLA]] fine-tune。
- **对比方法/Baselines**: 对比 [[ACT]]、[[OpenVLA]]、[[SpatialVLA]] 等
- **借鉴意义**: Token 减少+集成投票是个工程优化思路，如果你在部署 VLA 并且推理速度是瓶颈，可以参考
- **锐评**: 版本已经到 v5，说明改了很多轮，本身是个信号——这种工程优化论文很难找到干净的 story。核心贡献是"集成投票提升鲁棒性"，但 ensemble 本来就慢，和"减少 token"的目标有点打架，没看到具体效率数字对比。has_real_world=False，全仿真实验。整体是个 incremental 的工程 trick，不是思路突破。 ⚠️

### 7. GeoProp: Grounding Robot State in Vision for Generalist Manipulation
- **作者**: Guoyang Zhao 等
- **机构**: Tongji University, DAMO Academy, Alibaba Group, Nanyang Technological University
- **链接**: [arXiv](https://arxiv.org/abs/2607.07101) | [PDF](https://arxiv.org/pdf/2607.07101)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.07101v1/resource_figure/heatmap1.png)

- **核心方法**: Proprioception 和 visual token 没有显式对齐，导致很多 manipulation policy 甚至不如 vision-only baseline。GeoProp 是一个 plug-and-play adapter，通过 explicit geometric projection（把 3D kinematics 投影到 2D feature map）实现本体感觉与视觉的空间对齐。输入是 visual token + proprioceptive state，adapter 输出对齐后的 joint representation。用 [[FiLM]] 风格做条件化，在 [[RoboTwin]] 和 [[MetaWorld]] 上验证。
- **对比方法/Baselines**: 与 vision-only baseline、naive fusion 方案、以及其他 proprioception 融合方法对比
- **借鉴意义**: 如果你发现你的 VLA 本体感觉信息没用好（比如用了 proprio 反而不如不用），这篇给了一个可能的原因和解法
- **锐评**: 问题诊断是对的——"vision-only sometimes beats vision+proprioception"这个现象确实存在且值得研究。但 plug-and-play adapter 贡献量级偏小，本质是一个 feature alignment 的小技巧。has_real_world=True，但 MetaWorld 是仿真环境，不算真机。score 只有 2，不算关键词强 match。 ⚠️

### 12. The Rank-One Corner: How Much Value Equivalence Does a Task Need from a World Model?
- **作者**: Donna Vakalis
- **机构**: Mila – Quebec AI Institute
- **链接**: [arXiv](https://arxiv.org/abs/2607.06640) | [PDF](https://arxiv.org/pdf/2607.06640)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.06640v1/x1.png)

- **核心方法**: 从理论角度问：一个任务到底需要世界模型学到多少东西？提出 closure 概念——任务实际依赖的最小预测坐标集合。理论发现：latent 学到多少 closure，不取决于模型容量或观察质量，而取决于训练 objective 的维数。通过对 [[DreamerV3]] 的 [[RSSM]] latent 做线性探测，量化 value equivalence 与任务性能的关系。
- **对比方法/Baselines**: 用 DreamerV3 做实验平台，与 reconstruction objective 变体对比
- **借鉴意义**: 对做 world model 的人有一个清醒剂作用——不是模型越大越好，任务匹配性（closure 覆盖）更关键。对 loss function 设计有理论指导价值。
- **锐评**: Mila 单作者理论论文，结论 surprising 且反直觉（"维数决定 value equivalence"而非容量）。但目前只在 DreamerV3 上验证，是否能泛化到其他 world model 架构（尤其是 diffusion-based WM）没有给出。对工程实践影响有限，但理论层面值得一读。 👀
- 💡 **想精读？** 运行：`读一下 The Rank-One Corner: How Much Value Equivalence Does a Task Need from a World Model?`

### 17. TouchWorld: A Predictive and Reactive Tactile Foundation Model for Dexterous Manipulation
- **作者**: Jianyi Zhou, Feiyang Hong, Yunhao Li 等
