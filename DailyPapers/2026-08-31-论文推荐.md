### 7. On-Policy Self-Distillation in Diffusion Models
- **作者**: Wei Zhou, Xiongwei Zhu, Lingdong Kong, Bo Chen, Lei Zhang, Yongyuan Liang 等
- **机构**: 未知（affiliations 字段空白）
- **链接**: [arXiv](https://arxiv.org/abs/2608.24646) | [PDF](https://arxiv.org/pdf/2608.24646)
- **来源**: 🔥 HF Trending，⬆️ 66
- 📒 **笔记**: [[DiffusionOPSD]]

> ⏪ **再推提醒**：这篇在 2026-08-27 推荐过

- **核心方法**: 核心问题是：RL 可以用 endpoint reward 优化扩散模型，但中间去噪步骤该怎么引导？论文提出 On-Policy Self-Distillation（OPSD），让扩散模型在推理时生成 on-policy 轨迹，然后用"好轨迹"对"差轨迹"做蒸馏监督，把过程监督信号注入中间步骤。输入是当前策略的去噪轨迹分布，输出是经过 self-distillation 细化后的更对齐策略。核心区别在于不需要预训练的 value function 或 process reward model——自己给自己打分
- **对比方法/Baselines**: 与 [[DDIM]]、[[DPO]] for diffusion、[[RLHF]] 标准 endpoint reward 方法对比。借鉴了 [[Diffusion Forcing]] 的轨迹建模思路
- **借鉴意义**: 对做 diffusion policy 的人相关性很高。如果你在用 RL fine-tune diffusion policy 但发现 endpoint reward 信号稀疏导致训练不稳定，这篇提供了一个 process-level 的替代思路。需要看全文确认是否在 robotics benchmark 上有实验
- **锐评**: 方法思路清晰，self-distillation 作为过程监督信号是个有意思的方向。但 method_names 只提取到 TeX/CSS（富化数据质量受限），说明无法从 HTML 层面确认实验细节。摘要表明 `has_real_world=False`，没有真实机器人实验——纯图像生成对齐场景下的验证，能否迁移到连续动作空间的 diffusion policy 需要另说。claim 能不能成立要看全文的 ablation。⚠️
- **关联笔记**: 与 [[Diffusion Forcing]]、[[DDIM]] 概念相关；如果在用 diffusion policy 做 RL，与 VLA 方向直接关联

### 8. Faster Video Diffusion with Trainable Sparse Attention
- **作者**: Peiyuan Zhang, Yongqi Chen, Haofeng Huang, Will Lin, Zhengzhong Liu, Ion Stoica 等
- **机构**: UC Berkeley, MBZUAI
- **链接**: [arXiv](https://arxiv.org/abs/2505.13389) | [PDF](https://arxiv.org/pdf/2505.13389)
- **来源**: 🔥 HF Trending，⬆️ 38

![](https://arxiv.org/html/2505.13389v5/method-1.png)

- **核心方法**: VSA（Video Sparse Attention）针对视频 DiT 的 3D 注意力瓶颈。输入是视频 token 序列，输出是加速后的注意力计算，同时保持质量。核心设计是分层稀疏注意力：粗粒度层用大 tile 捕捉全局结构，细粒度层用小 tile 精确还原局部细节，通过 [[FlashAttention]] 优化实现 CUDA 级别加速。与 [[MoBA]]、[[NSA]]、[[BiFormer]] 的区别在于 VSA 是可训练的——稀疏模式从数据中学习，而不是手工设计
- **对比方法/Baselines**: 对比了 [[MoBA]]、[[NSA]]（原生稀疏注意力）、[[BiFormer]]; 基于 [[DiT]] 架构；FLOPS 和 MFU 指标与 [[FlashAttention]] 基线对比
- **借鉴意义**: 如果你在用视频 DiT 生成机器人演示数据或 world model rollout，这篇可以直接降低推理成本。对 diffusion-based world model 训练速度有实质性帮助
- **锐评**: Berkeley + MBZUAI 出品，有具体 FLOPS 数字和 MFU 指标，不是画饼。可训练稀疏 vs 固定稀疏的设计选择是合理的——模型自己学哪些 token 重要比手工设计更鲁棒。但 `has_real_world=False`，全在合成视频上验证，迁移到真实视频 DiT 的表现需要确认。title "Faster" 有点普通，不过内容看起来是货真价实的工程加速。👀
- **关联笔记**: 与 [[FlashAttention]]、[[DiT]] 概念相关

- **核心方法**: 4DAnyone 从单目视频重建动态 4D 人体。输入是无标定单目视频，输出是时序一致的多视角视频，再通过 4D Gaussian Splatting 提升为可渲染的 4D 表示。流程分两阶段：先用 [[SMPL]] + [[HMR]] 做人体姿态估计获得 3D 先验，再用 [[ReCamMaster]] / [[CameraCtrl]] 做多视角一致性生成，最后用 [[GVHMR]] + DNA 做 Gaussian lifting。与直接回归 3D 的方法相比，4DAnyone 绕开了需要多视角输入的限制

- **关联笔记**: 与 [[3D Gaussian Splatting]]、[[CameraCtrl]] 概念相关
