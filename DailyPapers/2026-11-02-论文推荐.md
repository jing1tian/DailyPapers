## World Model

### 1. Hy-Nomas: Towards Free-form Interactive World Generation

- **作者**: Tencent Hy Visual Generation Team
- **机构**: 腾讯混元视觉生成团队
- **链接**: [arXiv](https://arxiv.org/abs/2610.36729) | [PDF](https://arxiv.org/pdf/2610.36729)
- **来源**: 🔥 HF Trending，⬆️ 122
- 📒 **笔记**: [[HyNomas]]

> ⏪ **再推提醒**：这篇在 2026-10-29 推荐过

![](https://arxiv.org/html/2610.36729v1/teaser.png)

- **核心方法**: 输入是当前帧 + 文本指令 + 历史 KV cache，输出是连续视频片段。最核心的设计是 **segment-wise causal attention**：视频流切成 segment，描述性 context caption 全局可见，action 指令只能影响其所属 temporal window——解决的是"旧指令污染当前生成"这个多轮 world model 的核心痛点。另有一个 **Prompt Enhancer (PE)** 模块，把用户的自然语言请求和多模态历史翻译成结构化条件。训练走多阶段 curriculum：causal generation → text interaction → camera control → model-generated history，最后 diffusion distillation 提速推理。
- **对比方法/Baselines**: 基于 [[HunyuanVideo]] 8B 作为主干；用自建 Hy-Nomas-Bench 与其他 world models 做 human evaluation 对比（具体对手名称摘要未给出）；downstream adaptation 通过 [[LoRA]] 支持轻量迁移；训练基础设施依赖 PyTorch 分布式 + KV cache 优化。
- **借鉴意义**: causal attention 里 action/context 分离这个设计，对做多轮 robot world model 的人可以直接借鉴——保留任务上下文的同时限制动作指令的时序影响范围，是真实部署场景里的关键工程问题。PE 的设计思路同理。
- **锐评**: 122 upvotes、腾讯出品、8B 参数，纸面够硬。action/context 分离的 causal attention 是本文最有价值的技术点——这个问题在很多 video world model 里是被忽略的，这篇明确建模了。不过有几个疑点：(1) 评估全在自建 Hy-Nomas-Bench 上，没有在 GAIA-2 或其他公开 world model benchmark 上跑，可复现性和独立验证存疑；(2) `has_real_world = false`，纯视频生成场景，没有 robot deployment 实验，离真正的机器人 world model 还差那么一步；(3) diffusion distillation 的加速倍率未见量化数据。有真东西，但评估范围偏窄。🔥
- **关联笔记**: [[HunyuanVideo]] — 本文 backbone 来源；[[LingBot-Video]] — 腾讯系同类 video world model，值得横向对比；[[DreamerV3]] — world model 方向经典参照

## Embodied AI

### 2. InteractiveWorld: A Verifiable Human-Centric Environment for Building Better Interactive MLLM Assistants

- **作者**: Qinsi Wang, Wei Wen, Chong Zhou, Saksham Suri, Zechun Liu, Lemeng Wu, Hai Helen Li, Yiran Chen, Raghuraman Krishnamoorthi, Qi Qian
- **机构**: Duke University；Meta（实习期间完成）
- **链接**: [arXiv](https://arxiv.org/abs/2610.33966) | [PDF](https://arxiv.org/pdf/2610.33966)
- **来源**: 🔥 HF Trending，⬆️ 56

> ⏪ **再推提醒**：这篇在 2026-10-31 推荐过

![](https://arxiv.org/html/2610.33966v1/main_fig1.png)

- **核心方法**: 输入是人类第一人称（egocentric）视频流，输出是 AI 给人类的下一步自然语言指令。核心架构是三层模拟器：物理层（基于 ManiSkill3，执行 human action）+ 人类行为层（human agent 独立理解并执行指令）+ 语义层（场景状态更新）。AI assistant 只负责出指令，human agent 自行解读并行动——测的是 AI 作为"教练"的能力，与 robot-centric simulator 有本质区别。InteractiveBench 包含 120 个多轮任务，6 类（Guidance、Planning、Accessibility 等），用 state-based verifiable reward 评分。
- **对比方法/Baselines**: 评估了 12 个 frontier MLLM，包括 GPT-5、DeepSeek、GLM-5 等；物理层基于 [[ManiSkill3]] 构建；和 BEHAVIOR 等 robot-centric benchmark 在设计哲学上形成对比。ablation study 包含 memory augmentation 实验。
- **借鉴意义**: 对做 embodied AI 的人，这篇提供了一个新的评估视角——把 AI 从"执行者"变成"指导者"，对应 AR 眼镜、wearable assistant 等真实应用场景。benchmark 本身可以作为 MLLM 在具身场景下的辅助评估工具。但如果你主要做机器人策略学习，与你的直接工作距离较远。
- **锐评**: "让 AI 教人"而不是"让 AI 做事"是个真实的应用场景（AR 眼镜导航、手术辅助），这个角度切得比较新。state-based verifiable reward 比 LLM-as-judge 可信得多。但几个问题：(1) human agent 的行为模型到底有多真实——固定规则的 agent 和真实用户的 gap 在论文里没有深入讨论，benchmark validity 存疑；(2) 最强模型 25% 这个数字是"模型太烂"还是"benchmark 太难"，摘要没有提供足够的细分分析来区分；(3) 说 MLLM 还差得远这个结论本身不令人意外，这篇的价值更多在于提供了一个可验证的平台而非技术突破。思路硬，工程扎实，但圈子比较窄。👀
