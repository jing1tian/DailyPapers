### 1. FibVLA: An Efficient Temporal Vision-Language-Action Model with Fibonacci Sampling

- **作者**: Li Lin, Wujun Xu, Weiwei Meng, Kaiwen Xia, Kang Hao Cheong, Shuai Wang
- **机构**: 未知（arxiv仅显示个人邮箱）
- **链接**: [arXiv](https://arxiv.org/abs/2607.29596) | [PDF](https://arxiv.org/pdf/2607.29596)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [[FibVLA]]

![](https://arxiv.org/html/2607.29596v1/x1.png)

- **核心方法**: FibVLA 解决"VLA 缺乏时序上下文"这个老问题，提出三个组件：① **Logarithmic Hindsight Sampling**——用斐波那契数列间隔采样历史帧（1, 1, 2, 3, 5, 8…步之前），以 O(logN) 帧覆盖指数增长的历史视野；② **Channel-wise Temporal Encoding Module**——在 channel 维度融合多帧特征而非简单拼接，避免 token 数爆炸；③ **Fibonacci Recurrent Inference**——推理时复用前序计算，降低延迟。输入是多帧 RGB 观察序列，输出是 action token。
- **对比方法/Baselines**: 对比了 [[OpenVLA]]、[[TraceVLA]]、[[RT-1]]、[[CogACT]]、[[SpatialVLA]] 在 [[LIBERO]] 和 [[SimplerEnv]] 上的结果；真实机器人用 [[WidowX]]。
- **借鉴意义**: 斐波那契采样的思路可以直接移植到任何需要长时序历史的 VLA 或 WAM 框架里，开销极小。
- **锐评**: 斐波那契间隔采样是这篇最聪明的地方——它用数学上已知最优的增长率做到了"看得远但不贵"。相比直接用 sliding window 或 fixed-rate downsampling，理论上确实更合理。有 WidowX 真实实验撑腰，不是只靠仿真水分。但有一个问题需要验证：斐波那契采样天然偏向"远处"历史，而很多精细操作任务其实需要最近几帧的高密度信息——这个偏置会不会在接触丰富任务上反而是劣势，文章没有深入分析。另外机构信息缺失，不确定是哪个组的工作。🔥
- 💡 **想精读？** 运行：`读一下 FibVLA: An Efficient Temporal Vision-Language-Action Model with Fibonacci Sampling`

### 2. WCM: A World Critic Model for Vision-Language-Action Reinforcement Learning

- **作者**: Senyu Fei, Xiaopeng Yu, Siyin Wang, Xianzhong Zhao, Jingjing Gong, Xi (等)
- **机构**: Tongji University, Shanghai Innovation Institute, Fudan University
- **链接**: [arXiv](https://arxiv.org/abs/2607.29613) | [PDF](https://arxiv.org/pdf/2607.29613)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [[WCM]]

![](https://arxiv.org/html/2607.29613v1/x1.png)

- **核心方法**: VLA-RL 最大的痛点是 critic 只看单帧，给不出精准的时序价值估计。WCM 用一个世界模型来做 critic：给定当前 observation 和 action，先用 WM rollout 未来 trajectory，再在 rollout 上估值。关键区别是 critic 在 **trajectory 空间** 而非 **single-frame 空间** 打分，缓解了 VLA 中动作效果延迟的信用分配问题（credit assignment problem）。训练时用 [[PPO]]/[[AWR]] 框架，测在 [[LIBERO]]、[[ManiSkill]]、[[MetaWorld]]、[[CALVIN]] 四个 benchmark 上，有真机实验。
- **对比方法/Baselines**: 对比 [[OpenVLA-OFT]]、[[RECAP]] 等 VLA-RL baseline；借鉴 [[POMDP]] 框架建模部分可观测状态。
- **借鉴意义**: 对做 VLA-RL 的人来说这篇是必读——单帧 critic 的缺陷是公认的，这篇给了一个可操作的解法。可以直接 plug 进已有的 VLA-RL pipeline。
- **锐评**: 这篇击中了一个真实痛点：现有 VLA-RL 的 critic 在处理接触密集任务时的信用分配确实很烂，因为接触是滞后事件而价值必须即时估计。用 WM rollout 来"往前看再打分"的逻辑是正确的。但代价是推理时要运行一个 WM，latency 怎么解决？训练时 WM rollout 误差会累积，对长 horizon 效果如何？论文在四个 benchmark 都做了实验，覆盖面够广，不是单一数据集刷分。主要缺点是 WM 本身的质量上限会变成整个系统的上限。🔥
- 💡 **想精读？** 运行：`读一下 WCM: A World Critic Model for Vision-Language-Action Reinforcement Learning`

### 3. ActFovea: Runtime Safeguarding for VLA Policies via Spatiotemporal Visual-Action Consistency

- **机构**: 未知（arxiv 无完整机构信息）

![](https://arxiv.org/html/2607.29169v1/x1.png)

- **核心方法**: 针对 VLA 在运行时遭受干扰（物体移动、光照变化、遮挡）后产生的"SilentDrift"问题——策略还在执行旧 action 但观察已经改变。ActFovea 在推理阶段检测 spatiotemporal 一致性：用 visual consistency（当前帧与预期帧的差异）和 action consistency（当前 action 与历史的合理性）两个信号共同触发保护机制（暂停/重规划）。Plug-and-play，不需要重新训练 VLA。测在 [[LIBERO]] 上。
- **对比方法/Baselines**: 对比 [[FreezeVLA]]、[[AttackVLA]]、[[SafeVLA]] 等 VLA 安全/鲁棒性方法。
- **借鉴意义**: 对部署 VLA 到真实环境的人来说，一个免训练的 runtime 保护层是有价值的工程工具。
- **锐评**: 方向是对的，"检测 drift 然后保护"的逻辑直觉上合理。但这篇最大的问题是没有真实机器人实验——所有评估都在 LIBERO 仿真里，而 LIBERO 本身干扰类型比较有限。SilentDrift 这个问题在真实部署中才会真正暴露，仿真里评估多少有点隔靴搔痒。两个一致性信号的阈值怎么设定、对不同任务有没有需要调参？也没说清楚。⚠️

### 4. Safe Vision Language Action Models via Barrier Enhanced Flow Matching

- **作者**: Kasra Sinaei, Hung-Chieh Wu, Donald Ebeigbe
- **机构**: Department of Electrical Engineering, The Pennsylvania State University
- **链接**: [arXiv](https://arxiv.org/abs/2607.29569) | [PDF](https://arxiv.org/pdf/2607.29569)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.29569v1/x1.png)

- **核心方法**: 将 [[Control Barrier Function (CBF)]] 形式安全约束直接嵌入 [[Flow Matching]] 的去噪过程：在 FM 生成 action 的每一步 ODE 积分中，加入 CBF 梯度修正，把安全集约束编码为 vector field 的软约束，而非在输出端加 hard filter。基础 VLA 用 [[SmolVLA]]，机器人平台 SO-101（6-DoF 桌面机械臂）。
- **对比方法/Baselines**: 暂不清楚具体对比的方法（方法名列表里没有明确 baseline 的名字，摘要未提），需看全文确认。
- **借鉴意义**: CBF+FM 的组合给"diffusion policy 的安全问题"提供了一个理论扎实的框架，Penn State 电气系的出发点更偏控制理论，跟 ML 社区视角互补。
- **锐评**: 把 CBF 嵌进 FM 的 ODE solver 这个想法在控制理论上是正确的，比事后加 filter 优雅得多。但这类方法有一个已知的实际问题：CBF 的 safety set 定义依赖精确的状态信息（关节位置、碰撞几何），在高自由度灵巧操作中不好构建。真实实验只在 SO-101 上做了，覆盖范围有限。另外 SmolVLA 本身表现一般，用它来验证安全增益说服力不足。⚠️

### 7. FBFM: A Training-Free Asynchronous Feedback Mechanism for Flow-Matching in World-Action Models Execution

- **作者**: Li Peize, Zhang Ruimeng, Zhang Ru, Huang Cong, Chen Kai, Zhang Shanghang
- **机构**: 未知（enrichment 未提取到机构信息）
- **链接**: [arXiv](https://arxiv.org/abs/2607.29235) | [PDF](https://arxiv.org/pdf/2607.29235)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [[FBFM]]

![](https://arxiv.org/html/2607.29235v1/material/serial.png)

- **核心方法**: WAM（World Action Model）长 horizon 执行时依赖 recursive rollout，误差会累积。FBFM 加入异步反馈：在 WAM 执行过程中，对比 GT 真实观察与 WAM 预测观察，发现偏差后触发 reground（用真实帧覆盖 KV cache）——但这个 reground 是异步的，不打断正在运行的 FM inference，避免 latency spike。Training-free。在 [[LIBERO]]、[[RoboTwin2]] 和真实机器人测试。
- **对比方法/Baselines**: 对比 [[DreamZero]]、[[LingBot]] 等 WAM；借鉴 [[UniPC]] 做 FM 加速。
- **借鉴意义**: 对用 WAM 做机器人控制的人非常实用——不需要改模型，加一个反馈机制就能显著提升长 horizon 可靠性。

### 10. Temporal Policy: History-Initialized Action Generation for Robotic Learning from Demonstration

- **作者**: Dylan Miller（单作者）
- **机构**: University of Alberta, Canada
- **链接**: [arXiv](https://arxiv.org/abs/2607.29482) | [PDF](https://arxiv.org/pdf/2607.29482)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.29482v1/x1.png)

- **核心方法**: 标准 [[Flow Matching]] 从高斯噪声出发生成 action，ODE 路径复杂。Temporal Policy 改用"上一时刻 action 序列"来初始化流——耦合输运代替独立采样，前一时刻的 action chunk 作为当前时刻的起点，缩短了 ODE 积分路径，减少 NFE。引用 [[ManiFlow]] 为先驱。有真机实验（WAM 机械臂）。
- **对比方法/Baselines**: 对比标准 [[CFM]]（Conditional Flow Matching）、[[Diffusion Policy]]；借鉴 [[Vanden-Eijnden]] 的 coupled transport 理论。
- **借鉴意义**: 如果时序耦合初始化确实减少 NFE，对实时机器人控制很有价值。思路与 [[DiffusionForcing]] 中的 causal masking 有一定相通之处。
- **锐评**: 单作者 Alberta 小论文，但想法扎实。用历史 action 初始化 FM 是个有理论依据的设计——coupled transport 确实更高效。需要确认的是：这个方法对 action multimodality 的处理怎样？如果任务发生模态切换（比如抓不同方向的物体），从上一时刻 action 初始化反而会引入错误的先验。真机实验只有 WAM 机械臂，任务种类不多。🫠

- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.29622v1/figure_and_table/ray_vit_no_blank.png)

- **核心方法**: 标准 [[ViT]] encoder 对相机视角变化脆弱，因为 patch embedding 没有几何信息。RayViT 在每个 patch 的 positional embedding 里加入对应的相机光线方向（ray direction），用 [[RoPE]] 做 ray-aware position encoding，让 encoder 感知"这个 patch 是从哪个视角看的"。在 [[RoboCasa]] 上测了 10 个任务（包括真机实验），对比 [[CamPose]]、标准 ViT。
- **对比方法/Baselines**: [[CamPose]]、标准 [[ViT]]、[[PMP]]（Pre-trained Multi-camera Policy）。
- **借鉴意义**: 对做多相机 VLA 或多视角策略学习的人实用——轻量（只改 positional encoding），不需要改整体架构，可以直接 plug 进 OpenVLA/Pi0 类型的 VLA。
- **锐评**: 轻量、有理论动机、有真机实验——三个加分项都有。Ray-conditioning 的想法不算新（NeRF 系列都用），但把它用到 imitation learning ViT encoder 里是合适的工程选择。主要问题：RoboCasa 任务大多比较简单（开关炉灶、开关水龙头等），对接触丰富或 dexterous 任务的 viewpoint robustness 没有验证。另外"只改 positional encoding"意味着没法充分编码相机的 intrinsics，极端视角变化下效果不保证。👀

### 12. TRACT: Temporally Routed Action Chunks with Chronological Phase Authority for Contact-Rich Manipulation

- **作者**: Liu Jiahao, Kento Kawaharazuka, Tasuku Makabe, Kei Okada
- **机构**: 未知（应该是东京大学 Okada Lab）
- **链接**: [arXiv](https://arxiv.org/abs/2607.29285) | [PDF](https://arxiv.org/pdf/2607.29285)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.29285v1/x1.png)

- **核心方法**: [[ACT]] 预测 action chunk 时，如果 chunk 跨越任务阶段边界（比如"接近"→"接触"），单一 phase label 会错误描述整个 chunk。TRACT 引入"Chronological Phase Authority"：对 action chunk 内的每一步单独分配 phase label，按时序路由到对应 phase-specific module 处理。
- **对比方法/Baselines**: 对比 [[ACT]]、[[StageACT]]、[[PACE]] 等分阶段 action chunking 方法。
- **借鉴意义**: 接触密集任务里 phase boundary 问题确实存在，但 TRACT 的解法复杂度换来的收益需要看数字。
- **锐评**: 问题定义是真实的，但解法复杂。Phase labeling 本身要人工标注或需要额外检测器——这个成本在 paper 里没有充分讨论。仿真实验，没有真机结果。和 StageACT/PACE 的区别主要是粒度更细，算 incremental。🫠

### 13. Mirror Learning

![](https://arxiv.org/html/2607.28737v1/x1.png)

## 今日趋势

今天最明显的信号是 **VLA-RL 进入精细化阶段**：WCM 的 world critic、ActFovea/Safe-VLA 的 runtime safety——不再是"怎么训出更好的 VLA"，而是"怎么让 VLA 在 RL 训练和部署中更可靠"。World model 方向 FBFM + WorldDiT 都在往"统一架构"和"免训练增强"两个方向走，说明 WAM 的基础能力已经到了需要工程化的阶段。今天没有一篇让人觉得"这个会改变格局"，但 FibVLA 和 WCM 是今天最扎实的两篇。
