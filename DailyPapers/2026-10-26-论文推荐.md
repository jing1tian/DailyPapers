## Robot Perception / 位姿估计

### 2. F2G-Pose: Geometry-Aware Foundation Feature Lifting for Direct RGB-D Category-Level Object Pose Estimation
- **作者**: Jinyang Zhang, Haitao Lin, Jiashu Hou, Xiangyang Xue 等
- **机构**: Fudan University, Shanghai Innovation Institute
- **链接**: [arXiv](https://arxiv.org/abs/2610.31623) | [PDF](https://arxiv.org/pdf/2610.31623)
- **来源**: 🔥 HF Trending，⬆️ 14

> ⏪ **再推提醒**：这篇在 2026-10-25 推荐过

![](https://arxiv.org/html/2610.31623v1/pipeline.png)

- **核心方法**: F2G-Pose 针对无需 CAD 模型的类别级 RGB-D 位姿估计任务。输入 RGB-D 图像，输出物体的 3D 旋转和平移。核心贡献是用 [[RADIO]] 这类 Foundation Feature 作为 2D 语义提取器，然后通过几何感知的特征提升（Feature Lifting）将 2D 特征映射到 3D 点云上，避免了传统方法对逐实例 CAD 模型的依赖。用 [[MoE]]（Mixture of Experts）模块做点云的局部几何特征提取，与 Foundation Feature 做融合，最后直接回归旋转和平移。与 [[FoundationPose]] 相比，不需要参考图，与 [[GenPose]] 相比，去掉了对形状先验的依赖。
- **对比方法/Baselines**: 对比 [[FoundationPose]]、[[GenPose]]、[[RegDiff]]、[[AdaPoinTr]]；在 HANDAL 数据集上测 AUC/IoU 指标
- **借鉴意义**: 对 grasping 和 manipulation 任务有直接价值——无需 CAD 的类别级位姿估计是部署机器人抓取的关键瓶颈，这个方向值得跟
- **锐评**: Foundation Feature + 3D 几何提升的思路不新，但工程上把 2D VFM 和 3D 点云处理接起来做到 SOTA 是有价值的。问题是测试集都是桌面操作场景，真实机器人部署时遮挡和光照变化能不能扛住没有回答。摘要里 "directly" 预测位姿这个卖点其实大家都在做，MoE 在这里的必要性也没说清楚。🔥
- 💡 **想精读？** 运行：`读一下 F2G-Pose: Geometry-Aware Foundation Feature Lifting for Direct RGB-D Category-Level Object Pose Estimation`

## World Model / Video Generation

### 3. Looking Ahead: Modeling Future Evolution in Autoregressive Video Generation
- **作者**: Ruopeng Gao 等
- **机构**: Nanjing University, ARC Lab Tencent IEG, Zhejiang University
- **链接**: [arXiv](https://arxiv.org/abs/2610.29989) | [PDF](https://arxiv.org/pdf/2610.29989)
- **来源**: 🔥 HF Trending，⬆️ 171

> ⏪ **再推提醒**：这篇在 2026-10-23 推荐过

![](https://arxiv.org/html/2610.29989v1/chain.png)

- **核心方法**: 针对 AR 视频 diffusion（chunk-by-chunk 生成）在 teacher forcing 下的时序一致性问题。输入当前 chunk，预测下一 chunk，但核心问题是模型只学到了"合理的续接"而不是"场景如何真实演化"。方法是在生成当前 chunk 时，额外引入一个 Future Context Prediction（[[FCP]]）模块，预测未来帧的粗略演化方向，用这个 future context 作为条件来约束当前帧的生成。与 [[HunyuanVideo]]、[[MAGI-1]] 等对比，在 [[PhyGround]] 和 [[WorldModelBench]] 基准上验证物理合理性。
- **对比方法/Baselines**: 对比 [[HunyuanVideo]]、[[MAGI-1]]、[[DeepSeek]] 视频系列；使用 [[DiT]] 架构基础
- **借鉴意义**: 对做 robot world model 的人有参考价值——AR 视频生成的时序一致性问题在机器人 trajectory generation 中也存在。FCP 这种 future-conditioned generation 的思路可以迁移
- **锐评**: 思路有意思，teacher forcing 导致的 distribution shift 是 AR 视频模型的真实痛点。但从摘要看，FCP 模块预测的是"粗略演化方向"，这个粗略到底多粗、training signal 从哪来没说清楚。在 PhyGround 基准上好不代表真实物理正确，WorldModelBench 是什么测的什么也需要看全文。171 个 upvotes 说明社区感兴趣，但结论留待全文验证。👀
- 💡 **想精读？** 运行：`读一下 Looking Ahead: Modeling Future Evolution in Autoregressive Video Generation`

## Diffusion / 视频生成

### 4. SANA-Video: Efficient Video Generation with Block Linear Diffusion Transformer
- **作者**: Junsong Chen, Yuyang Zhao, Jincheng Yu, Ruihang Chu 等
- **机构**: NVIDIA
- **链接**: [arXiv](https://arxiv.org/abs/2509.24695) | [PDF](https://arxiv.org/pdf/2509.24695)
- **来源**: 🔥 HF Trending，⬆️ 56

> ⏪ **再推提醒**：这篇在 2026-10-23 推荐过

![](https://arxiv.org/html/2509.24695v2/teaser.png)

- **核心方法**: NVIDIA 出品的小参数量视频生成模型，目标是 720x1280 高分辨率、分钟级时长的高效生成。核心是 Block Linear Diffusion Transformer，用 linear attention 块替代标准 full attention 降低计算复杂度，配合 [[DCAE]] 压缩 latent 空间，支持 [[LongSANA]] 长视频策略和 [[Self-Forcing]] AR 生成。与 [[SkyReelv2]]、[[MAGI-1]] 对比。
- **对比方法/Baselines**: 对比 [[SkyReelv2]]、[[MAGI-1]]；使用 [[DiT]] + [[RoPE]] 架构基础
- **借鉴意义**: 对做 robot video generation 或 simulation 视频生成的人有工程参考价值，linear attention 在长视频上的效率优化是实用技术
- **锐评**: 这是 NVIDIA 工程论文，做的是"更快更省"，不是"更聪明"。Block Linear 这种思路已经做了很多年，这篇的贡献是把它做到高分辨率长视频这个场景且工程上跑通了。对做 robotics 的人来说跟核心问题关系不大，但如果要部署视频生成组件到边缘设备，这个方向值得参考。💤

### 5. RSIPO: Recursive Self-Improving Policy Optimization for Agentic Reinforcement Learning
- **作者**: Fan Zhang, Hao Wu, Jinyang Wu 等
- **机构**: CUHK, Shanghai AI Laboratory, Westlake University, Tongji University
- **链接**: [arXiv](https://arxiv.org/abs/2610.15772) | [PDF](https://arxiv.org/pdf/2610.15772)
- **来源**: 🔥 HF Trending，⬆️ 8

![](https://arxiv.org/html/2610.15772v1/intro_paradigms.png)

- **核心方法**: 针对 agentic LLM 的长时序 RL 问题，提出 Recursive Self-Improving Policy Optimization（RSIPO）。输入 LLM + 任务，输出优化后的 agentic policy。用 Self-Distillation（[[SDAR]]）做数据增强，结合 On-Policy 采样和 Search-Based 策略，通过递归自我提升来优化信用分配问题。与 [[GRPO]]、[[PPO]]、[[SFT]] 对比。
- **借鉴意义**: 跟 embodied AI 和 robot manipulation 关系不大，这是 LLM agent 的 RL 优化，不是机器人控制策略
- **锐评**: RLVR 做 agentic LLM 的方向没什么问题，RSIPO 这个名字拆开来就是递归版 self-improving + policy optimization 的组合，听起来吓人，从摘要看没有本质突破。8 个 upvotes 已经说明问题。💤
