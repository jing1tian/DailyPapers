### 1. SpikeVLA: Vision-Language-Action Models with Spiking Neural Networks
- **作者**: Ruiqi Song, Dujun Nie, Siyu Teng, Baiyong Ding, Xiaotong Zhang, Dong Li, Chenming Zhang, Yuchen Li, Hangbin Wu, Long Chen
- **机构**: 未知（affiliations 未提取到）
- **链接**: [arXiv](https://arxiv.org/abs/2606.27807) | [PDF](https://arxiv.org/pdf/2606.27807)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.27807v1/x1.png)

- **核心方法**: 把 VLA 全链路换成脉冲神经网络（[[SNN]]）：(i) Spike-V 用事件驱动脉冲层替换视觉编码器的稠密连续层；(ii) Spike-L 把跨模态推理重写为脉冲动力学 + token 级稀疏；(iii) Spike-A 用拉普拉斯核族码（Laplacian-kernel population coding）+ 多层全连接 SNN 解码连续控制动作。整个系统针对低功耗实时场景设计，靠事件驱动稀疏性降推理能耗。
- **对比方法/Baselines**: 对标 [[NaVILA]]（VLN 任务），在 RxR 数据集上对比 [[UniNaVid]]；机器人控制任务 baselines 摘要未详列。
- **借鉴意义**: SNN 进 VLA 全链路是第一次认真的尝试。如果能耗数字是真的，对边缘部署（无人机、电池供电移动机器人）有直接价值。
- **锐评**: 亮点是把 SNN 做全了，不是只换一个视觉编码器。实验覆盖了 VLN 导航和机器人控制，`has_real_world=True` 有真实实验。但"maintaining competitive performance"这个措辞太保守——SNN 相对 ANN 的精度代价有多大？摘要里能耗下降没有给出具体数字，只说"significantly reduces"。等全文看绝对值。 🔥

### 2. S²-VLA: State-Space Guided Vision-Language-Action Models for Long-Horizon Manipulation
- **作者**: Zhipeng Xie, Zongyi Han, Xiangyi Wei, Shiliang Sun, Yang Li, Jing Zhao
- **机构**: 东华师范大学计算机科学与技术学院，上海
- **链接**: [arXiv](https://arxiv.org/abs/2606.27872) | [PDF](https://arxiv.org/pdf/2606.27872)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.27872v1/Abs_v2.png)

- **核心方法**: 提出 State-Space Guided Adaptive Attention（[[SSGAA]]）：维护一个 belief state 追踪任务进度，动态生成门控权重，自适应融合视觉特征、任务意图、时序动作三路信息。不同任务阶段关注点动态转移（开始阶段偏语言规划，执行阶段偏视觉），解决静态 cross-attention 融合在长任务中累积误差的问题。模型只用 2B 参数。
- **对比方法/Baselines**: 在 [[LIBERO]] 和 [[SimplerEnv]] 上对比了 [[OpenVLA]]、[[OpenVLA-OFT]]、[[TraceVLA]]、[[SpatialVLA]]、[[SmolVLA]]、[[CogACT]]、[[MemoryVLA]]、[[RT-1]]。
- **借鉴意义**: 2B 干翻 7B 的核心在于 belief state 驱动的动态融合，值得在长任务 VLA 架构里直接借鉴这个 gating 思路。
- **锐评**: 结果够惊艳。但 belief state 是怎么学的——摘要里没提显式监督信号，纯靠端到端？那 belief state 的语义可解释性存疑，调试和 debug 会很痛苦。另外 [[SimplerEnv]] 本质上是 sim-based 评测，`has_real_world=True` 可能只来自真实机器人数据的 in-distribution 验证，不是 OOD 真机实验。今天 VLA 方向最值得读的实验论文。 🔥

### 3. Drop-Then-Recovery: How Redundant Are Vision-Language-Action Models?
- **作者**: Guoheng Sun 等
- **机构**: University of Maryland, College Park; Cisco Research
- **链接**: [arXiv](https://arxiv.org/abs/2606.27755) | [PDF](https://arxiv.org/pdf/2606.27755)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.27755v1/x1.png)

- **核心方法**: DTR 分析框架：把预训练 VLA 的 Transformer Block 逐块删掉（Drop），然后对保留结构做 fine-tune（Recovery），用下游 action loss 恢复情况判断这个 block 有没有被用上。配套 GateProbe——用虚拟门控权重做一次性灵敏度估计，免去逐块移除的高代价搜索。
- **对比方法/Baselines**: 覆盖多个 VLA 架构（含 [[OpenVLA-OFT]]、[[PaliGemma]] 系列），在 [[LIBERO]]、[[RoboTwin]] 上验证，`has_real_world=True`。
- **借鉴意义**: 实打实的结论：砍掉一半 LLM block，LIBERO 上 OpenVLA-OFT 从 95.0% 升到 98.3%；只留两个 LLM block 仍能恢复 baseline。对要在边缘设备部署 VLA 的人是直接可用的工程依据。
- **锐评**: 方向和 [[VLA-Pruner]] 有重叠，但这篇更系统。值得追问：LIBERO 这类 sim benchmark 的语言指令复杂度极低，"两个 LLM block 就够用"的结论放到 open-vocabulary 真实指令下还成立吗？需要看全文里 OOD 实验有没有覆盖这一点。 👀
- **关联笔记**: [[VLA-Pruner]] — 同属 VLA 压缩/冗余分析；[[VLA-Hijack]] — VLA 架构安全视角
- 💡 **想精读？** 运行：`读一下 Drop-Then-Recovery: How Redundant Are Vision-Language-Action Models?`

### 4. Direct Action-Head Injection of A Grounded 3D Point Unlocks Spatial and Task Generalization
- **作者**: Shiang-Feng Tsai 等
- **机构**: 台湾清华大学（NTHU）; 国立阳明交通大学（NYCU）
- **链接**: [arXiv](https://arxiv.org/abs/2606.27663) | [PDF](https://arxiv.org/pdf/2606.27663)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.27663v1/x1.png)

- **核心方法**: 在 VLA 的 action head 里注入一个 grounded 3D 点（由 VLM 从语言指令中定位目标位置），用 [[AdaLN]] 做条件融合。这个显式 3D 锚点让 action head 不再依赖隐式语言理解来推断目标位置，从而解决 (a) spatial 泛化（测试时物体位置变化）和 (b) task 泛化（OOD 指令）两个问题。
- **对比方法/Baselines**: 对比 [[MolmoAct]]、[[OpenVLA]]、[[RT-2]]，在 LIBERO-90（in-distribution）和 OOD 场景上验证，`has_real_world=True`。
- **借鉴意义**: 用显式 3D 语言接地弥补 VLA 空间泛化短板，比"更多数据"更有针对性。在自己的 VLA pipeline 里复现这个 3D 接地思路成本不高。
- **锐评**: 思路清晰，但核心假设是 VLM 能可靠地从语言提取 3D 目标点——在 LIBERO-90 这种受控场景下没问题，放到 open-world 场景 VLM grounding 精度才是瓶颈。OOD 实验的分布 shift 幅度摘要没交代，需要全文确认。 👀
- **关联笔记**: [[MolmoAct2]] — 同系 action head 设计

### 5. Qwen-AgentWorld: Language World Models for General Agents
- **作者**: Qwen Team（Alibaba + Tsinghua）
- **机构**: 阿里巴巴（Qwen 团队）
- **链接**: [arXiv](https://arxiv.org/abs/2606.24597) | [PDF](https://arxiv.org/pdf/2606.24597)
- **来源**: 🔥 HF Trending，⬆️ 139

![](https://arxiv.org/html/2606.24597v1/x1.png)

- **核心方法**: 训练两款语言世界模型（LWM）：Qwen-AgentWorld-35B-A3B 和 397B-A17B，覆盖 7 个 agentic 领域（web、terminal、GUI、game 等）。三阶段训练：CPT（注入世界建模能力）→ SFT（激活 next-state prediction 推理）→ RL（hybrid rubric-and-rule reward 提升仿真保真度）。同时展示了 LWM 作为解耦仿真器用于 agentic RL 的扩展能力。
- **对比方法/Baselines**: 在自建 AgentWorldBench（基于 9 个 benchmark 构建）上显著优于 [[GPT-5]]、[[DeepSeek]]、[[MiniMax]] 等。
- **借鉴意义**: 大规模语言世界模型的第一个认真开源版本，多域 next-state prediction 训练范式值得参考。但注意——这是 **text-based world model**，模拟的是文本状态转移，不是视频/图像状态，和 robot WAM 是两件事。
- **锐评**: Qwen 团队出品，工程质量可期，规模也够。但把 LWM 叫 "world model" 会产生概念混淆——7 个 agentic 领域全是数字环境（web/terminal/game），没有 robot manipulation 或 embodied navigation。139 upvotes 是 LLM 社区的关注而非 robotics。不过"LWM as RL environment simulator"这个范式如果有人扩展到视觉域就是大事，值得追踪。 🔥

### 6. DIM-WAM: World-Action Modeling with Diverse Historical Event Memory
- **作者**: Kai Wang 等
- **机构**: 中国科学院自动化所 NLPR; 引望智能科技; FiveAges
- **链接**: [arXiv](https://arxiv.org/abs/2606.27677) | [PDF](https://arxiv.org/pdf/2606.27677)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.27677v1/x1.png)

- **核心方法**: 在 WAM 框架（联合预测视频帧和动作）里加入多粒度 memory bank：从真实观测中提取紧凑视觉事件，通过相似度合并更新多个 bank，读取时用 bank identity + 时间嵌入编码长程上下文，同时加 progress-supervision（进度监督目标）让 memory token 不只编码历史，还编码当前任务阶段。
- **对比方法/Baselines**: 在 [[RMBench]] 上对比 [[LingBot-VA]]（28.4% → 69.8%），在 4 个真实 Franka 任务上 stage success 70.7% → 91.5%，full-task 52.5% → 80.0%。`has_real_world=True`。
- **借鉴意义**: 实机结果扎实，全任务成功率提升 27 个点。memory bank + 进度监督这个组合对做长任务 WAM 或 VLA 的人值得实验。
- **锐评**: 核心贡献清楚，有真机验证。但有几个细节值得追问：memory bank 更新是 online 的吗？实时更新延迟代价多少？4 个 Franka 任务的具体难度（任务步数、是否开放词汇）摘要没交代，80% 全任务成功率在简单 pick-and-place 上说服力不足。 👀
- **关联笔记**: [[HiMem-WAM]] — 同为 WAM + hierarchical memory 方向；[[MotionWAM]] — 运动感知 WAM
- 💡 **想精读？** 运行：`读一下 DIM-WAM: World-Action Modeling with Diverse Historical Event Memory`

### 8. PhysisForcing: Physics Reinforced World Simulator for Robotic Manipulation
- **作者**: Peiwen Zhang 等
- **机构**: 北京大学; NVIDIA
- **链接**: [arXiv](https://arxiv.org/abs/2606.28128) | [PDF](https://arxiv.org/pdf/2606.28128)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.28128v1/figs/Fig1_Teaser.png)

- **核心方法**: 在视频生成式世界模型上注入物理约束。PAI（Physics-Aware Injector）+ PF（Physics-Forcing loss）：用 [[CoTracker3]] 追踪生成视频中的物体轨迹，与 NVIDIA Newton 物理引擎的模拟轨迹对比，用 trajectory consistency loss 约束视频生成，使预测满足刚体运动学。
- **对比方法/Baselines**: 对比 [[DreamGen]]、[[GigaWorld]]、[[WorldArena]]，在 [[RoboTwin]] 上验证，`has_real_world=True`。
- **借鉴意义**: 物理约束注入视频 WAM 是解决"视觉好看但运动学不合理"的正确方向。北大+NVIDIA 出品，RoboTwin 有真机实验。
- **锐评**: 思路正确，但有个核心问题：NVIDIA Newton 给出的"物理正确"轨迹和真实世界接触力学之间本身有 sim-to-real gap——用 sim 物理约束视频生成，再用来训 robot policy，套了两层模拟，每层都有 gap。另外 CoTracker3 在遮挡和快速运动下的追踪精度有限，这个 tracking loss 的鲁棒性需要仔细验证。 👀
- **关联笔记**: [[DreamGen]] — 同属视频生成 + robot manipulation 方向；[[Flash-WAM]] — 另一个快速 WAM 方案

### 10. Translation as a Bridging Action: Transferring Manipulation Skills from Humans to Robots

- **关联笔记**: [[EgoVLA]] — ego-centric 视角 VLA；[[DROID]] — 跨机器人操作数据集

### 11. Unleashing Infinite Motion: Scaling Expressive Quadrupedal Motion via Generative Video Priors
- **作者**: Youzhi Liu
- **机构**: 阿里巴巴高德地图（Alibaba Amap）
- **链接**: [arXiv](https://arxiv.org/abs/2606.28237) | [PDF](https://arxiv.org/pdf/2606.28237)

- **借鉴意义**: 视频先验 → 四足运动多样性扩展，是近期 hot topic 的具体落地。如果你做四足运动控制或"视频先验 → robot"方向，这篇值得看。

- 💡 **想精读？** 运行：`读一下 Unleashing Infinite Motion: Scaling Expressive Quadrupedal Motion via Generative Video Priors`
