### 2. OASIS: Observation-Action Space Alignment via SE(3) Trajectory Prediction for Robotic Manipulation
- **作者**: Xinzhe Chen, Sihua Ren 等
- **机构**: 西北工业大学（国家人机混合增强智能重点实验室）+ 西安人工智能与机器人研究院
- **链接**: [arXiv](https://arxiv.org/abs/2605.25829) | [PDF](https://arxiv.org/pdf/2605.25829)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.25829v1/x1.png)

- **核心方法**: 输入 RGB 观测 + 语言指令，输出 SE(3) 轨迹作为中间表征（而非 pixel-space 预测或语义 feature）。关键：用[[刚体几何]]的 SE(3) 表征桥接观测空间和动作空间，让动作解码器不再需要隐式恢复空间几何信息。通过 [[AuxTraj]] 辅助轨迹头联合训练世界模型和动作预测模块
- **对比方法/Baselines**: 对比 [[RDT]]、[[ThinkAct]]、[[Seer-Large]]、[[ACT]] 等；借鉴了 [[WAM]] 的概念框架；在 [[LIBERO]]、[[CALVIN]] 基准上测试
- **借鉴意义**: SE(3) 作为 VLA 中间表征这个思路新颖——不是预测 pixel，而是预测刚体轨迹。对做操作任务几何建模的人值得看
- **锐评**: 核心 insight 是对的：动作空间和观测空间本来就不对齐，用 SE(3) 轨迹做桥梁比 pixel prediction 在计算上更轻、物理上更合理。但摘要没有提真实机器人实验范围有多大——`has_real_world=True` 说明有，但覆盖几个任务、几个机器人没说清楚。另外 SE(3) 假设刚体操作，对软体、流体等非刚体场景直接失效，应用边界需要注意。 👀

### 4. Drift-Resistant Navigation World Model with Anchored Epipolar Guidance
- **作者**: Po-Chien Luan, Zimin Xia（共同一作）等
- **机构**: VITA Lab @ EPFL
- **链接**: [arXiv](https://arxiv.org/abs/2605.24761) | [PDF](https://arxiv.org/pdf/2605.24761)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.24761v1/x1.png)

- **核心方法**: 输入历史图像序列 + 动作，输出未来图像帧用于导航规划。核心：用对极几何（[[Epipolar Geometry]]）作为几何锚点（Anchored Epipolar Guidance），约束自回归生成中的每一帧，防止几何漂移（geometric drift）和感知漂移（perceptual drift）。基于 [[NWM]] 框架扩展，使用 [[Conditional DiT]] 主干；用 [[CEM]]（Cross-Entropy Method）做规划
- **对比方法/Baselines**: 对比 [[EgoWM]]、[[NWM]]、[[RECON]]；在 [[SCAND]]、[[HuRoN]]、[[TartanDrive]] 数据集测试；指标 ATE、RPE、FDE
- **借鉴意义**: 室内外导航世界模型的漂移问题是真实痛点，对极几何是解法之一。EPFL VITA 组出品质量有保证
- **锐评**: 用对极约束做几何锚点这个思路简洁且有理论依据——相机运动参数已知的前提下，对极线约束是免费的几何先验。但有一个假设：相机内外参已知（或估计精确），在野外导航遇到标定漂移时性能如何？摘要没有提。评测 ATE/RPE/FDE 而不是任务成功率，说明这还是停留在预测质量层面，has_real_world=False 进一步证实。方向对，但机器人端到端的闭环还差一步。 👀

### 7. X-DiffVLA: X-Embodied Diffusion Action Heads for Vision-Language-Action Models
- **作者**: Boyu Li 等
- **机构**: UCAS + Beijing Academy of Artificial Intelligence (BAAI) + BeingBeyond
- **链接**: [arXiv](https://arxiv.org/abs/2605.25044) | [PDF](https://arxiv.org/pdf/2605.25044)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.25044v1/x1.png)

- **核心方法**: 输入多模态观测（视觉+语言），输出跨具身的动作预测。核心设计：X-Embodied Diffusion Action Head——用一个共享的 [[扩散策略|Diffusion Policy]] 动作头编码具身无关的运动原语（Embodiment-agnostic Motion Primitives），同时配备具身特定的适配器（embodiment-specific adapters）做 DoF 映射；训练时在多个平台的数据上混合，inference 时通过具身 ID 选择对应 adapter。在 [[RoboCasa]]、BeingBeyond XR-1 机器人、[[FAST]] 行动空间上验证
- **对比方法/Baselines**: 对比 [[OpenVLA]]、[[UniVLA]]，以及 [[MCTD]]（多模态 cross-task diffusion）、[[DemoGrasp]] 等跨具身基线
- **借鉴意义**: 多机器人平台统一策略学习的现实解法。共享 backbone + 具身特定 adapter 的设计已被 NLP 验证过（LoRA 家族），在 robotics 里 X-DiffVLA 是较系统的实践
- **锐评**: has_real_world=True，而且跑了真实的 BeingBeyond XR-1（不是只在 sim 里），这是加分项。扩散头 + 具身 adapter 的组合思路清晰。但核心问题：共享的"运动原语"真的跨具身泛化了吗，还是只在数据分布相似的场景里好用？消融 adapter 效果和 adapter 数量的 tradeoff 是关键实验。另外 FAST action space 这个选择是亮点——高频 action token 代替传统 EEF 坐标，这才是可扩展的设计。 🔥

### 8. QuoVLA: Quotient Space for Vision-Language-Action Models
- **作者**: Wang, Xuan; Wu, Yinan; Duan, Haoran; Han, Jungong
- **机构**: 清华大学自动化系
- **链接**: [arXiv](https://arxiv.org/abs/2605.24890) | [PDF](https://arxiv.org/pdf/2605.24890)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.24890v1/o.jpg)

- **核心方法**: 输入视觉+语言，输出操作动作。核心理论：用[[商空间]]（Quotient Space）分解 VLM 潜在空间——将 VLM latent 分解为"视觉语言语义子空间"和"动作流形商空间"，允许 action-relevant 信息从 VLM 表征中分离出来单独优化，避免 action finetuning 破坏原始语义表征。在 [[LIBERO]]、[[RoboTwin]] 上与 [[OpenVLA]]、[[SpatialVLA]]、[[SimVLA]] 等对比
- **对比方法/Baselines**: 基线：[[OpenVLA]]、[[SpatialVLA]]、[[SimVLA]]、[[ACT]]；理论上借鉴了商空间的数学框架（quotient manifold theory）；测试平台 [[LIBERO]]、[[RoboTwin]]

- **锐评**: 理论包装有意思——商空间这个数学框架用在 VLA 上是第一次看到。问题在于：从 LIBERO/RoboTwin 的仿真结果到真实世界之间的 gap 没有被解决，has_real_world=False 是硬伤。另外"商空间分解"在实现层面是怎么做到的（是否需要显式的流形约束损失？还是隐式通过训练目标体现）？摘要没有说清楚。如果只是花哨的数学外衣包一个 LoRA，那就没意思了。 👀

### 9. Afford-VLA: Action-Aligned Visual Planning via Internalized Affordance
- **作者**: Runze Wang 等
- **机构**: 复旦大学 + KAUST + 上海交通大学 + 华东师范大学
- **链接**: [arXiv](https://arxiv.org/abs/2605.24203) | [PDF](https://arxiv.org/pdf/2605.24203)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.24203v1/x1.png)

- **核心方法**: 输入视觉观测 + 语言指令，输出动作；中间层引入内化的[[可供性]]表征（Internalized Affordance）作为视觉规划锚点。关键：不依赖外部空间几何（如点云、深度），也不用 symbolic 中间表征，而是在 VLM backbone 内部学习 action-aligned 的可供性热图（affordance heatmap），用它引导动作生成。在 [[SimplerEnv]]、[[LIBERO]]、[[LeRobot]] 框架下与 [[OpenVLA]]、[[SpatialVLA]]、[[CoA]] 等对比
- **对比方法/Baselines**: 对比 [[OpenVLA]]、[[SpatialVLA]]、[[CoA]]（Chain of Affordance）；借鉴了 [[可供性]] 理论；用 [[FAST]] 动作 tokenizer；在 [[SimplerEnv]]、[[LIBERO]] 测试
- **借鉴意义**: 可供性作为视觉-动作对齐的中间表征是合理的物理直觉；不需要 3D/深度传感器是工程优点
- **锐评**: has_real_world=True，在 Fudan 的真实机器人上跑了。可供性热图内化进 VLM 这个思路比外挂一个 affordance detector 更优雅。但：affordance heatmap 的监督信号从哪来？如果需要人工标注接触点，数据成本可能很高。另外和 [[CoA]] 的差别要看实验设计——同样都是 affordance 引导规划，差别如果只是内化 vs. 外挂，那 novelty 有限。KAUST + Fudan 的合作质量一般靠谱。 👀

### 10. EXPO-FT: Sample-Efficient Reinforcement Learning Finetuning for Vision-Language-Action Models
- **作者**: Perry Dong, Kuo-Han Hung 等
- **机构**: Stanford University
- **链接**: [arXiv](https://arxiv.org/abs/2605.25477) | [PDF](https://arxiv.org/pdf/2605.25477)
- **来源**: 📄 arXiv 关键词检索

- **对比方法/Baselines**: 对比 [[SERL]]、[[DSRL]] 等 real-world RL 框架；借鉴 [[RLPD]] 的 offline+online 混合策略；使用 [[SpaceMouse]] 做人工干预收集数据

- **锐评**: has_real_world=True，Stanford 出品，这是两个很强的信号。SFT 预热再上 RL 是经过验证的稳定化策略；高 UTD 比提升样本效率也是已知有效方法。但关键数字是什么：用多少真实样本能从 VLA 基础性能提升到部署级别？摘要强调"sample-efficient"，但如果还是需要几千个真实 demo，那"高效"二字就要打折。HIL 干预的成本（人工时间）也应该有量化。期待看到完整数字。 🔥

- **借鉴意义**: 如果你在选 VLM backbone 做 VLA finetuning，这篇的消融直接给你答案：哪种表征初始化成功率最高
- **锐评**: 这是一篇"controlled experiment"论文，学术价值在于系统消融，算法贡献为零。但结论如果扎实，对 VLA 初始化选型有直接指导意义。CUHK 洪生明组出品质量可以信赖。has_real_world=True 加分。唯一担心：结论是否强依赖于 PaliGemma2 这个特定 backbone，换个 VLM 结论还成立吗？ 👀

### 12. Efficient Long-Horizon VLA Models via Static-Dynamic Disentanglement
- **作者**: Qiu, Weikang; Lei, Huashuo; Huang, Tinglin; Ying, Rex
- **机构**: Yale University + HKUST
- **链接**: [arXiv](https://arxiv.org/abs/2602.03983) | [PDF](https://arxiv.org/pdf/2602.03983)

- **锐评**: has_real_world=True。Yale + HKUST 组合。静-动态分离的直觉对——背景不用每帧重编码。但关键问题："静态"和"动态"的 token 分类是否自适应？场景发生变化（比如推开一扇门）时"背景"突然变了，分类会不会出错？如果是硬阈值分类，鲁棒性存疑。另外与 ContextVLA、MemoryVLA 的差别是什么，论文需要说清楚。 👀

### 13. Capability and Robustness Cannot Both Be Free: An Information-Theoretic Bound for VLA Models

### 14. Bridging the Semantic-Action Gap in Visual Token Pruning for Efficient VLA Inference
- **作者**: Ziyan Liu 等
- **机构**: 哈尔滨工业大学（深圳）+ 中国科技大学
- **链接**: [arXiv](https://arxiv.org/abs/2511.16449) | [PDF](https://arxiv.org/pdf/2511.16449)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2511.16449v5/x1.png)

- **核心方法**: 视觉 token 剪枝用于 VLA 加速，但发现标准 token 剪枝（按语义显著性）会丢弃对动作预测重要的 token。提出 SAGPrune：在剪枝时同时考虑语义显著性（semantic score）和动作相关性（action relevance score），用[[Redundancy-Minimization]]策略在两个目标之间做最优 token 选择。在 [[OpenVLA]]、[[LIBERO]]、[[SIMPLER]] 上测试
- **对比方法/Baselines**: 对比 [[FastV]]、[[SparseVLM]]、[[DivPrune]]、[[EfficientVLA]]、[[FitPrune]]；借鉴了 [[CUDA]] 风格的计算图分析；使用 [[VTW]]（Visual Token Weighting）技术
- **借鉴意义**: "语义显著"不等于"动作相关"——这个 insight 对做 VLA inference 加速的人来说很重要
- **锐评**: has_real_world=True，这是加分项。核心发现是真实的：VLM 的 attention map 选的是"看起来重要的"token，而 VLA 需要的是"动作执行需要的"token，两者的分布不同。SAGPrune 的解法是加一个 action relevance 分数，合理但不惊艳——action relevance 怎么得到的？如果要用 GT action 监督，那 inference 时没法在线计算，是用历史动作还是另外训一个 action relevance predictor？实现细节是核心。 👀

### 15. SpecPrune-VLA: Accelerating VLA Models via Action-Aware Self-Speculative Decoding
- **作者**: Hanzhen Wang, Jiaming Xu, Yushun Xiang, Jiayi Pan, Yongkang Zhou, Yong-Lu Li, Guohao Dai
- **机构**: 未知（NVIDIA 参与）
- **链接**: [arXiv](https://arxiv.org/abs/2509.05614) | [PDF](https://arxiv.org/pdf/2509.05614)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2509.05614v3/x1.png)

- **核心方法**: 用推测解码（[[Self-Speculative]] decoding）加速 VLA：以少量视觉 token 的"草稿模型"先生成候选动作，再用完整 VLA 验证。区别于传统推测解码：VLA 的 token 重要性有 action-aware 信息，引导草稿生成时优先保留动作关键 token。在 [[OpenVLA]]、[[CogACT]]、[[LIBERO]]、[[SimplerEnv]] 上验证，利用 [[FlashAttention]] 和 LoRA 训练
- **对比方法/Baselines**: 对比 [[FastV]]、[[SparseVLM]]、[[DivPrune]]、[[EfficientVLA]]；在 RTX GPU 上测速；同时考虑 DivPrune 和 EfficientVLA 作为 token 选择的 baseline
- **借鉴意义**: 推测解码从 LLM 移植到 VLA 是自然延伸，action-aware 的引导是关键改进
- **锐评**: has_real_world=True。推测解码加速 VLA 这个方向被这篇和 Bridging-SAG 同时做，说明这块竞争激烈。SpecPrune-VLA 的特点是用全局上下文（而非只看当前帧）做 token 重要性判断——摘要说"现有方法只看局部信息导致 >20% 成功率下降"。如果这个下降真的存在且被 SpecPrune 解决，那是真贡献。但速度提升几倍、成功率代价是多少，这两个数字才是关键。 👀
