### 3. HarnessEval-W: Agentifying the Evaluation of Visual Worlds
- **作者**: 未知（富化未提取到作者信息）
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2608.16859) | [PDF](https://arxiv.org/pdf/2608.16859)
- **来源**: 🔥 HF Trending，⬆️ 123
- 📒 **笔记**: [[HarnessEval-W]]

> ⏪ **再推提醒**：这篇在 2026-08-19 推荐过

![](https://arxiv.org/html/2608.16859v1/fig_teaser.png)

- **核心方法**: 把世界模型 rollout 的评估从"一个标量分"改成"agentic 推理过程"。输入是世界模型生成的视频/交互序列，输出是带理由的结构化评分报告。核心组件：[[WorldPlay]] 评估器（LLM agent 逐步与世界模型交互，在每一步给出有依据的评分）+ [[WorldScore]] 和 [[WorldMark]] 作为协议基准。关键区别在于"评估即推理"——一个标量说不清哪一帧物理出错了，agentic 评估器能定位到具体 timestep 的因果/物理错误。
- **对比方法/Baselines**: 对比 [[WorldScore]]、[[VBench]]（传统标量指标）；评估对象包括 [[HunyuanVideo]]、[[DreamX]] 等主流视频生成/世界模型
- **借鉴意义**: 对做世界模型的人直接相关——评估标准的质量决定了训练信号的质量。尤其是需要评估 action-conditioned WM 的物理一致性时，agentic 评估比单一 metric 有更高的诊断价值。
- **锐评**: 思路是对的，agentic 推理比打标量分更有可解释性。但两个问题没有被回答：(1) agentic evaluator 自己也会犯物理错误，LLM 对流体动力学和接触力学的判断未必可靠；(2) 如果只在 video generation 模型（HunyuanVideo 这类）上评估，对 action-conditioned WM 的指导价值打折扣——robotics 里的世界模型不只是生成视频，还要预测 action outcome。123 upvotes 说明方向被认可，但能否成为行业标准还看 benchmark 覆盖的场景深度。🔥
- **关联笔记**: [[WBench]]（世界模型评估基准同类竞争）；[[SC3-Eval]]（另一评估方向）

### 5. LLM-as-a-Verifier: A General-Purpose Verification Framework
- **作者**: Jacky Kwok（Stanford University, UC Berkeley, NVIDIA Research）
- **机构**: Stanford University, UC Berkeley, NVIDIA Research
- **链接**: [arXiv](https://arxiv.org/abs/2607.05391) | [PDF](https://arxiv.org/pdf/2607.05391)
- **来源**: 🔥 HF Trending，⬆️ 18

> ⏪ **再推提醒**：这篇在 2026-08-19 推荐过

![](https://arxiv.org/html/2607.05391v2/figures/SOTA.png)

- **核心方法**: 不让 LLM 输出离散分数，而是对 scoring token 的 logit 分布取期望，得到连续置信分数。输入是 task description + candidate solution，输出是连续分数（用于排序或 RL reward）。三个 scaling 维度：(1) score 粒度（token 级别细化）；(2) 重复评估（多次期望均值）；(3) criteria decomposition（把评估标准拆解后分别打分再综合）。另有 Probabilistic Pivot Tournament 用于从候选集中高效选优。
- **对比方法/Baselines**: 在 [[RoboRewardBench]] 上对比 trained robotics reward models（胜出 87.4%）；对比 [[GRPO]] 和 [[SAC]] 做 RL dense reward 实验；在 Terminal-Bench V2、SWE-Bench Verified 上刷 SOTA
- **借鉴意义**: 对做机器人 RL 的人：verifier 提供的 dense feedback 提升了 SAC 和 GRPO 的样本效率，reward shaping 角度值得借鉴。RoboRewardBench 87.4% 是实质性数字，不是虚的。
- **锐评**: logit 期望代替离散采样这一点干净，理论基础扎实。但有两个不舒服的地方：(1) 18 个 upvotes，说明这篇热度比较低，社区反应冷淡——要么是因为之前推过，要么因为更多人把它当 coding agent 工具而不是 robotics 工具；(2) RoboRewardBench 评的是对 robot trajectory 的偏好判断，跟真实机器人闭环控制还有一步。这不是核心 embodied AI 论文，主战场在 code/agent。但如果你在做 RLHF for robotics 或稀疏 reward 强化学习，这个框架值得拿来用。👀

## 3D/4D 视觉

### 7. 4DAnyone: Create Anyone in 4D from a Casual Monocular Video
- **作者**: Yudong Jin, Tao Xie, Qihang Zhang, Zehong Shen, Zhen Xu, Yujun Shen, Hujun Bao, Xiaowei Zhou, Yinghao Xu
- **机构**: Zhejiang University (State Key Lab of CAD&CG), Hong Kong University of Science and Technology, Chinese University of Hong Kong
- **链接**: [arXiv](https://arxiv.org/abs/2608.20335) | [PDF](https://arxiv.org/pdf/2608.20335)
- **来源**: 🔥 HF Trending，⬆️ 66

> ⏪ **再推提醒**：这篇在 2026-08-22 推荐过

![](https://arxiv.org/html/2608.20335v1/teaser.png)

- **核心方法**: 从随意拍摄的单目视频重建 4D 人体（时序 [[4DGS]]）。输入是单镜头人物视频，输出是可从任意视角实时渲染的 4D Gaussian Splatting 表示。核心问题是"多视角扩展时的一致性崩溃"——当目标视角超出单次 [[DiT]] forward pass 容量时需要分组，分组之间信息断裂。解法：Reference Context Packing (RCP) 把积累的参考视角压缩为定长混合分辨率 context（O(1) 复杂度），Target Context Routing (TCR) 在去噪时旋转 target group 划分，让不同组之间在高噪声步骤共享信息，低噪声步骤稳定细节。
- **对比方法/Baselines**: 评估在 [[DNA-Rendering]] 和 [[DyMVHumans]] benchmark；对比 [[ReCamMaster]]、[[TrajectoryCrafter]]、[[CameraCtrl]] 等相机控制视频生成方法；人体参数估计用 [[SMPL]]、[[HMR]]；训练使用自建 MVGameHuman 数据集（游戏引擎构建）
- **借鉴意义**: 对具身 AI 的价值：人体视角合成可以用于数据增强（不同视角下的人体动作数据）。MVGameHuman 数据集是个值得关注的资源。RCP 的 context compression 思路也可以借鉴到需要处理多视角输入的机器人感知模型。
- **锐评**: 问题诊断（bounded-attention-context）清晰，RCP+TCR 对症下药。在 DNA-Rendering 和 DyMVHumans 上超越现有方法是实质贡献。但 has_real_world=false——只是 benchmark 测试，没有展示在实际场景采集视频上的鲁棒性。而且 4D human reconstruction 的核心受益方是人体动画、AR 领域，不是机器人操作。整体是扎实的 4DGS 工程论文，robotics 方向看 MVGameHuman 数据集就够了，不需要精读整篇。👀
- 💡 **想精读？** 运行：`读一下 4DAnyone: Create Anyone in 4D from a Casual Monocular Video`
