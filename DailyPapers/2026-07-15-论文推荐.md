### 1. TS-Mask VLA: 2D Temporal-Spatial Masking for Vision-Language-Action Model with Effective Bridging
- **作者**: Shengzhuo Yang 等
- **机构**: Zhejiang Key Laboratory of Advanced Intelligent Warehousing and Logistics
- **链接**: [arXiv](https://arxiv.org/abs/2607.09818) | [PDF](https://arxiv.org/pdf/2607.09818)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.09818v1/x1.png)

- **核心方法**: 针对 autoregressive token-based VLA 模型中离散 token 与连续动作空间之间的 bridging gap，提出时序-空间二维 masking 策略（TS-Mask）。输入是视觉观测 + 语言指令，输出是动作 token 序列。关键在于在时间维度（跨帧动作依赖）和空间维度（当前帧内关节关系）同时施加结构化掩码，迫使模型学习跨维度的完整上下文。与 [[FlowVLA]]、[[ReMask]] 等工作相比，核心区别在于同时捕获时序连续性和空间协调性，而不只做单维 masking
- **对比方法/Baselines**: 对比了 [[OpenVLA]]、[[SmolVLA]]、[[ThinkAct]]，在 [[LIBERO]] 和 [[CALVIN]] benchmark 上验证，并有真实机器人实验
- **借鉴意义**: 直接拿来义务改造现有 VLA 的 action head，masking 策略轻量，适合在 [[OpenVLA]] 或 [[π0]] 基础上快速实验
- **锐评**: 这篇分数最高（8 分）是有道理的：方向明确、有真实机器人实验、benchmark 覆盖面合理。masking 本身不是新思路，但放在动作生成的时序-空间联合维度上是对的组合。唯一需要追问的是：masking ratio 如何选取，敏感性如何？摘要没有提这部分，ablation 结果待查
- **关联笔记**: [[VLA]]、[[CoT-VLA]]、[[FlowVLA]]

### 2. Towards Predictive, Aligned, and Scalable Robot Learning（Lumo-2）
- **作者**: Tang, Peijun, Xie, Shangjin, Huang, Baifu, Sun, Binyan, Yang, Haotian, Luo, Kunc 等
- **机构**: 未知（摘要内机构字段为空）
- **链接**: [arXiv](https://arxiv.org/abs/2607.11270) | [PDF](https://arxiv.org/pdf/2607.11270)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.11270v1/figures/teaser.png)

- **核心方法**: Lumo-2 是一个 latent world-action model（LWAM），在潜在空间里同时推理世界动态和动作序列。输入是视觉观测 + 语言，输出是 latent world state 序列和动作预测。核心是让 policy 不直接从像素→动作，而是先在潜在空间预测世界演化，再从这个预测轨迹中解码动作——本质是 [[WAM]] 的潜在空间变体。在 RefSpatialBench、BLINK 等多模态基准上对齐，并在真实机器人上验证
- **对比方法/Baselines**: 与 [[DINO]]、[[VQ]] 变体比较，benchmark 包括 RefSpatialBench、BLINK，在真实 VisionPro 设备上测试
- **借鉴意义**: 如果你在做 latent world model + policy 的联合训练，Lumo-2 提供了一个"先预测世界再解码动作"的架构参考，比直接 pixel-to-action 更有可解释性
- **锐评**: 论文的核心 insight 是正确的——在潜在空间里做 world-action 联合推理比直接预测动作更 scalable。但"latent world dynamics"能学到什么、学到多细，摘要完全没有量化。Affiliations 也是空的，来历不明，需要看全文确认是否是真实系统还是 simulation-heavy。不过方向是今年的风口，值得精读
- **关联笔记**: [[WAM]]、[[World Model]]、[[LeWM]]

### 3. IntentVLA: Short-Horizon Intent Modeling for Aliased Robot Manipulation
- **作者**: Shijie Lian 等（HIT, HKUST(GZ), BUAA, ZZU, ECNU, USTC, DeepCybo）
- **机构**: HIT / HKUST(GZ) / BUAA / DeepCybo 等
- **链接**: [arXiv](https://arxiv.org/abs/2605.14712) | [PDF](https://arxiv.org/pdf/2605.14712)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.14712v2/x1.png)

- **核心方法**: 针对 imitation learning 中的"动作多模态"问题——相同观测可能对应不同动作块（aliased demonstrations）。IntentVLA 在 VLA 的推理链中显式建模"短时意图"（short-horizon intent），先预测未来若干帧的意图状态，再生成动作块。输入是当前帧 + 语言，输出是意图 token 序列 + 动作块。区别于 [[MemoryVLA]]（历史依赖）和 [[TwinBrainVLA]]（双流），这里专注于前向意图预测来解歧义
- **对比方法/Baselines**: 与 [[OpenVLA]]、[[StarVLA]]、[[GEAR]]、[[LangForce]] 比较，在 [[RoboCasa]]、[[SimplerEnv]]、[[RoboTwin2]]、[[LIBERO]] 和 [[VGGT]] 上测试
- **借鉴意义**: 对做 imitation learning 的人非常有价值——multimodal demonstrations 是真实数据集的常态，当前大多数 VLA 对此没有专门处理
- **锐评**: 问题定义很清晰，解法直觉上合理。最大的疑问是：短时意图预测的质量如何控制？如果意图预测出错，会不会比没有意图更差？摘要未提供意图预测准确率的量化，需要看全文 ablation
- **关联笔记**: [[VLA]]、[[MemoryVLA]]、[[Diffusion Policy]]
- 💡 **想精读？** 运行：`读一下 IntentVLA: Short-Horizon Intent Modeling for Aliased Robot Manipulation`

### 4. Let It Be Simple: One-Step Action Generation for Vision-Language-Action Models
- **作者**: Chen, Yitong, Zhang, Shiduo, Gong, Jingjing, Qiu, Xipeng
- **机构**: USTC / Shanghai Innovation Institute / Fudan University
- **链接**: [arXiv](https://arxiv.org/abs/2606.05737) | [PDF](https://arxiv.org/pdf/2606.05737)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.05737v2/x1.png)

- **核心方法**: 论文的 key insight 是：VLA 的 condition-target 关系（视觉+语言 → 动作）更接近 image-to-text 而非 text-to-image，动作空间的熵远低于图像空间。基于此，用 [[CFM]]（Conditional Flow Matching）的 one-step 推理替代多步 diffusion，推导出"不可约速度下界"（irreducible velocity lower bound）作为理论支撑。输入是视觉观测 + 语言，one-step 直接输出动作，无需 DDIM 或多步 denoise
- **对比方法/Baselines**: 借鉴 [[CFM]]、[[FM]] 框架，对比 [[SimVLA]]、[[OpenVLA]]，在 [[LIBERO]] 和 OpenPI 上测试，基于 [[PaliGemma]] + [[SigLIP]] 架构
- **借鉴意义**: 如果你的 pipeline 里用 diffusion policy 推理太慢，这篇的 one-step 思路可以直接参考。理论推导有一定新颖性
- **锐评**: "VLA 应该用 one-step 而非 diffusion"这个论点有说服力，理论分析也有意思。但只在 LIBERO（仿真）和 OpenPI 上测试，缺真实机器人实验，结论外推需谨慎。此外"one-step"的鲁棒性在噪声观测下如何？摘要未讨论
- **关联笔记**: [[CFM]]、[[FlowMatching]]、[[Diffusion Policy]]
- 💡 **想精读？** 运行：`读一下 Let It Be Simple: One-Step Action Generation for Vision-Language-Action Models`

### 5. Simple Recipe Works: VLA Models are Natural Continual Learners with Reinforcement Learning
- **作者**: Hu, Jiaheng, Shim, Jay, Tang, Chen, Sung, Yoonchang, Liu, Bo, Stone, Peter, Mart 等
- **机构**: 未知（Affiliations 为空）
- **链接**: [arXiv](https://arxiv.org/abs/2603.11653) | [PDF](https://arxiv.org/pdf/2603.11653)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2603.11653v3/x1.png)

- **核心方法**: 传统观点认为 VLA 的持续学习（CRL）需要复杂机制（如 EWC、回放缓冲区）来防止遗忘。这篇反直觉地发现：当用 [[GRPO]]（Group Relative Policy Optimization）做 RL 微调时，VLA 天然地表现出持续学习能力，naive sequential fine-tuning 配合 RL 就够用。输入是任务序列，输出是在不同任务上保持能力的策略。关键组件是 [[LoRA]] + RL 奖励信号，无需额外的遗忘防护机制
- **对比方法/Baselines**: 与 [[SLCA]]、[[RETAIN]] 等 continual learning 方法比较，对比 [[OpenVLA]] baseline，在 [[RoboCasa]] 上测试，用 zero-shot（ZS）和 Forward Transfer（FWT）指标评估
- **借鉴意义**: 对做多任务/持续学习机器人策略的人有直接价值：RL 本身可能就是 continual learning 的解药，不需要复杂的 CRL 算法
- **锐评**: 发现本身非常有价值，逆直觉但说得通——RL 的奖励驱动性防止了 catastrophic forgetting。但"simple recipe"能 scale 到更复杂的任务序列吗？RoboCasa 的任务多样性是否足够？另外奖励函数的设计细节摘要没给
- **关联笔记**: [[VLA]]、[[GE-Act]]、[[GRPO]]

### 6. See like a Robot: Robot-Centric Pointmaps for Vision-Language-Action Models
- **作者**: Byungkun Lee 等
- **机构**: KAIST AI / Holiday Robotics
- **链接**: [arXiv](https://arxiv.org/abs/2607.11498) | [PDF](https://arxiv.org/pdf/2607.11498)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.11498v1/x1.png)

- **核心方法**: 现有 VLA 在 camera frame 里观测场景，但动作是在 robot frame 里定义的，存在坐标系不匹配。PointVLA 提出把场景表示转换为 **robot-centric pointmap**——以机器人基座为原点的稠密点云图，作为视觉输入的附加通道。输入是 RGB + robot-centric pointmap + 语言，输出是在机器人坐标系中的动作。与 [[GeoVLA]] 的区别在于 robot-centric vs. camera-centric geometry
- **对比方法/Baselines**: 与 [[SmolVLA]]、[[GeoVLA]] 比较，在 [[RoboCasa]] 上测试（CoffeePressButton、CoffeeServeMug 等任务），有 [[DROID]] 真实机器人实验，用 [[SigLIP]] 视觉编码器

- **锐评**: 问题定义准确，解法直接有效。但 pointmap 的质量依赖深度传感器精度，在动态光照或遮挡场景下的鲁棒性如何？另外这类"给 VLA 加几何信息"的 paper 近期太多（GeoVLA、TraceVLA 等），差异化不够大
- **关联笔记**: [[VLA]]、[[GeoVLA]]

### 12. Cycle-World: Mitigating Error Accumulation in Long-term Video World Models via Reverse-Prediction Cycle Consistency
- **作者**: Zihan Su, Teng Hu, Jiangning Zhang, Ruiyan Wang, Ran Yi, Lizhuang Ma, Dacheng Tao 等
- **机构**: Zhejiang University / Nanyang Technological University
- **链接**: [arXiv](https://arxiv.org/abs/2607.11836) | [PDF](https://arxiv.org/pdf/2607.11836)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2607.11836v1/x1.png)

- **核心方法**: Autoregressive diffusion video 生成在长程滚动中存在误差积累（错误叠加导致内容漂移）。Cycle-World 提出**逆向预测循环一致性**（Reverse-Prediction Cycle Consistency）：正向预测 frame t→t+1 的同时，约束 t+1→t 的逆向预测误差不超过阈值，形成闭环自约束。与 [[CausVid]]、[[Self-Forcing]] 等工作的区别在于 cycle 约束是显式的双向几何约束，而非单侧 regularization
- **对比方法/Baselines**: 对比 [[LongLive]]、[[CausVid]]、[[SkyReels]]，在长程视频生成上验证，用 [[RoPE]] 位置编码，与 [[Pyramid-Flow]] 比较
- **借鉴意义**: 对做 video world model 的人有直接价值——error accumulation 是长程预测的核心痛点，cycle consistency 是个干净的约束形式
- **锐评**: 方法设计简洁，逻辑清晰。但这篇没有直接在机器人控制任务上验证，只做了视频生成的定量指标（CGI、PACE），能否真的改善 world model 用于 planning，还需要下游任务验证
- **关联笔记**: [[World Model]]、[[CausVid]]、[[DiffusionForcing]]
- 💡 **想精读？** 运行：`读一下 Cycle-World: Mitigating Error Accumulation in Long-term Video World Models via Reverse-Prediction Cycle Consistency`

### 19. VIA: Visual Interface Agent for Robot Control
- **作者**: Hu, Hengyuan, Sundaresan, Priya, Gao, Jensen, Sadigh, Dorsa

- **链接**: [arXiv](https://arxiv.org/abs/2607.11119) | [PDF](https://arxiv.org/pdf/2607.11119)

### 20. WALA: Learning Executable Latent Actions from Action-Labeled Demonstrations and Action-Free Videos
