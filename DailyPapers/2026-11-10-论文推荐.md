## 世界动作模型 (WAM)

### 1. Diffusion-Steering-Based MPC with a JEPA World Action Model
- **作者**: Shashank Hegde, Alexander Popov, Elie Aljalbout, Nikolai Smolyanskiy
- **机构**: NVIDIA
- **链接**: [arXiv](https://arxiv.org/abs/2610.12407) | [PDF](https://arxiv.org/pdf/2610.12407)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2610.12407v2/figures/method/modes.png)

- **核心方法**: LeWAM 是在 [[LeWM]]（decoder-free JEPA 世界模型）基础上加入策略头，构建一个四任务统一的双向 Transformer：同时处理正向动力学、逆向动力学、逆向动作预测和策略预测，所有任务共享一个端到端训练的 JEPA latent。关键创新是把 MPC 的随机采样从"动作空间"移到"策略头的噪声空间"——用 Diffusion Steering 在噪声域规划，然后 decode 出动作，避免了 WAM 被动力学模型误差所利用。这让 MPC 在利用 WAM 的同时不会被它的不准确性反过来钻空子。
- **对比方法/Baselines**: 对比了 [[LeWM]]（前驱，仅有正向动力学无策略头）、[[DreamerV3]]、[[DINO-WM]]、[[V-JEPA 2-AC]]、[[UWM]]、[[Cosmos Policy]]。核心是对比 reconstruction-based WAM 和 JEPA-based WAM 在 latent 对齐质量上的差异。
- **借鉴意义**: 如果你在做 WAM + MPC 的组合，这篇是目前最干净的做法——diffusion steering 把 WAM 和策略的结合点从"动作输出"提前到"噪声空间"，思路值得借鉴。
- **锐评**: NVIDIA 出的，代码质量和实验设计都靠谱。四任务统一训练防止 feature collapse 的 multi-task 策略有意思；论文用 linear probe 定量展示了 latent 的可解释性，实验诚实。有一点：没有 real-robot 实验（`has_real_world=False`），全是 simulation，能不能泛化到真机有待观察。但方法层面没有明显硬伤，今天最强论文。🔥
- **关联笔记**: [[LeWM]] — LeWAM 的直接前驱，LeWM 是 decoder-free 单向正向世界模型

### 6. MDF++: Visuo-Tactile World Action Model with End-to-end Representation Learning
- **作者**: Zixuan Huang, Jinhao Yu, Zachary Charlick, Dmitry Berenson
- **机构**: University of Michigan, Ann Arbor
- **链接**: [arXiv](https://arxiv.org/abs/2611.09293) | [PDF](https://arxiv.org/pdf/2611.09293)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2611.09293v1/pull_fig.png)

- **核心方法**: MDF++ 是一个结合视觉和触觉传感的 World Action Model，核心改动是把预训练 encoder（通常被 frozen）换成与 diffusion backbone 端到端联合训练。训练策略用多任务学习（cross-modal correlation）防止特征坍缩：强制视觉 latent 和触觉 latent 保持互信息，不让一个 modality 被另一个压制。在螺栓拧紧、螺母配合等 contact-rich 任务上相比 frozen encoder WAM 提升 50%。
- **对比方法/Baselines**: 对比了 [[UWM]] 以及使用 frozen pretrained encoder 的标准 WAM 配置。在 bolt screwing 和 nut mating 任务上做了真实机器人实验。
- **借鉴意义**: 做触觉融合的人值得看。端到端训练 WAM encoder 并不是新想法，但这篇给了干净的实验证明，以及 feature collapse 的解决方案。
- **锐评**: 50% 的提升数字很好看，但任务只有三类 contact-rich 场景，泛化能力未知。论文说 "naive joint training leads to feature collapse"，但 multi-task 解决方案描述比较模糊，细节要看全文。触觉传感器本身的部署成本和标定难度摘要里没提，实际上这是落地的最大障碍。方向是对的，但工作量偏小。👀
- **关联笔记**: [[UWM]] — 对比基线，统一世界模型

- **机构**: University of Würzburg, Computer Vision Lab
- **链接**: [arXiv](https://arxiv.org/abs/2611.09625) | [PDF](https://arxiv.org/pdf/2611.09625)

![](https://arxiv.org/html/2611.09625v1/figures/bar_results.png)

- **对比方法/Baselines**: 对比基础 [[DreamerV3]]，以及 TWISTER 等其他测试时适应方法。主要在游戏类任务（需要记忆的场景）上验证，没有 robot 实验。

### 2. Meituan-Robotics-0: A Vision-Language-Action Foundation Model for Desktop Manipulation
- **作者**: Meituan Robotics Team（40+ 人）
- **机构**: Meituan Robotics
- **链接**: [arXiv](https://arxiv.org/abs/2611.08577) | [PDF](https://arxiv.org/pdf/2611.08577)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2611.08577v1/main_m42_clean_v2.png)

- **核心方法**: MR0 是美团机器人的 VLA foundation model，核心是三阶段训练：① 离散 action token 预训练（1.47 亿多模态视觉语言样本）；② 连续 cross-embodiment flow-matching 中训（15,060 小时机器人轨迹，12 种形态）；③ 真实环境 post-training。引入 Rollback 数据增强：从人工纠错视频中提取"被替换的策略片段 + 人工纠正"构成正负样本对，用 CFG-DAgger 进行监督而无需价值函数学习。统一末端执行器接口（EEF）和异步 action chunk merging 处理推理延迟。
- **对比方法/Baselines**: 对比了 [[π_0.5]]，在三个真实机器人任务上做了对比，平均成功率和 progress score 均更高。在 RoboTwin 2.0 达到 93.6%（Rank 5）。
- **借鉴意义**: 看数据集规模和多形态支持的工程细节，以及 Rollback 这个用纠错数据做正负监督的思路。工业界规模 VLA 的训练 recipe 参考价值很高。
- **锐评**: 93.6% 在 RoboTwin 2.0 是强数字，15,060 小时数据量诚意十足。Rollback 的思路新颖——把人工干预变成 DPO 风格的正负对比，不需要 value function，比 HG-DAgger 更轻量。但"stationary-base desktop manipulation"的范围限制明显，非桌面操作没有验证。工业界出的论文实验可信度高，但不要期待理论上的突破。🔥

### 3. VICTR: Value-Informed In-Context Learning for Vision-Language-Action Models
- **作者**: Luca Macesanu, Tianluo Zhang, Aditya Patil, Archit Sharma, Kevin Angers, Christopher M. Clark, Chen Feng, Juexiao Zhang
- **机构**: New York University
- **链接**: [arXiv](https://arxiv.org/abs/2611.08698) | [PDF](https://arxiv.org/pdf/2611.08698)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2611.08698v1/victr-pull-fig.png)

- **核心方法**: VICTR 解决 VLA in-context learning 中"视觉相似度不等于执行阶段相似度"的问题。核心模块是 IC-VFE（In-Context Value Function Estimator）：给定参考演示视频、语言指令和当前观测，估计相对任务进度（0-1 的完成度）。进度估计是以参考演示为条件的，所以能对齐未见任务的执行状态与演示的对应阶段。基于进度选择对应阶段的 demonstration chunk，提供给 [[π_0.5]] 策略生成 in-context 动作。
- **对比方法/Baselines**: 对比了 fine-tuned [[π_0.5]] baseline（6.2% 成功率）。在 out-of-domain 真实操作任务上，VICTR 达到 23.8% 成功率，task progress 从 28.9% 提升到 55.5%。
- **借鉴意义**: 进度感知 retrieval 是一个设计得很干净的 ICL 改进，对任何需要演示引导的策略都有参考价值。如果在做 few-shot 机器人学习，这个 value function estimator 的设计值得参考。
- **锐评**: 23.8% 听着不高，但 baseline 只有 6.2%，翻了近 4 倍，更重要的是在 out-of-domain 任务上验证的，说明有真实泛化能力。IC-VFE 的关键假设是有参考演示视频，实际部署时这个条件能不能满足需要考虑。论文里的 progress 估计做得怎么样，在 distribution shift 下准不准，这个 ablation 是关键——摘要里没提具体数字，要看全文。🔥

## VLA - 效率优化

### 4. ActPrune: Action-Grounded Visual Token Pruning for Efficient Vision-Language-Action Models
- **作者**: Sungwon Moon, Minji Kim, Hyemin Boo, Daeun Song, Jiyoung Lee
- **机构**: Ewha Womans University
- **链接**: [arXiv](https://arxiv.org/abs/2611.08827) | [PDF](https://arxiv.org/pdf/2611.08827)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2611.08827v1/fig1.png)

- **核心方法**: ActPrune 把 token 剪枝的决策时机从 visual encoder 编码之后提前到编码之前，利用上一帧的 action chunk 作为几何先验。对于固定第三视角摄像头：保留沿末端执行器预测轨迹投影的 patch + 语义锚点；对于腕部摄像头：剪掉因 action 引起的相机运动而"实际上没变化"的 patch。整个方法 training-free，不需要重新训练 VLA。
- **对比方法/Baselines**: 对比了 [[SparseVLM]]、[[DivPrune]]、[[FastV]] 等现有 token 剪枝方法。在 [[LIBERO]] 和 VLABench 仿真环境 + 4 个真实机器人任务上验证，1.61× 加速，59.5% FLOPs 减少。
- **借鉴意义**: Training-free 的属性让它可以即插即用到任何 VLA。如果你的 VLA 在实时性上有瓶颈，这篇是目前设计最合理的加速方案之一——因为它用了 task-aware 的几何先验，而不是通用的注意力分数。
- **锐评**: 思路清晰，几何先验的使用非常符合直觉。真实机器人实验 + 多个仿真环境，实验规模够用。有一个隐含假设：action chunk 准确——如果上一帧的 action prediction 偏差大，几何先验就不准了，这个鲁棒性没有显式 ablation。另外 1.61× 加速依赖于 59.5% FLOPs 减少，这个加速在真实推理链路（包括 KV cache、batch size 等因素）中能不能线性兑现，需要自己验证。👀

### 7. SURE: Spatiotemporal Uncertainty Representation for Efficient Vision-Language-Action Learning
- **作者**: Jingye Zhang, Choo Sin Wai, Dake Zhong 等
- **机构**: Tsinghua University
- **链接**: [arXiv](https://arxiv.org/abs/2611.09684) | [PDF](https://arxiv.org/pdf/2611.09684)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2611.09684v1/intro_image.png)

- **核心方法**: SURE 在 VLA 训练中显式建模时空不确定性。空间不确定性：加一个轻量的转置卷积概率动作解码器，用局部相邻动作 bins 的相关性捕获空间 uncertainty，不要求每个演示动作都是唯一的"正确答案"。时间不确定性：引入 Soft-DTW 对齐监督，允许预测动作序列和演示序列之间有局部时间偏移而不惩罚。两个模块合力减少对演示者特定姿态和执行节奏的依赖。
- **对比方法/Baselines**: 对比了 [[OpenVLA]]、[[OpenVLA-OFT]]，在 [[LIBERO]]、[[RoboTwin 2.0]] 以及真实操作任务上验证。10% 数据或 20% 训练步数可以达到基线相同的成功率。
- **借鉴意义**: 低数据效率场景下训 VLA 的好配方。Soft-DTW 解决 temporal shift 的思路值得直接借用——它早就在时间序列领域有应用，用到 VLA 训练里很自然但我还没见过其他人这样做。
- **锐评**: 10% 数据能达到基线性能是有吸引力的 claim，但具体是哪 10%（随机采样还是精选子集）对结论影响很大，这个细节要看全文确认。两个模块叠加，ablation 应该分别验证各自的贡献，摘要没提但应该有。整体是扎实的工程论文。👀

### 10. VLA Handover: Failure-Prediction-Based Switching from On-Robot to Server VLA Models
- **作者**: 来自 Institute of Science Tokyo
- **机构**: Institute of Science Tokyo
- **链接**: [arXiv](https://arxiv.org/abs/2611.08987) | [PDF](https://arxiv.org/pdf/2611.08987)

![](https://arxiv.org/html/2611.08987v1/fig_system.png)

### 14. ODEAction: From Predicting Chunks to Evolving Actions
- **作者**: 来自 Tsinghua, Fudan, Westlake 等多所高校
- **机构**: Beijing University of Posts and Telecommunications / Tsinghua / Fudan / Westlake 等

- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2611.09672v1/figure1.png)

- **核心方法**: ODEAction 把 VLA 的动作生成从"分块预测"换成"连续演化"。核心思路：把演示动作序列插值成连续轨迹，学习一个 action transition field，然后用 ODE 积分递推生成动作——相当于把 action chunk 的分段不连续问题通过 ODE 框架从根本上消除。在当前动作位置出发，ODE 解算器沿学到的向量场滑动到下一个动作。
- **对比方法/Baselines**: 在 [[RoboTwin]] 仿真环境上对比标准 VLA，有 real-world 实验（`has_real_world=True`）。
- **借鉴意义**: 如果你的 VLA 在 action chunk 边界有抖动问题（机械臂轨迹不平滑），这篇提供了一个理论更干净的解法。ODE-based 动作生成的计算开销是否可接受是关键问题。
- **锐评**: 思路有趣，ODE 是消除离散分块不连续的合理工具。但 ODE 积分的计算开销在实时闭环控制里是个现实问题——摘要没提推理延迟数据，要重点看。论文背后是多所学校合作，质量上应该够用，但这类"替换预测范式"的工作需要更大规模的 benchmark 验证。👀
- 💡 **想精读？** 运行：`读一下 ODEAction: From Predicting Chunks to Evolving Actions`
