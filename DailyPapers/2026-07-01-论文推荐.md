### 1. Event-VLA: Action-Conditioned Event Fusion for Robust Vision-Language-Action Model
- **作者**: Jiaxin Liu, Xun Xu 等
- **机构**: ShanghaiTech, HKUST(GZ), UMich, SJTU
- **链接**: [arXiv](https://arxiv.org/abs/2606.29384) | [PDF](https://arxiv.org/pdf/2606.29384)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.29384v1/x1.png)

- **核心方法**: 输入是 RGB 帧 + 事件相机流，输出是机器人动作序列。关键模块是 action-conditioned event fusion：用当前动作指令作为条件，引导事件流的注意力权重（[[CrossAttn]] cross-attention），把事件信息注入到 VLA 的视觉 token 中。与现有 VLA 的区别在于不是简单地拼接事件特征，而是用动作意图来选择性融合——相当于先"知道要做什么"再"看哪里"。在光照骤降、快速移动、遮挡三种扰动场景下分别测试，也与 [[OpenVLA]] OFT 做了 baseline 对比。
- **对比方法/Baselines**: 以 [[OpenVLA]] 为 base policy，baseline 包括 [[ACT]]；用 CKA 分析表征相似度，用 RMSE 评估动作精度。
- **借鉴意义**: 做 real-world VLA 部署的人必看。室内光照不稳定、机器人快速移动导致运动模糊是实际场景的常见故障，事件相机的方向比在正常光照下再堆 RGB 数据更可持续。
- **锐评**: score 9 拿了个第一，实至名归。方法动机清晰，有 real-world 验证，事件相机融入 VLA 是一个有实际价值的方向而不只是论文新颖性。唯一值得追问的是计算开销：事件相机流的处理速度是否跟得上实时推理。摘要没有给出延迟数字，需要全文确认。🔥

### 2. SA-VLA: State-aware tokenizer for improving Vision-Language-Action Models' performance
- **作者**: Tengyue Jiang 等
- **机构**: SJTU, East China University of Science and Technology, Hong Kong Polytechnic University, Xi'an UEST
- **链接**: [arXiv](https://arxiv.org/abs/2606.30113) | [PDF](https://arxiv.org/pdf/2606.30113)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.30113v1/tokenizer.png)

- **核心方法**: 输入是连续动作向量 + 机器人当前本体状态（proprioception），输出是离散 action token。现有的 VQ tokenizer（如 [[FAST]]、[[BET]]）把每个 codebook entry 固定映射到一个连续动作原型，忽略了机器人当前状态——同一个"抓握"动作在手臂伸直和弯曲时对应的关节角度完全不同。SA-VLA 在 codebook lookup 时引入 state conditioning，让量化的中心点随本体状态动态调整，减小 tokenizer 重建误差。
- **对比方法/Baselines**: 与 [[FAST]] tokenizer、BPE 离散化方案对比；在 [[RoboTwin]] 和 AgileX 平台上做实验，有 real-world 验证。
- **借鉴意义**: 任何用离散 action tokenization 的 VLA 都能套用。如果你在用 OpenVLA-OFT 类方案，这篇提供了一个即插即用的 tokenizer 改进方向。
- **锐评**: 解决的问题真实存在，方法逻辑干净。方法有 real-world 验证加分。唯一存疑的是 codebook collapse 问题：state conditioning 会不会让不同状态都压到相似的 code？摘要没有 ablation 细节，全文应该有。🔥

![](https://arxiv.org/html/2606.29892v1/x1.png)

- **核心方法**: 输入是 VLA 推理时的 token 概率分布，输出是自监督的 reward 信号，用于测试时 RL 微调。核心观察：在离散 action token 的 VLA 中，token 序列的概率可以用 DTW（动态时间规整）和专家轨迹对比生成 pseudo reward，从而不需要环境交互或人工标注的成功信号就能做 GRPO 优化。

### 6. Training Vision-Language-Action Models with Dense Embodied Chain-of-Thought Supervision
- **作者**: Li Haoyang, Li Guanlin, Feng Youhe 等
- **机构**: Renmin University of China, Zhipu AI
- **链接**: [arXiv](https://arxiv.org/abs/2606.30552) | [PDF](https://arxiv.org/pdf/2606.30552)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.30552v1/x1.png)

- **核心方法**: 输入是 RGB + 语言指令，输出是 dense chain-of-thought（场景感知 → 目标识别 → 任务规划 → 子任务分解）+ 动作序列。核心观点：不同 embodiment 的 low-level action/state 空间差异大，但 high-level 认知过程（看什么、怎么分解任务）是跨 embodiment 共享的。ZR-0 用 dense CoT 监督信号来让 VLA 学习这个共享的认知层，从而提升 cross-embodiment 迁移。训练数据包括 [[LIBERO]]、[[RoboTwin]]、[[RoboCasa]] 和 RoboTwin2。
- **对比方法/Baselines**: 对比 [[GR-1]] 和其他 VLA baseline；有 cross-embodiment 迁移实验。
- **借鉴意义**: 如果你在做 cross-embodiment 或 multi-task VLA，dense CoT 监督是一个值得尝试的方向——不需要改架构，只需要更丰富的标注。
- **锐评**: 方向对，但"dense CoT 监督"需要大量高质量标注数据，成本不低。摘要没说清楚这些 CoT 标注是怎么来的（人工？LLM生成？），这是最关键的 scalability 问题。如果是 LLM 生成，那 CoT 质量的上限就是 LLM 自身能力，circular 风险存在。👀

### 7. TAP-VLA: Tactile Annotation Prompting for Vision Language Action Models
- **作者**: Van der Merwe Mark, Shehab Mohamad Louai, Lee Jayjun 等
- **机构**: University of Michigan (Robotics + CSE Departments)
- **链接**: [arXiv](https://arxiv.org/abs/2606.29089) | [PDF](https://arxiv.org/pdf/2606.29089)
- **来源**: 📄 arXiv 关键词检索

### 8. Fast Enough to Act: Spatio-Temporal Visual Token Merging for Low-Latency Robotic VLMs and VLAs

- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.29350v1/x1.png)

- **核心方法**: 输入是视频帧序列（含大量视觉 token），输出是合并后的精简 token 序列，喂给 VLA 推理。ST-Merge 在时间维度和空间维度上同时做 token merging：时间上合并相邻帧的相似 token，空间上合并同帧内的冗余 patch。Plug-and-play，training-free，无需重新训练 VLA 模型。与 [[ToMe]]、[[FastV]]、[[TempMe]] 等做了对比，有 real-world 验证。

### 14. X-Mind: Efficient Visual Chain-of-Thought via Predictive World Model for End-to-End Driving
- **作者**: Zhao Bohao, Wei Chengrui 等
- **机构**: 未知（未提取完整机构信息）
- **链接**: [arXiv](https://arxiv.org/abs/2606.28758) | [PDF](https://arxiv.org/pdf/2606.28758)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.28758v1/x1.png)

- **核心方法**: X-Mind 把 Predictive World Model（PWM）无缝嵌入大型驾驶模型的内部层（而非串联），通过 Recurrent Block Diffusion 在单次 forward pass 中完成多步去噪，生成压缩的"抽象草图"作为未来状态预测，指导当前动作决策。输入是多视角图像 + 过去 BEV 表示，输出是未来轨迹。核心卖点是 latency：一次 forward 而非串联调用。
- **对比方法/Baselines**: DiffusionDrive、UniAD 类方法；在自动驾驶 benchmark 上有 ADE 指标对比。
- **借鉴意义**: PWM 嵌入 VLA 而非串联 VLA，这个思路同样适用于机器人操作的 world model + policy 融合，值得关注。
- **锐评**: 自动驾驶应用，和我们 robotics 方向相关性适中。但把 WM 嵌入模型内部（而非外部串联）的思路很有启发性——如果迁移到 manipulation，可以大幅降低推理延迟。has_real_world: False，全是 sim/benchmark。👀
- 💡 **想精读？** 运行：`读一下 X-Mind: Efficient Visual Chain-of-Thought via Predictive World Model for End-to-End Driving`

### 15. Learning Transferable Dynamics Priors from Action to World Modeling
- **作者**: Ze Huang, Jiahui Zhang, Hairuo Liu, Chenxi Zhang 等
- **机构**: Fudan University, Shanghai Innovation Institute, SJTU, McGill University
- **链接**: [arXiv](https://arxiv.org/abs/2606.29501) | [PDF](https://arxiv.org/pdf/2606.29501)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.29501v1/x2.png)

- **核心方法**: 输入是机器人操作视频 + 动作序列，输出是可迁移的 dynamics prior。A2World 用 action-conditioned multi-view interactive [[DiT]] 做 diffusion world model 预训练，让模型学会"动作如何改变场景"这一可复用的交互动力学。预训练后的 dynamics prior 迁移到下游任务：VLA 行动预测、world model 生成、OOD 泛化。训练数据覆盖 [[DROID]]、AgiBot、WidowX 等多个机器人平台。[[MoE]]（Mixture of Experts）用于跨平台适配。

- **借鉴意义**: 做 world model 预训练的同学必看。如果你想用 world model 作为 data augmentation 或 policy 的初始化，A2World 提供了一个严肃的方案——预训练 dynamics prior 而不仅仅是视频生成。
- **锐评**: 方向好，execution 扎实，多平台训练有说服力。用 DiT + MoE 做跨平台 adaptation 比简单 fine-tune 有更好的理论依据。有 real-world 验证加分。唯一需要追问的是 prior 迁移的极限：当动作空间差异极大（比如从 6-DOF arm 迁移到 dexterous hand）时还能 work 吗？🔥
- **关联笔记**: [[WAM-Survey]] — 可结合 world action model 综述来定位 A2World 在整个框架中的位置

### 17. RoboGaze: Evaluating Robot World Models via Structured Vision-Language Analysis

- **机构**: VinUniversity, VinRobotics, DFKI, TU Darmstadt
- **链接**: [arXiv](https://arxiv.org/abs/2606.28385) | [PDF](https://arxiv.org/pdf/2606.28385)

## 今日趋势

VLA 已经从"能不能 work"进入"怎么让它在真实世界更 robust"的阶段——Event-VLA 做的事情（低光照鲁棒性）、TAP-VLA 做的事情（触觉感知）、ST-Merge 做的事情（降延迟）都是落地工程问题，说明 VLA 的基础能力已经被接受，下一步是部署环境适应性。World model 这边 A2World 的 dynamics prior 预训练是个值得跟的方向——不是用 WM 生成视频，而是用 WM 学 dynamics 然后迁移给 policy，这个思路比单纯 video generation 更有实际价值。
