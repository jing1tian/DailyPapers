> ⏪ **再推提醒**：这篇在 2026-05-21 推荐过

![](https://arxiv.org/html/2605.20150v1/x1.png)

- **核心方法**: TideGS 解决 3DGS 在超大规模场景下的显存瓶颈。核心是 Out-of-Core 优化策略：将 Gaussian 参数表从 VRAM 迁移到 DRAM（CPU 内存），通过 Sparse Working Set 机制只把当前渲染需要的 Gaussian 子集加载进 GPU。配合 CLM（Chunk-Level Management）和 TSP（Task Scheduling Protocol）管理数据搬运，实现单 GPU 上十亿级 Gaussian 训练，突破了此前受 VRAM 限制的数千万上限。
- **对比方法/Baselines**: 对比标准 3DGS [[NeRF]] 体系；在 [[MatrixCity]] 和 BigCity 大规模场景上评估
- **借鉴意义**: 大规模城市级场景重建对 autonomous driving 和 outdoor robot navigation 有直接价值；十亿级 Gaussian 对 [[GaussianDream]] 类 world model 方向也是基础技术储备
- **锐评**: 工程论文，把显存问题解决得很干净。upvote 才 7 说明社区关注度低，但这种基础设施工作往往低调高价值。唯一的问题是 Out-of-Core 带来的 CPU-GPU 搬运延迟——训练速度损失多少，摘要没说，等全文数据。 👀

### 8. Gated DeltaNet-2: Decoupling Erase and Write in Linear Attention
- **作者**: Ali Hatamizadeh, Yejin Choi, Jan Kautz（NVIDIA）
- **机构**: NVIDIA
- **链接**: [arXiv](https://arxiv.org/abs/2605.22791) | [PDF](https://arxiv.org/pdf/2605.22791)
- **来源**: 🔥 HF Trending，⬆️ 21

- **核心方法**: Gated DeltaNet-2 改进线性注意力的状态更新机制。标准线性注意力把"遗忘旧信息"和"写入新信息"耦合在一起，导致写新内容时会无意破坏已有关联。GDN-2 引入独立的 erase gate 和 write gate（类似 LSTM 的解耦设计），允许精确编辑固定大小的循环状态而不干扰无关记忆。推导出和 [[KDA]]（Kernel Delta Attention）等价的 chunkwise 计算形式，保持 O(L) 训练效率。
- **对比方法/Baselines**: 对比 GDN-1（前版）、标准 Mamba、Transformer；在 [[RULER]]、[[NIAH]] 系列任务上评测长程依赖；借鉴 WY 表示和 SWA 滑动窗口
- **借鉴意义**: 线性注意力对长序列 robot trajectory 建模有潜在价值；erase/write 解耦对需要精确状态更新的 world model recurrent 架构有参考意义
- **锐评**: 今天唯一真正新的论文。从理论上把 erase/write 解耦讲清楚了，数学推导严谨，NIAH 任务提升明显。upvote 才 21 说明关注度不高，可能因为线性注意力赛道已经很拥挤——Mamba、RetNet、GLA 等等。核心问题：真实长序列任务（不是 benchmark）上和 softmax attention 差距多大？值得追踪但不用急着读。 👀
