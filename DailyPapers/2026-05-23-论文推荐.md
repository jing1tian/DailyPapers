### 1. World Action Models: The Next Frontier in Embodied AI
- **作者**: Wang, Siyin; Shi, Junhao; Fu, Zhaoyang; He, Xinzhe; Liu, Feihong; Yang, Chenchen; Zhou, Yikang et al.
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2605.12090) | [PDF](https://arxiv.org/pdf/2605.12090)
- **来源**: 🔥 HF Trending，⬆️ 64

- **核心方法**: 这是一篇系统综述/position paper，梳理了"World Action Model（WAM）"这一新兴范式——在 VLA 的 observation-to-action 映射基础上显式建模物理世界的演化。核心主张：当前 VLA 缺乏对干预后世界状态变化的显式预测能力，WAM 通过将世界模型（预测未来状态/图像/latent）与动作策略深度融合来填补这一缺口。综述按"生成方式"和"预测粒度"两个维度对现有工作分类，涵盖从 RSSM 类到 Diffusion/AR 类 WM 的完整谱系，并提出 WAM 作为 Embodied AI 下一前沿的理论框架。
- **对比方法/Baselines**: 综述性质，覆盖 [[DreamerV3]]、[[IRIS]]、[[MuJoCo]] 系列等 RL 世界模型，以及 [[π0]]、[[OpenVLA]] 等 VLA 基线；借鉴 [[GR00T]] 框架设计的通用性讨论。
- **借鉴意义**: 做 world model + robot 的人必看。把现有碎片化工作串起来给了一个统一视角，避免重复造轮子。
- **锐评**: 64个 HF upvote 不是没有道理。WAM 这个名字起得有点刻意蹭热度（WAM ≈ WAM survey 跟论文本身命名有出入），而且"world model + VLA = WAM"这个公式是否真的需要一个新名字值得商榷。但综述质量看摘要确实扎实，分类框架有参考价值。没有 real-world 实验是综述的天然局限，不该苛求。整体属于方向梳理类必备文献。 🔥

### 12. Beyond Euclidean Proximity: Repairing Latent World Models with Horizon-Matched Trajectory Reachability Metrics
- **作者**: Li, Liangyu; Wang, Shengzhi; Liu, Qingwen
- **机构**: Tongji University
- **链接**: [arXiv](https://arxiv.org/abs/2605.22164) | [PDF](https://arxiv.org/pdf/2605.22164)
- **来源**: 📄 arXiv 关键词检索

- **核心方法**: 发现 latent MPC 的一个根本性缺陷：用 Euclidean 距离在 latent space 里比较 terminal state 和 goal state 隐含"latent 距离 = 行为距离"的假设，但这个假设在非线性 latent space 里根本不成立。提出 TRM（Trajectory Reachability Metric）——用 horizon-matched 的轨迹可达性度量替换 Euclidean 距离，使 planner 用与任务实际 horizon 匹配的决策相关信息来评估候选序列。在 [[PLDM]]、[[LeWM]] 框架上验证，PushT、TwoRoom 环境。
- **对比方法/Baselines**: [[PLDM]]、[[LeWM]]（直接改进基线）；评估环境：PushT、TwoRoom；借鉴 [[DreamerV3]] 的 latent 控制框架设计。
- **借鉴意义**: 如果你在用 latent world model 做 MPC 规划，TRM 值得试。核心洞察（Euclidean 距离不适合 latent 目标匹配）是真实存在的问题，但只在仿真环境验证了。
- **锐评**: 问题定义精准，是那种"说出来大家都知道但没人系统解决"的问题。Tongji 做的，没有 real-world 实验，只跑了 PushT 和 TwoRoom 这两个玩具环境，泛化性存疑。方法本身不复杂，实现难度低，值得当作一个 trick 放进 MPC 管道里。 👀

### 23. Identifiable Token Correspondence for World Models
- **作者**: Youngin Kim, Ray Sun, Inho Kim, Bumsoo Park, Hyun Oh Song
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2605.16457) | [PDF](https://arxiv.org/pdf/2605.16457)
- **来源**: 📄 arXiv 关键词检索

- **核心方法**: 针对基于 token 的 transformer world model 在长 horizon rollout 中出现的时序不一致问题（物体重复、消失、变形），提出 ITC（Identifiable Token Correspondence）。核心机制：在 token 表示中引入可识别性约束，使每个 token 在跨时间步的 rollout 中保持稳定的对应关系，防止 token 身份在预测过程中"漂移"。在 [[DreamerV3]]、[[IRIS]]、[[STORM]] 等主流 WM 框架上验证，MinAtar 和 Atari 游戏环境。
- **对比方法/Baselines**: 对比 [[DreamerV3]]、[[IRIS]]、[[STORM]]、[[DART]]；使用 PPO 做下游 RL；VQ（Vector Quantization）作为 token 化机制基础。
- **借鉴意义**: 做基于 token 的 world model 或者 video generation 的人都值得看——token 时序对应关系是个普遍问题，不只是 WM 独有。
- **锐评**: 切入点很准，长 horizon 里的 token 身份漂移确实是 IRIS 类方法的已知痛点。但只在 Atari/MinAtar 游戏环境上验证，距离 robot manipulation 或者真实世界应用还差很远。IQM 指标上的提升是否有 real-world 意义需要后续工作证明。方法本身有扎实的理论动机。 🔥
- **关联笔记**: [[World Model]]、[[DreamerV3]]（直接对比基线）

### 2. GesVLA: Gesture-Aware Vision-Language-Action Model Embedded Representations
- **作者**: Guo, Wenxuan; Li, Ziyuan; Zhang, Meng; Liu, Yichen; Dong, Yimeng; Xu, Chuxi; Wei, Yunfei; Chen, Ze et al.
- **机构**: Tsinghua University, Dexmal
- **链接**: [arXiv](https://arxiv.org/abs/2605.22812) | [PDF](https://arxiv.org/pdf/2605.22812)
- **来源**: 📄 arXiv 关键词检索

- **核心方法**: 解决 VLA 在多相似物体场景下依赖纯文本指令无法消歧的问题。GesVLA 在 [[PaliGemma]] backbone 上引入手势感知模块：用 [[MediaPipe]] 实时追踪用户手势，通过 [[GroundingDINO]] 将手势指向映射到目标物体，生成带有空间锚点的嵌入表示，再送入动作解码器。输入是图像 + 文本 + 手势；输出是动作序列。有 real-world 实验。
- **对比方法/Baselines**: 基于 [[PaliGemma]] 做 backbone；用 [[GroundingDINO]] 做开放词汇目标检测；[[MediaPipe]] 做手势追踪；对比 VLA 基线的文本-only 版本。
- **借鉴意义**: 人机交互方向的工作。如果你在做 human-in-the-loop 或者 assisted teleoperation，手势+VLA 这个结合有实际应用价值。
- **锐评**: 想法直接，手势消歧是真实场景中存在的问题。但 MediaPipe + GroundingDINO 的方案工程感强、学术创新弱——感觉是拼积木而不是做方法创新。有 real-world 实验是加分项。泛化能力（多少种手势、复杂场景下手势追踪鲁棒性）需要看完整文才能判断。 👀

### 3. Pre-VLA: Preemptive Runtime Verification for Reliable Vision-Language-Action and World-Model Rollouts
- **作者**: Zhen Sun et al.
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2605.22446) | [PDF](https://arxiv.org/pdf/2605.22446)
- **来源**: 📄 arXiv 关键词检索

- **核心方法**: 在 VLA/WM 执行前做"预先运行时验证"——先用轻量 world model 对候选动作序列做前向预测，检测是否可能产生物理失败或分布外行为，只有通过验证的动作才发给执行器。架构包含 Dual-Branch 结构：主 VLA 生成候选动作，WM 前向预测未来状态，OOD 检测器（基于 [[NoiseGate]] 机制）判断是否安全。用 [[LIBERO-10]] 和 [[WorldVLA]] 做评估，配合 [[OpenVLA]] 基线。
- **对比方法/Baselines**: 基线 [[OpenVLA]]、[[RynnVLA]]；评估 benchmark [[LIBERO-10]]；使用 PPO 和 WMPO 做训练；参考 [[ARGUS]] 方法。
- **借鉴意义**: 安全部署 VLA 的方向。如果你关心 robot 的 deployment reliability 而不只是 task success rate，这个思路值得参考。
- **锐评**: 把 world model 当安全过滤器而不是策略优化器，角度新颖。但有一个根本性的循环问题没解决：如果 world model 本身就不准确（这在 real world 里是常态），那预验证的结果也不可信。实验只在 LIBERO 仿真环境做，real-world 鲁棒性完全未知。idea 好，但距离实用还早。 👀

### 6. Spatial Memory for Out-of-Vision Manipulation in Vision-Language-Action (SOMA)
- **作者**: Pengteng Li, Weiyu Guo, He Zhang, Tiefu Cai, Xiao He, Yandong Guo, Hui Xiong
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2605.22283) | [PDF](https://arxiv.org/pdf/2605.22283)
- **来源**: 📄 arXiv 关键词检索

- **核心方法**: SOMA 解决 VLA 假设"目标始终可见"这个硬伤。当目标物体移出相机视野（Out-of-Vision, OOV），现有 VLA 直接失效。SOMA 引入空间记忆模块：用 [[VGGT]] 从历史帧建立 3D 空间记忆，当目标 OOV 后可从记忆中检索目标的空间位置，生成带有空间锚点的 token 注入 VLA 解码器（基于 DiT 架构）。输入：当前图像 + 语言 + 历史帧记忆；输出：动作。在 [[SimplerEnv]]、[[RoboCasa]] 仿真 + 真实机械臂做了实验（`has_real_world=True`）。
- **对比方法/Baselines**: 对比 [[StarVLA]]、[[SpatialVLA]]、[[GR-1]]；评估 [[SimplerEnv]]、[[RoboCasa]]；依赖 [[VGGT]] 做 3D 感知，基于 DiT 架构解码器。
- **借鉴意义**: 解决了 VLA 部署中一个实际存在但被忽视的问题。任何做 table-top manipulation 或 mobile manipulation 的人都会遇到目标出视野的情况。
- **锐评**: 问题定义扎实，有 real-world 实验，是今天少数几篇真正解决实际问题的 VLA 工作。用 VGGT 建 3D 空间记忆的方案工程上不轻量，inference 开销是关键问题（摘要未提及延迟）。RoboCasa 的成功能否迁移到更复杂的开放场景？需要更多实验。整体属于有货的工作。 🔥

### 8. From Abstraction to Instantiation: Learning Behavioral Representation for VLA (BehaviorVLA)
- **作者**: Bing Hu, Zaijing Li, Rui Shao, Junda Chen, April Hua Liu, Wei-Shi Zheng, Liqiang Nie
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2605.22671) | [PDF](https://arxiv.org/pdf/2605.22671)
- **来源**: 📄 arXiv 关键词检索

- **核心方法**: 解决 VLA 在分布偏移下行为表征退化问题。BehaviorVLA 提出两级表征框架：Abstract Level（VBE，Visual Behavior Encoder）捕获跨环境的通用行为语义，Instantiation Level（PBD，Phase-Conditioned Behavior Decoder）将抽象表征实例化为具体动作序列。用 [[RoboTwin2]]、[[CALVIN]]、[[LIBERO]] 多环境训练，引入 Prior-Guided 训练策略避免表征坍缩，参考 [[OpenVLA]]、[[RDT]] 做对比。
- **对比方法/Baselines**: 基线 [[OpenVLA]]、[[RDT]]；评估 [[RoboTwin]]、[[CALVIN]]、[[LIBERO]]；借鉴 [[OFT]]（Orthogonal Fine-Tuning）做参数高效学习。

### 10. EvoScene-VLA: Evolving Scene Beliefs Inside the Action Decoder for Chunked Robot Control
- **作者**: Chushan Zhang et al.
- **机构**: Australian National University, University of Queensland, Beijing Normal University
- **链接**: [arXiv](https://arxiv.org/abs/2605.21862) | [PDF](https://arxiv.org/pdf/2605.21862)
- **来源**: 📄 arXiv 关键词检索

- **核心方法**: 针对 Chunked VLA 的视觉更新延迟问题。当前 VLA 每隔 N 步才更新视觉观察，chunk 内动作完全基于"陈旧"的视觉条件预测，但这段时间里场景（接触、遮挡、物体运动）已经变化。EvoScene-VLA 在动作解码器内加入循环场景前缀（recurrent scene prefix）：用 SlotSSM 维护场景状态的连续时序演化，每步解码都能"感知"场景变化，而不需要等待下一次视觉更新。有 real-world 实验。对比 [[OpenVLA]]、[[SpatialVLA]]、[[ManiGaussian]]、[[MemoryVLA]]。
- **对比方法/Baselines**: 基线 [[OpenVLA]]、[[SpatialVLA]]、[[TraceVLA]]；借鉴 [[MDT]]（Masked Diffusion Transformer）；在 [[RoboTwin]] 上评估；参考 [[MemoryVLA]] 概念。
- **借鉴意义**: Chunked VLA 的时序盲区是真实问题。SlotSSM 在解码器内维护场景演化这个设计值得借鉴。
- **锐评**: 问题切入精准，解决的是 chunked policy 里一个容易被忽视的 latency 问题。SlotSSM 集成进解码器的方案工程复杂度增加了多少没说清楚，inference 延迟是否可接受需要看完整实验。有 real-world 实验加分。 👀
- **关联笔记**: [[MemoryVLA]]（相关概念，场景记忆）

### 21. Action with Visual Primitives (AVP)
- **作者**: Weilong Guo, Anyverse Dynamics
- **机构**: Anyverse Dynamics, Tsinghua University
- **链接**: [arXiv](https://arxiv.org/abs/2605.22183) | [PDF](https://arxiv.org/pdf/2605.22183)
- **来源**: 📄 arXiv 关键词检索

- **核心方法**: 当前 VLA 把语言指令和视觉观察在单一 forward pass 里直接映射到动作，指令理解和视觉感知高度耦合。AVP 把动作预测分解为两阶段：先从当前图像提取"视觉原语"（Visual Primitives）——可能是关键点、affordance、物体状态等视觉抽象中间表示；再基于视觉原语生成动作。使用 [[SAM]] 做分割，跨域泛化（Cross-Domain）。有 real-world 实验，对比 [[OpenVLA]]、[[RT-2]]。
- **对比方法/Baselines**: 基线 [[OpenVLA]]、[[RT-2]]；使用 [[SAM]] 做分割；参考 [[LDA]] 做视觉表征学习。
- **借鉴意义**: 视觉原语作为中间表征的思路在 affordance learning 领域有渊源，VLA 里加进来的新意在于端到端训练。值得关注作为 VLA 解耦的一种实现方式。
- **锐评**: 单作者（Weilong Guo，Anyverse Dynamics）。Visual Primitives 的概念不新，affordance 相关工作已经做了很多年。这里的创新是把它整合进 VLA 流水线，但"视觉原语"具体是什么（关键点？affordance map？物体状态？）从摘要看不清楚，需要读全文。有 real-world 实验是加分项。 👀
- **💡 想精读？** 运行：`读一下 Action with Visual Primitives`

### 22. SONIC: Supersizing Motion Tracking for Natural Humanoid Whole-Body Control
- **作者**: Zhengyi Luo, Ye Yuan, Tingwu Wang, Chenran Li, Fernando Castañeda, Sirui Chen, Zi-Ang Cao et al.
- **机构**: NVIDIA
- **链接**: [arXiv](https://arxiv.org/abs/2511.07820) | [PDF](https://arxiv.org/pdf/2511.07820)
- **来源**: 📄 arXiv 关键词检索

- **核心方法**: 针对人形机器人神经控制器"规模不够大"的问题。SONIC 做全身运动跟踪（whole-body motion tracking），用 FSQ（Finite Scalar Quantization）对运动序列做 token 化，PPO 训练大规模运动跟踪策略，显式建模 SMPL 人体模型。扩展数据规模（运动捕捉数据量 10x+）、模型规模、计算量，测量对 OOD 运动内容的泛化曲线。在 NVIDIA 仿真环境 + PICO VR 设备做 real-world 验证。
- **对比方法/Baselines**: 参考 [[OpenHomie]]、[[BeyondMimic]]、[[PHUMA]]；使用 SMPL 做人体建模；评估 MPJPE 指标；VR（PICO）做控制接口。
- **借鉴意义**: 人形机器人控制的 scaling law 研究。如果你在做 humanoid，SONIC 给出了数据/模型/计算 scaling 对运动跟踪的实证结论。
- **锐评**: NVIDIA 出品，团队阵容（Zhengyi Luo, Ye Yuan 都是运动合成领域的知名研究者）有保证。Scaling + 运动跟踪的组合是当前人形机器人的热点，实验在 PICO VR 上有 real-world 验证。FSQ token 化运动的方案不是第一次被提出，但这个规模的系统性 scaling 研究确实罕见。MPJPE 指标是运动质量的指标，但运动跟踪准确度和实际任务完成率之间的关系论文没说清楚。 🔥

- **作者**: Jiang, Peifeng; Liu, Hong; Jin, Jin; Wang, Wenshuai; Li, Xia

### 4. PhysX-Omni: Unified Simulation-Ready Physical 3D Generation for Rigid, Deformable, and Articulated Objects
- **作者**: Cao, Ziang; Liu, Yinghao; Li, Haitian; Yao, Runmao; Hong, Fangzhou; Chen, Zhaoxi; Pan, Liang; Liu, Ziwei et al.

### 9. TideGS: Scalable Training of Over One Billion 3D Gaussian Splatting Primitives via Out-of-Core Optimization
- **作者**: Zhong, Chonghao; Shi, Linfeng; Chen, Hua; Sun, Tiecheng; Zhao, Hao; Yuan, Binhang; Li, Chaojian
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2605.20150) | [PDF](https://arxiv.org/pdf/2605.20150)
- **来源**: 🔥 HF Trending，⬆️ 6

- **核心方法**: 解决 3DGS 大规模训练的显存瓶颈。标准 3DGS 每个 Gaussian 需要大属性向量，参数表快速超出 GPU 显存（VRAM）容量，限制至几千万 Gaussian。TideGS 用 out-of-core 优化：将 Gaussian 参数分块存在 DRAM/SSD 中，训练时按需调入 GPU，用 TSP（Tile Streaming Protocol）管理数据流，实现超过 10 亿 Gaussian 的训练（在 MatrixCity 大场景上验证）。
- **对比方法/Baselines**: 对比 CLM（标准 3DGS）；评估 MatrixCity、BigCity 大规模场景；硬件 RTX GPU + DRAM out-of-core。
- **借鉴意义**: 做大场景 3DGS 的工程团队直接关注。对做 embodied AI 的人间接价值（大场景重建可用于仿真数据生成）。
- **锐评**: 基础设施工作，工程价值明确但学术新意一般。10 亿 Gaussian 听起来很猛，但渲染质量（PSNR/SSIM）提升了多少？只是"能训"不代表"训出来好"。HF 只有 6 个 upvote 反映了社区的实际兴趣度。对机器人任务直接价值有限。 💤

### 28. ForeSplat: Optimization-Aware Foresight for Feed-Forward 3D Gaussian Splatting
- **作者**: Yuke Li et al.
- **机构**: ShanghaiTech University
- **链接**: [arXiv](https://arxiv.org/abs/2605.22020) | [PDF](https://arxiv.org/pdf/2605.22020)

- **核心方法**: 前馈 3DGS 速度快但质量比 per-scene 优化差，predict-then-refine 的折中方案让优化过程引导预测改进。ForeSplat 用 meta-learning（[[MAML]]/[[FOMAML]]）让前馈模型在 predict 阶段就"预见"后续优化的梯度方向，使初始预测更接近优化后的最终结果，减少精化步数。在 [[AnySplat]]、[[InstantSplat]]、[[LRM]] 上做 meta-training。

### 27. Rethinking Token Reduction for Diffusion Models via Output-Similarity-Awareness (DiTo)
- **作者**: Hangyeol Lee, Hyojeong Lee, Joo-Young Kim
- **机构**: KAIST
- **链接**: [arXiv](https://arxiv.org/abs/2605.22011) | [PDF](https://arxiv.org/pdf/2605.22011)
- **来源**: 📄 arXiv 关键词检索

- **核心方法**: DiT（Diffusion Transformer）的 token 裁剪方法普遍忽视生成目标（最小化输出差异），只考虑 token 之间的特征相似性作为裁剪依据。DiTo 提出以输出相似性（Output-Similarity）为指导的 token 裁剪，选择裁剪后对最终生成结果影响最小的 token。在 DiT-XL、ImageNet 上评估，对比 [[ToMeSD]]、[[ToFu]]、[[SiTo]]、[[ATS]] 等现有 TR 方法。
- **对比方法/Baselines**: 对比 [[ToMeSD]]、[[ToFu]]、[[SiTo]]、[[ToMA]]、[[ATS]]；基础模型 DiT-XL、FlashAttention2；ImageNet 评估。
- **借鉴意义**: 做扩散模型推理加速的值得看。DiTo 的核心洞察（特征相似 ≠ 输出相似）有普遍性。对 diffusion policy 推理速度有间接价值。
- **锐评**: KAIST 的工作，逻辑清晰，问题定义精准。但只在静态图像生成（DiT-XL + ImageNet）上验证，扩散策略（Diffusion Policy for robot）的 token 结构完全不同，能否迁移是问题。学术贡献扎实，应用价值待观察。 💤
