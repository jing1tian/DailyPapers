# 双路径条件注入（Dual-Path Conditioning）

**双路径条件注入**是 [[ForeTimeVLA]] 提出的架构机制，将预测的未来状态编码通过**慢速语义路径**和**快速动作路径**两条并行通道注入 [[pi0.5|π₀.₅]] 策略，使策略同时获得高级语义预见和低级动作精调信号。

## 两条路径

### 慢速 VLM 路径（Slow Path）

- **输入**: 64维预测未来编码 $\hat{z}_t$
- **处理**: 线性投影 → 4个2048维 future token；相位分布期望嵌入 → 1个2048维 phase token
- **注入位置**: π₀.₅ 的 VLM 前缀（prefix），共5个额外 token
- **作用**: 将时序预见暴露给高层语义语言-视觉模型，影响全局策略理解

### 快速动作专家路径（Fast Path）

- **输入**: 64维 $\hat{z}_t$ + 标量时间到转换 $\hat{d}_t \in [0,1]$
- **处理**: 线性投影 → 1024维残差特征
- **注入位置**: 动作专家 suffix 的每个 token 及其自适应归一化条件
- **作用**: 给动作解码器提供直接的预测编码和转换时间窗口信号，影响精细动作执行

## 设计要点

- 两路径各有**学习标量门控**，初始化为0.05，避免训练早期扰动预训练权重
- 总新增参数 1.251M，相对 π₀.₅ 的 ~2B 参数几乎可忽略
- 消融实验（Table III）验证仅慢路径或仅快路径均不如完整双路径
