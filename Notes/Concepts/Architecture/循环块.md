# 循环块 (Loop Block)

## 定义

一种在 [[Vision-Language-Action Model|VLA]] 中用于循环精炼多模态表示的 **共享权重 Transformer 模块**：同一组参数被迭代应用 $N$ 次，每次迭代渐进提升表示质量，替代传统深层 Transformer 中每层独立的参数。

## 数学形式

$$
h^{(n)} = \mathrm{LoopBlock}(h^{(n-1)}; M), \quad n = 1, \dots, N
$$

其中 $M$ 为共享参数，$h^{(0)}$ 为感知锚层（Perceptual Anchor Layers）的输出。

## 核心要点

1. **权重共享**: 所有 $N$ 次迭代共用同一套 [[Transformer]] 参数，相比 $L \times N$ 层独立 Transformer 参数量减少约 45%。
2. **[[因果注意力|因果注意力掩码]]**: Action tokens 只能关注视觉/语言上下文，不能看到其他 Action tokens 未来的信息。
3. **感知锚定**: 每次循环前注入来自感知锚层的稳定低层视觉特征，防止多次迭代导致低层几何信息丢失。
4. **配置记法 $L \otimes N$**: $L$ 为感知锚层数，$N$ 为循环迭代次数，如 3⊗8 表示 3 层锚层 + 8 次迭代。
5. **与深层 Transformer 的权衡**: 更多迭代次数提升精炼能力，但过少层数会限制初始表示质量（消融：3⊗8 和 4⊗6 最优）。

## 代表工作

- [[LoopVLA]]: 首次在 VLA 中引入 Loop Block，以 1.2B 参数在 LIBERO 达 96.0% 成功率，超越 4B 级基线。
