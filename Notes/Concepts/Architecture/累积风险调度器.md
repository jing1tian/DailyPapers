# 累积风险调度器（Cumulative Hazard Scheduler）

## 定义
将[[累积风险函数|生存分析中的累积风险框架]]应用于视频去噪过程，使用轻量 MLP 在每步预测停止风险增量，动态决定何时终止去噪并将当前视频状态传给动作分支。

## 核心要点
1. **状态感知**: 调度器输入当前视频特征 $z_k$（状态信息）+ 噪声水平 $\sigma_k$，实现真正的状态依赖调度
2. **训练-部署一致**: 训练时随机采样停止点（探索），部署时用确定性阈值 $F_k > \eta$（利用），通过概率分解保持一致性
3. **可插拔设计**: 骨干 WAM 保持冻结，调度器仅需 ~3000 步 PPO 后训练即可从仿真迁移到真实机器人

## SANTS 中的具体实现

| 参数 | 值 |
|------|---|
| 架构 | 2 层 MLP，512→256 瓶颈 |
| 输入 | 池化视频特征 + 噪声水平（标量） |
| 输出 | 停止风险 $\Delta H_k$ + Beta 分布参数 $(m_k, c_k)$ |
| 部署阈值 | $\eta = 0.85$ |

## 代表工作
- [[SANTS]]: 首次将累积风险框架用于 WAM 视频去噪停止决策
