# 因果混合注意力

## 定义

为 Mixture-of-Transformers 骨干设计的模态专属可见性掩码机制，通过差异化定义视频、动作、几何 token 之间的因果依赖关系，防止非因果信息泄露给动作预测。

## 数学形式

可见性矩阵 $M_{ij} \in \{0, 1\}$ 定义 token $i$ 是否可见 token $j$：

$$
\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d}} + M\right)V
$$

## 核心要点

1. **三类 token 差异化可见性**：
   - 未来**动作** token：可见历史上下文 + 同时步未来动作；不可见未来视频帧和寄存器
   - **寄存器** token：可见自身 + 历史视频；不可见未来视频和动作
   - 未来**视频** token：可见历史上下文 + 同时步及之前未来帧（标准因果）
2. **防止几何信息捷径**：若动作 token 可见寄存器，则可从几何路径获取未来信息，破坏因果性
3. **单向（因果）优于双向**：消融实验显示双向注意力虽提高 SR 但削弱几何质量
