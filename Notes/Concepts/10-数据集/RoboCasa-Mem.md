# RoboCasa-Mem

## 定义
面向长时程移动操作的记忆能力评估 benchmark，包含 9 个家庭任务，覆盖 Environment Memory（物体位置、空间关系）和 Process Memory（操作顺序、历史状态）两大类共 5 种记忆类型。

## 核心要点
1. 分类框架：Environment Memory vs Process Memory
2. 新指标 MemER（Memory Engagement Rate）量化记忆依赖程度
3. 基于 [[RoboCasa365]]，含真实机器人实验
4. 对比 [[ACT]], [[DP]], [[VGGT]] 等方案
