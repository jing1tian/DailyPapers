# Qwen2.5-VL

## 定义

阿里巴巴开发的视觉语言模型系列（Qwen2.5-VL），继承 Qwen 系列架构，支持图像、视频、文档等多模态输入，具备强大的视觉理解和推理能力。Qwen2.5-VL-7B-Instruct 为 70 亿参数的指令微调版本。

## 核心要点

1. **多模态输入**: 支持图像、多图、视频帧、文档截图等多种视觉输入形式
2. **强视觉定位**: 原生支持 bounding box 预测和视觉定位任务
3. **长序列**: 支持最长 16,384 token 序列，适合包含大量视觉 token 的任务
4. **指令遵循**: Instruct 版本经过 RLHF 微调，指令遵循能力强
5. **可微调**: 支持 LoRA 和全量微调，广泛用于下游任务适配

## 代表工作

- [[PhysX-Omni]]: 以 Qwen2.5-VL-7B-Instruct 为骨干，微调用于仿真就绪 3D 资产生成
