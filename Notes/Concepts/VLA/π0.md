# π0

## 定义

π0（Pi-zero）是 Physical Intelligence 提出的基础机器人策略模型，基于流匹配（[[Flow Matching]]）在大规模跨机器人数据上预训练，再通过少量演示数据进行领域适应。

## 核心要点

1. 采用扩散/流匹配框架生成连续动作序列
2. 大规模跨机器人预训练数据，具有强泛化能力
3. 在 [[VLA-REPLICA]] 评测中 ID 平均成功率 34%，OOD 30%
4. π0.5 是其改进版本，ID 达 54%，OOD 达 35%
5. 显著优于从头训练的 [[模仿学习]] 方法（ACT：18%，DiT：16%/12%）

## 代表工作

- [[VLA-REPLICA]]: 作为被评测的 VLA 模型，取得最高 ID 成功率（π0.5）
- [[G3VLA]]: 作为单塔 flow-matching 架构的代表，几何旁路注入收益最明显的 backbone——LIBERO 平均 84.6%→88.1%（GT 监督），真实世界 OOD 视角下提升显著
