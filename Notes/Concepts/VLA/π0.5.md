# π0.5

## 定义

π0.5 是 Physical Intelligence 在 [[π0]] 基础上的改进版 VLA 模型，通过改进预训练数据规模和训练策略进一步提升了操作成功率。

## 核心要点

1. [[π0]] 的改进版本，保持流匹配框架
2. 在 [[VLA-REPLICA]] 评测中：
   - **ID 平均成功率 54%**（所有评测模型最高）
   - **OOD 平均成功率 35%**（所有评测模型最高）
3. 折叠毛巾任务 ID 成功率达 100%
4. 仍在记忆计数 OOD 任务上失败（计数 OOD 几乎为 0%）
5. 预训练规模和数据质量是超越 π0 的关键

## 代表工作

- [[VLA-REPLICA]]: 作为被评测模型，在所有任务上取得最高平均性能
- [[G3VLA]]: 验证几何旁路注入在已接近饱和的强 backbone 上仍有效——LIBERO 平均 95.9%→97.0%
