# 吸收掩码扩散（Absorbing Mask Diffusion）

## 定义

一种用于离散 token 序列的扩散模型，其中前向过程将 token 以随机比例替换为 `[MASK]`（吸收状态），反向过程逐步预测并恢复被掩码的 token。

## 数学形式

**前向过程（逐步掩码）**：

$$
\tilde{c}_i = [\text{MASK}] \text{ if } b_i = 1 \text{ else } c_i, \quad b_i \sim \text{Bernoulli}(r), \quad r \sim \mathcal{U}(0, 1)
$$

**反向过程（预测损失）**：

$$
\ell_c = -\sum_{i: b_i=1} \log p_\theta(c_i \mid \tilde{C}_r, \mathcal{C}_t)
$$

## 核心要点

1. **吸收状态**: 与 Gaussian 噪声扩散不同，离散 token 不能直接加高斯噪声；`[MASK]` 是唯一的"噪声"状态（吸收态）
2. **掩码比例均匀采样**: $r \sim \mathcal{U}(0,1)$ 使模型在训练时见到不同完整度的代码序列，类似 BERT 但连续化
3. **双向条件生成**: 预测时可利用已知 token 的双向上下文（不像自回归模型只能利用左侧上下文）
4. **与连续扩散联合**: 在 [[AW-0]] 中与 Flow Matching（视频/动作）联合训练，通过 [[Mixture-of-Transformers]] 共享特征

## 代表工作

- [[AW-0]]: 用于联合生成参数化技能程序，与视频/动作 Flow Matching 联合去噪
- MDLM (Sahoo et al. 2024): 系统化提出 Masked Diffusion Language Model
- SDAR: 用于代码生成的掩码扩散语言模型（AW-0 代码专家初始化基础）

## 相关概念

- [[Flow-Matching]]: 连续域的对应扩散方法
- [[Mixture-of-Transformers]]: AW-0 中将掩码扩散集成到多专家架构的框架
- [[WAM]]: AW-0 扩展的世界动作模型框架
