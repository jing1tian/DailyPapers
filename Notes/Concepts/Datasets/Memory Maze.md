# Memory Maze

## 定义
用于评估智能体长程记忆能力的 3D 迷宫导航数据集/环境，要求模型回忆之前访问过的位置和物体，测试数百帧跨度内的时序一致性。

## 核心要点
1. 场景为随机生成的 3D 迷宫，智能体需要重访之前看到的物体
2. 评估指标：LPIPS（感知图像相似度）、SSIM、PSNR
3. 长上下文设置：测试中上下文可达 480 帧，适合评估长程记忆
4. 也提供 Memory Cards 变体，专门测试离散物体回忆率

## 代表工作
- [[CoME]]: 在 Memory Maze 上消融三类记忆专家，LPIPS 从 0.209 降至 0.097
