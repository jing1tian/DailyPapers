# LLM (Large Language Model)

## 定义

基于 Transformer 架构、在大规模文本语料上预训练得到的大参数量语言模型，具备强大的语言理解、生成和指令遵循能力。在机器人和具身智能领域，LLM 常被用作冻结的语义解析器，将自然语言指令转化为结构化的中间表示（如目标类别、子任务序列），供下游感知或控制模块使用。

## 核心要点

1. **零样本/少样本语义解析**: 无需任务特定微调即可将自由形式指令解析为目标类别、动作序列等结构化输出
2. **作为冻结组件使用**: 在很多 VLA/机器人系统中，LLM 不参与训练，只在推理时调用一次并缓存结果，降低系统复杂度和计算开销
3. **常与视觉定位模型协同**: LLM 负责"指令 → 语义类别"，再交给 [[SAM3|SAM 3]]、Grounding DINO 等模型完成"语义类别 → 空间位置"的定位，形成语言到空间的两阶段流水线

## 代表工作

- [[SVP-IL]]: 用冻结 LLM 将语言指令解析为目标物体类别 $c = \mathrm{LLM}(l)$，再交给 SAM 3 生成几何掩码
- [[RoVLA]]: 用 Qwen3-8B 对训练指令做语义等价改写，实现指令层面的数据增强
