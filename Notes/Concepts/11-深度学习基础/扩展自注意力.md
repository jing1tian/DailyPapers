# 扩展自注意力

## 定义

在标准自注意力机制的基础上，将外部参考信息（如物体图像、参考帧）的 Key/Value 拼接到序列 Key/Value 中，使主序列的每个 Query token 可以全局关注参考信息，实现"软注入"。

## 数学形式

$$
\text{Attention}(Q_{main},\ [K_{main};\ K_{ref}],\ [V_{main};\ V_{ref}])
$$

其中 $[;]$ 表示在序列维度拼接，$K_{ref}, V_{ref}$ 来自参考（如物体先验图像编码）。

## 核心要点

1. **无需修改 Query**: 主序列的 Query 不变，仅扩展 Key/Value 池
2. **全局感受野**: 主序列中任意位置的 token 都可以关注参考信息
3. **软注入**: 注意力权重决定参考信息的影响强度，非硬编码
4. **常见于图像生成**: IP-Adapter、参考图像引导生成等广泛使用

## 代表工作

- [[RoboDream]]: 将物体先验图像 token 注入视频扩散 Transformer 的自注意力层，实现物体外观的一致性控制
- IP-Adapter: 在图像扩散模型中通过扩展自注意力注入参考图像风格/内容
