# 自回归语言模型

## 定义

按顺序逐 token 生成序列的语言模型，每个 token 的生成以之前所有 token 为条件。GPT 系列、LLaMA、Qwen 等主流大语言模型均采用自回归架构。

## 数学形式

$$
p(x_1, x_2, \ldots, x_n) = \prod_{i=1}^{n} p(x_i \mid x_1, x_2, \ldots, x_{i-1})
$$

## 核心要点

1. **因果注意力**: 使用掩码注意力确保每个位置只能看到之前的 token，维持自回归特性
2. **Teacher Forcing**: 训练时以真实 token 作为下一步输入，推理时以模型输出为输入
3. **序列长度限制**: 最大序列长度（context window）是关键限制，影响可处理信息量
4. **VLM 扩展**: 将视觉 token（图像 patch embedding）插入文本 token 序列，实现多模态自回归生成
5. **3D 生成应用**: 将 3D 几何编码为文本 token 序列后可直接用 AR LM 生成（如 PhysX-Omni 的 Template-based RLE）

## 代表工作

- [[PhysX-Omni]]: 利用自回归 VLM（Qwen2.5-VL）通过文本化几何表示生成仿真就绪 3D 资产
