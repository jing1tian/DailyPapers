# 视觉编码器

## 定义

视觉编码器（Visual Encoder）是将原始图像输入映射为高维特征表示（通常是 patch token 序列）的神经网络模块，是视觉-语言模型和视觉-语言-动作模型的感知基础。

## 数学形式

$$
v_t = \phi(o_t) \in \mathbb{R}^{N \times d}
$$

其中 $o_t$ 为输入图像，$N$ 为 patch 数量，$d$ 为 token 维度。

## 核心要点

1. **ViT 架构主流**：现代视觉编码器以 Vision Transformer（ViT）为主，将图像分割为固定尺寸 patch（如 16×16），每个 patch 映射为一个 token
2. **冻结 vs 微调**：在 VLA 等下游任务中，视觉编码器通常保持冻结以防止"遗忘"；AHEAD 中完全冻结 OpenVLA 编码器
3. **Patch token 特性**：patch token 具有空间位置信息，可以被下游模块（如 AHEAD 的世界模型）按空间位置操作
4. **典型规模**：224×224 输入 / 16×16 patch → N=196 个 token

## 代表工作

- [[OpenVLA-OFT]]: 使用 SigLIP 视觉编码器，产生 196 个 patch token，AHEAD 将其冻结并在 token 层面上进行潜空间预测
- [[AHEAD]]: 在冻结视觉编码器的 patch token 上建立世界模型，通过替换预测 token 实现动态场景的预测性操作
