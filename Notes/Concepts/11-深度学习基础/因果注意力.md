# 因果注意力 (Causal Attention)

## 定义

一种带有**因果掩码（Causal Mask）** 的自注意力机制：每个 token 只能关注其**左侧**（时间上更早的）token，不能看到未来信息，确保自回归生成的合理性。

## 数学形式

$$
\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d}} + M\right) V
$$

其中因果掩码 $M_{ij} = 0$ 若 $j \leq i$，$M_{ij} = -\infty$ 若 $j > i$（上三角部分屏蔽未来 token）。

## 核心要点

1. **自回归生成**: 因果注意力是 GPT 系列等自回归语言模型的核心组件，确保生成第 $t$ 个 token 时只利用前 $t-1$ 个 token 的信息。
2. **与双向注意力的区别**: BERT 使用双向（非因果）注意力，可看到全部上下文；GPT/LLaMA 使用因果注意力，只看左侧上下文。
3. **在 VLA 中的应用**: [[LoopVLA]] 使用因果注意力掩码让 Action tokens 只关注视觉/语言上下文，而不是其他 Action tokens（类似 Action 间的因果生成）。
4. **KV Cache 兼容**: 因果结构天然支持 KV Cache 加速推理——已计算的 token 的 K/V 可被缓存复用。

## 代表工作

- [[LoopVLA]]: Loop Block 中使用因果注意力控制 Action tokens 的信息访问范围。
- GPT 系列、LLaMA、Qwen 等自回归 LLM 的核心机制。
