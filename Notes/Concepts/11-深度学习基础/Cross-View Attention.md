# Cross-View Attention

## 定义

让多个相机视角（或多个视图）的 token 在注意力机制中相互交互、双向融合信息的机制，常与位置/几何编码（如 [[PRoPE]]）配合，使模型在保留各视角局部结构的同时建立跨视角的全局几何一致性。

## 数学形式

典型两步式融合（以 [[G3VLA]] 为例）：

$$
H = \mathrm{Fusion}_\psi\big(Z; \{K^v, T^v\}_{v=1}^{V}\big)
$$

其中融合分两步：
1. **Frame Attention**：每个视角内部独立做自注意力，保留视角局部结构
2. **Cross-View Attention**：展平视角和 patch 维度，所有视角 token 在几何位置信号（如 [[PRoPE]]）引导下做双向跨视角注意力

## 核心要点

1. 与单视角自注意力的关键区别在于：注意力计算范围跨越视角边界，使不同相机看到的同一物理点能够相互"看到"对方的特征
2. 通常需要配合相机几何信息（内参/外参）作为位置编码或 attention bias，否则纯靠学习到的外观相似度难以建立准确的跨视角对应关系
3. 计算顺序设计（先视角内、再跨视角）能在控制计算量的同时，逐步从局部到全局聚合信息
4. 广泛用于多相机机器人感知、3D 重建（如 [[VGGT]]、DUSt3R 系列）、多视角生成等任务

## 代表工作

- [[G3VLA]]: 提出双向跨视角融合模块，配合 [[PRoPE]] 投影位置编码，将标定相机几何注入 VLA 视觉 token 处理流程
- [[VGGT]]: 多视角几何重建中使用类似的跨视角 token 交互机制

## 相关概念

- [[PRoPE]]: 为跨视角注意力提供基于相机模型的几何位置信号
- [[VGGT]]: 稠密几何预测中的跨视角信息聚合范式
- [[Action Chunking]]: 跨视角融合后的 token 最终服务于动作生成
