# 世界效应（World Effects）

## 定义

在动作条件世界模型中，**世界效应**指与 agent 当前动作无关、由环境本身持续施加的状态变化动力学，例如重力、惯性漂移、弹簧回复力等。即使 agent 不采取任何动作（零动作），这些效应仍然存在并改变系统状态。

## 数学形式

设状态转换 $s_{t+1} = f(s_t, a_t)$ 可分解为：

$$
s_{t+1} = \underbrace{f_w(s_t)}_{\text{世界效应（动作无关）}} + \underbrace{f_a(s_t, a_t)}_{\text{动作效应}}
$$

其中 $f_w$ 在 $a_t = 0$ 时仍非零，体现环境的自主动力学。

## 核心要点

1. **动作不变性**：世界效应不依赖 agent 的当前动作选择，同一状态下换不同动作，世界效应保持一致。
2. **持续性**：典型世界效应在每个时间步均持续作用（如重力），不随任务完成而消失。
3. **对规划的影响**：若世界模型无法区分世界效应与动作效应，则在有显著世界效应的任务上 [[Model Predictive Control|MPC]] 规划质量下降。
4. **典型类型**：重力驱动滑动（PushT-W）、常数位移漂移（TwoRoom-W）、竖直面重力（Reacher-W）、摆动动力学（Ball-in-Cup）。

## 代表工作

- [[DWM]]：首个明确提出"世界效应"概念并设计专用解耦框架的工作，通过辅助 World Head + 对比损失显式分离世界效应与动作效应。
