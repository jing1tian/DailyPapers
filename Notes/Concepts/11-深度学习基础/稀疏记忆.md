# 稀疏记忆

## 定义
稀疏记忆是一种序列建模技术，通过以固定步长对历史帧进行间隔采样（而非保留所有历史），在有限计算预算下同时保留长期上下文和短期细节，解决长时序 Transformer 的 KV 缓存爆炸问题。

## 数学形式

设当前时刻为 $t$，记忆步长为 $k$，记忆帧数为 $m$：

$$
\mathbf{z}^{mem}_t := (\ldots, z_{t-2k}, z_{t-k})
$$

历史（短期细节）：

$$
\mathbf{z}^{hist}_t := (z_{t-1}, z_t)
$$

完整上下文 = $\mathbf{z}^{mem}_t \cup \mathbf{z}^{hist}_t$，token 数量为 $(m+2) \times HW$（固定），不随序列增长。

## 核心要点
1. 记忆 token 覆盖长时序（如任务初始配置），步长 $k$ 控制覆盖范围
2. 历史 token 保留短期连续性（如接触、速度信息）
3. 组合后上下文 token 数固定，推理时间不随时序增长
4. 与 KV 缓存配合：记忆和历史 token 的 KV 跨去噪步骤复用

## 代表工作
- [[WEAVER]]: 使用稀疏记忆（6 帧，步长 5）+ 短期历史（2 帧），实现长时序操作建模（默认 m=6, k=5）
