# 最近邻查找

## 定义

最近邻查找是向量量化（VQ）tokenizer 中的核心操作：将连续嵌入向量映射到离散 codebook 中最近的条目，实现连续空间到离散 token 的转换。

## 数学形式

$$
q_i = \arg\min_{1 \leq k \leq K} \|p_i - c_k\|_2^2
$$

其中 $p_i$ 为输入嵌入，$c_k$ 为第 $k$ 个 codebook 向量，$K$ 为 codebook 大小，$q_i$ 为最终离散 token 索引。

## 核心要点

1. **向量量化**: 是 VQ-VAE 和 Patch-lookup tokenizer 的核心步骤，将连续空间离散化
2. **直通梯度（Straight-Through Estimator）**: 反向传播时直接将梯度传递到编码器，绕过 argmin 的不可微性
3. **Codebook 更新**: 通过 EMA 或 commitment loss 更新 codebook 向量
4. **Patch-lookup**: ITC 使用的 tokenizer 类型，直接用 patch 像素值查最近邻

## 代表工作

- [[IRIS]]: 使用 VQ-VAE tokenizer，最近邻查找将帧编码为离散 token 序列
- [[ITC]]: 在 Sinkhorn 分配后，对"新生成"的 token 执行最近邻查找得到离散索引
