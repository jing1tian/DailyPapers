# Latent Canvas

## 定义

将多模态信息（观测图像、机器人状态、动作、未来预测、价值函数）统一编码为结构化潜在帧序列，使单一扩散模型能在同一空间中联合建模策略、世界模型和价值函数三种角色。由 [[NavWAM]] 提出。

## 数学形式

9 帧潜在序列 $\mathbf{C} = [z_0, z_1, \ldots, z_8]$，其中：

- **已观测帧**（条件，$\sigma=0$）: $z_0$（VAE 填充）、$z_1$（状态 $s_t$）、$z_2$（目标图像 $g$）、$z_3$（当前观测 $o_t$）
- **预测帧**（去噪目标）: $z_4$（动作块 $a_{t:t+H-1}$）、$z_5$（未来状态 $s_{t+H}$）、$z_6, z_7$（未来观测）、$z_8$（价值 $v_{t+H}$）

## 核心要点

1. **统一表示**: 低维数据（状态 $\mathbb{R}^3$、动作 $\mathbb{R}^{3H}$、标量价值）渲染为常数图像帧后经 [[Causal VAE]] 编码，与图像帧在同一潜在空间对齐
2. **三模式切换**: 通过屏蔽不同帧，同一模型支持策略模式（预测动作）、世界模型模式（预测未来观测）、价值模式（估计目标进度）
3. **计算效率**: 单次前向传播直接输出动作，相比 CEM+NWM 延迟降低 1136 倍
4. **动作权重增强**: 动作帧的损失权重 $\lambda=5$，补偿低维信号在高维图像潜在空间中的梯度稀释

## 代表工作
- [[NavWAM]]: Latent Canvas 的首次提出，用于目标条件视觉导航
- [[Cosmos Predict2]]: 提供 Canvas 所基于的视频扩散主干和 Causal VAE

## 相关概念

- [[Diffusion Transformer]]: 在 Canvas 潜在空间上进行去噪的模型主干
- [[Action Chunking]]: Canvas 中动作帧所预测的多步动作序列
