# 混合执行（Hybrid Execution）

## 定义

在机器人执行过程中，动态选择使用结构化代码（技能调用）或直接神经网络动作块的控制策略，通过有效性和进度检查在两种模式间切换。

## 数学形式

混合仲裁函数（Arbitrate）：

$$
\pi_\text{hybrid}(a_t \mid o_t) =
\begin{cases}
\pi_\text{code}(a_t) & \text{if } \text{Valid}(C_k) \land \text{Progress}(M_t) \\
\pi_\text{action}(a_t) & \text{otherwise}
\end{cases}
$$

其中 $\text{Valid}(C_k)$ 检查代码切片语法正确性和 API 匹配，$\text{Progress}(M_t)$ 检查前序代码切片完成度。

## 核心要点

1. **有效性检查**: 语法解析通过 + API 参数匹配，确保技能调用可执行
2. **进度检查**: 检查前序代码切片是否已执行完成，防止跳步或重复
3. **互补优势**: 代码路径提供语义鲁棒性（对视觉分布偏移不敏感），动作块提供精细操作精度
4. **场景依赖**: 在视觉随机化/分布偏移场景下代码路径更优；干净场景下动作块往往更精准
