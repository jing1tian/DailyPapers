# 世界动作模型（WAM）

**World Action Model（WAM）**，一类将视频预测（World Model）与机器人动作生成（Action Model）统一的框架，使策略能够在潜在空间中"预见"未来观测并据此规划动作。

## 核心思路

标准 VLA 策略仅响应当前观测，缺乏对未来的感知。WAM 通过引入**视频预测头**，迫使策略内部表示具备对未来场景变化的建模能力：
- 输入：当前观测 $o_t$ + 历史帧
- 输出：动作 $a_t$ + 未来帧预测 $\hat{o}_{t+1}, ..., \hat{o}_{t+k}$

## 关键变体

| 方法 | 特点 |
|------|------|
| [[Fast-WAM]] | 快速 WAM，以高效视频编码实现可部署的预测策略 |
| DECOWAM | 解耦 WAM，将视频预测和动作生成分离 |

## 部署挑战

视频生成模块（如 [[Wan 2.2 视频 VAE]]）延迟高，难以满足实时控制（15 Hz）需求。

## 蒸馏范式

**Fast-WAM 衍生蒸馏**（[[ForeTimeVLA]] 提出）：将 WAM 预测结构压缩为64维编码，蒸馏到因果 VLA 学生策略，在推理时无需调用视频生成模块。
