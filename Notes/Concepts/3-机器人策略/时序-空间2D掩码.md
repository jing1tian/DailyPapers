# 时序-空间2D掩码

## 定义

时序-空间 2D 掩码是一种针对机器人**动作 token 矩阵**（$T \times D$，时间步 × 动作维度）的两阶段掩码策略：先按时间轴随机掩码整帧（时间掩码），再在剩余帧中按动作维度轴随机掩码部分 token（空间掩码），同时建模跨帧时序依赖和帧内维度耦合。

## 数学形式

**掩码比例**（余弦调度）：

$$
r = \cos\!\left(\frac{\pi t}{2}\right), \quad t \sim \text{Uniform}(0, 1)
$$

**时间掩码**：选择 $\lceil r \cdot T \rceil$ 个帧，掩码这些帧的所有 $D$ 个 token

**空间掩码**：在剩余帧中，每帧随机掩码 $\lceil r \times D \rceil$ 个 token

## 核心要点

1. **1D vs 2D**：传统 1D 掩码只沿一个轴（时间或维度）掩码，忽略另一结构轴；2D 掩码同时建模两轴
2. **长程任务优势**：消融实验显示 2D 掩码在 LIBERO-Long 任务上较 1D 提升 +6.6pp（91.6% vs 85.0%）
3. **结构先验**：两阶段设计反映了动作的内在结构：帧间时序平滑性 + 帧内维度耦合（如末端执行器 6-DoF 联动）
4. **与余弦调度配合**：低掩码率样本更多，有利于精细动作的端到端学习
