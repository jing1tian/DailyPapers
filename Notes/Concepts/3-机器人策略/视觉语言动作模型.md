# 视觉语言动作模型（VLA）

## 定义
将视觉感知、语言理解与机器人动作生成统一到单一模型的端到端框架。以视觉观察和语言指令为输入，直接输出机器人动作，通常基于预训练的视觉语言模型微调得到。

## 核心要点

1. **端到端学习**: 从图像+语言到动作，无需手工特征工程
2. **预训练迁移**: 利用大规模视觉语言预训练提供丰富语义理解能力
3. **动作表示**: 可输出关节角度、末端执行器位姿，或（如 SONIC 中）FSQ token
4. **全身操作**: 结合 SONIC 等全身控制框架，VLA 可驱动人形机器人执行复杂全身任务

## 代表工作

- [[SONIC]]: VLA 输出 FSQ token 驱动人形机器人全身操作，平均成功率 75%
