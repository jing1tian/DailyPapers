# VLA（视觉-语言-动作模型）

## 定义
将视觉感知、语言理解和机器人动作生成统一在单一模型中的多模态架构，通过预训练大型视觉-语言基础模型并添加动作输出头，实现基于自然语言指令的端到端机器人操控。

## 数学形式

$$
a_t = \pi(o_t, l; \theta)
$$

其中策略 $\pi$ 以视觉观测 $o_t$ 和语言指令 $l$ 为输入，输出机器人动作 $a_t$（或动作序列 $a_{t:t+k}$）。

## 核心要点

1. **架构**: 通常由视觉编码器（ViT）+ 语言大模型（LLM backbone）+ 动作解码器（自回归 token 或 DiT 动作头）组成
2. **两类主流动作头**:
   - 自回归：将动作离散化为 token，用 LLM 自回归预测（如 OpenVLA）
   - 扩散：用 [[扩散策略|Diffusion Policy]] 或 [[Diffusion Transformer (DiT)|DiT]] 生成连续动作（如 Pi-0, GR00T）
3. **泛化能力**: 从网络规模的多模态预训练中获得跨任务泛化，通过少量机器人数据微调即可适配新任务
4. **部署挑战**: 参数量通常数十亿，边缘设备部署需要模型压缩（量化、剪枝等）

## 代表工作

- [[Omega-QVLA]]: 首个对 VLA 语言主干和 DiT 动作头全栈 W4A4 量化的方法
- [[QuantVLA]]: 早期 VLA 量化工作，跳过 DiT 注意力层规避量化难题
- [[Pi-0.5]]: 基于 DiT 动作头的 VLA，Ω-QVLA 主要评估对象之一

- [[Diffusion Transformer (DiT)]]: 扩散 VLA 的动作头架构
- [[扩散策略]]: VLA 动作生成的扩散框架基础
- [[后训练量化（PTQ）]]: VLA 部署时的主要压缩手段
- [[行为克隆]]: VLA 训练的基础监督学习方式
