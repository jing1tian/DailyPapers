# PerAct

## 定义

基于体素表征（voxel value map）的机器人操作策略：将多视角 RGB-D 观测体素化为统一的 3D 体素网格，用 Perceiver Transformer 在体素特征上预测离散化的末端执行器关键帧动作（位置 + 朝向 + 夹爪状态）。

## 核心要点

1. 把多相机 RGB-D 观测反投影融合为单一 3D 体素网格，显式编码场景几何，避免依赖纯 2D 图像坐标
2. 用 Perceiver 架构处理高分辨率体素输入，缓解体素化带来的计算/内存开销问题
3. 动作预测采用"检测式"离散化方案——在体素网格中定位下一个关键帧的末端执行器位置
4. 局限：体素化分辨率与场景范围强相关，扩展到大场景或高精度任务时内存开销显著上升；需要针对任务重新设计体素化流程，难以直接复用预训练 2D 视觉-语言 backbone

## 代表工作

- PerAct 原始论文：在 RLBench 多任务操作基准上验证体素表征的有效性
- [[G3VLA]]: 将 PerAct 列为"结构化 3D 表征"代表性工作，与其轻量级几何旁路注入思路形成对比——PerAct 需要任务专用体素化设计，G3VLA 则可直接插入预训练 VLA 视觉 token 通路

## 相关概念

- [[RVT]]: 用虚拟视图渲染替代体素化，缓解 PerAct 的内存开销问题
- [[Act3D]]: 基于点云而非体素的 3D 操作策略
- [[PRoPE]]: G3VLA 中用于跨视角几何融合的替代轻量方案
