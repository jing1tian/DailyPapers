# 传送带操作（Conveyor-Belt Manipulation）

**传送带操作**是机器人操作领域的一类动态抓取任务：机器人需在**运动中**的传送带上拦截、抓取并搬运目标物体，要求策略具备对目标运动的预判能力。

## 任务特点

| 维度 | 挑战 |
|------|------|
| 时序性 | 目标持续移动，抓取窗口有限（高速传送带仅数百毫秒）|
| 末端姿态 | 需提前调整接触姿态，不能在接触时再纠偏 |
| 速度鲁棒性 | 不同传送带速度下策略表现差异大 |
| 预见性需求 | 静态 VLA 难以在目标到达前预备就绪 |

## 评估指标

- **成功率**（Grasp Success Rate）：正确拾取并搬运目标
- **早期失败**（Early Failure）：目标进入范围前策略放弃或误触
- **晚期失败**（Late Failure）：目标已过可抓位置策略仍未启动
- **接触姿态误差**（Contact-Pose Error）：末端执行器姿态不对导致抓取失败

## 场景分级

| 档位 | 特征 |
|------|------|
| 静止 | 物体固定，测试基础定位精度 |
| 慢速 | 低速移动，有较充裕的反应时间 |
| 中速 | 中等速度，时序预见价值开始体现 |
| 快速 | 高速移动，时序预见最为关键 |

## 代表数据集

传送带操作语料库（[[ForeTimeVLA]] 构建）：458 集，96,512 帧，覆盖箱子/玉米/西瓜目标，静止/移动多档速度。

## 代表工作

- [[ForeTimeVLA]]: 首个将因果时序预见蒸馏应用于传送带操作的 VLA 方法，快速档位下成功率为基线 5.5 倍

## 相关概念

- [[VLA（视觉-语言-动作模型）]]: 执行操作任务的策略骨干
- [[世界动作模型（WAM）]]: 为传送带操作提供时序预见能力
- [[Action Chunking]]: 多步动作块预测减少控制延迟
