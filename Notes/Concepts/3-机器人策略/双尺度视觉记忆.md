# 双尺度视觉记忆（Dual-scale Visual Memory）

## 定义

在机器人策略中同时维护两种时间尺度的历史帧记忆：短期记忆（小步长，捕捉局部运动细节）和长期记忆（大步长，捕捉任务级进展），通过[[Causal VAE]]编码后与当前观测共同输入策略模型。

## 数学形式

- **短期记忆**: 步长 $\delta_s$，取 4 帧，帧索引 $\{t - k\delta_s\}_{k=1}^{4}$
- **长期记忆**: 步长 $\delta_l = H$（动作块长度），取 4 帧，帧索引 $\{t - kH\}_{k=1}^{4}$

在 WorldBridge 中 $\delta_s = 2$，$\delta_l = H = 32$。

## 核心要点

1. **互补性**: 短期记忆感知精细运动（如夹爪开合、物体位移），长期记忆跟踪任务阶段（如已完成的子任务）
2. **因果编码**: 使用[[Causal VAE]]编码，丢弃填充帧对应的首个潜变量，仅保留有效潜变量
3. **记忆密集任务切换**: 对需要大量历史信息的任务（如饮料扫描）可切换注意力掩码，让动作直接访问记忆 token
4. **消融证明**: 短期记忆在 RoboCasa +5.16pp，长期记忆再 +4.25pp

## 代表工作

- [[WorldBridge]]: 提出双尺度视觉记忆，在 RoboDojo Memory 类任务达到 31% SR
