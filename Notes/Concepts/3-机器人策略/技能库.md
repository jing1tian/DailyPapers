# 技能库（Skill Library）

## 定义

将机器人操作中重复出现的子任务动作序列抽象为参数化程序（技能），存储在可复用的库中，供后续任务通过代码调用复用。

## 数学形式

技能定义为参数化函数：

$$
\text{skill}_k(\theta_1, \theta_2, \ldots, \theta_n) \rightarrow \{a_t\}_{t=1}^{T}
$$

其中 $\theta_i$ 为技能参数（如目标位置、力度等），输出为动作序列。

## 核心要点

1. **自动发现**: 无需人工定义技能边界，由 LLM 协调器从大量轨迹中发现重复子任务模式
2. **参数化接口**: 技能以声明式 API 定义，参数由代码生成模型在线填写（如坐标、方向）
3. **跨任务复用**: 同一技能（如 `fold_edge_over`）可被多个不同上层任务调用
4. **与世界模型集成**: 在 [[AW-0]] 中，技能库既用于视频/动作预测的语义先验，也用于智能体执行时的程序调用

## 代表工作

- [[AW-0]]: 通过自动标注管线构建 YAM（23 个技能）和人类 ego（27 个技能）技能库，并与 WAM 联合训练
- [[Code as Policies]]: 早期代码化技能调用工作，但需要人工定义 API
- VoxPoser, RVT: 以感知 API 为基础的技能组合

## 相关概念

- [[Code as Policies]]: 技能库的前置工作，代码调用预定义技能
- [[混合执行]]: 在测试时动态决定是否调用技能库中的技能
- [[Agentic Robot]]: 技能库是智能体机器人实现技能复用的关键组件
- [[WAM]]: AW-0 将技能库嵌入 WAM 框架
