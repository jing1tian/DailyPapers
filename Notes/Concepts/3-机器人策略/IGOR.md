# IGOR

## 定义
一种用于学习可控 latent action 表示的机器人 world model 方法，从无标签视频中推断 latent action 并用于 action-conditioned 视频生成。

## 核心要点
1. 从无标签视频训练 latent action model
2. latent action 编码视频帧间的变化因子
3. 与 CD-LAM 同属 latent action model 系列方法
4. 主要用于机器人数据增广和 model-based RL

## 代表工作
- [[CD-LAM]]：将 IGOR 作为 baseline 对比 latent action 去偏方法
