# 推理适配器

## 定义

在蒸馏框架中用于将学生分支推理锚点 token 投影到与教师分支对齐的潜在空间的轻量级网络（通常为 MLP + LayerNorm），使学生表征能够在不同维度或语义空间中与教师表征计算相似度损失。

## 核心要点

1. **空间桥接**：将学生 token 投影到推理潜在空间，弥补教师/学生分支输入差异导致的表征偏移
2. **轻量设计**：通常为单层或双层 MLP，不显著增加参数量
3. **仅用于蒸馏**：推理适配器参数参与反向传播，但推理时可选择保留或去除

## 代表工作

- [[3DThinkVLA]]: 推理适配器 $\mathcal{R}$ 将学生分支的推理锚点 token 投影后与教师表征计算余弦相似度蒸馏损失
