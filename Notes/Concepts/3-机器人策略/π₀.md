# π₀（Pi-Zero）

## 定义

π₀ 是 Physical Intelligence（Pi）发布的通用机器人基础模型，基于视觉-语言-动作（VLA）框架，采用流匹配生成动作，支持多种机器人形态的通用操作。

## 核心要点

1. **VLA 架构**: 融合视觉编码器 + 语言模型 + 扩散/流动作头
2. **流匹配动作生成**: 使用 [[Flow Matching]] 生成连续动作分布
3. **动作监督训练**: 需要大量机器人动作标注数据，限制了数据规模扩展
4. **多任务通用**: 在多种操作任务上表现强劲，是业界重要 baseline

## 性能（UR3 真实机器人对比）

| 方法 | UR3 平均成功率 |
|------|--------------|
| π₀ | 71.7% |
| [[TraceGen]] | 81.7% |
| **[[mu0]]** | **91.7%** |

## 局限性

- 需要具身特定的动作标注，数据收集成本高
- 跨具身体迁移困难（每个机器人形态需单独训练）

## 代表工作

- [[mu0]]: 在无动作监督的情况下超越 π₀，说明 3D 轨迹预训练的有效性
- [[π₀.₅]]: π₀ 的升级版本，进一步提升操作能力
