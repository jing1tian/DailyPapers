## 一句话总结

> LingBot-Touch 是首个跨压阻、磁性、视触觉三类传感器的触觉基础模型，通过将触觉信号映射至统一的指尖坐标空间并以 Tactile-JEPA 在潜在空间预测接触，使同一个冻结编码器在 26 个现实操作任务和 12 个仿真灵巧手任务中平均提升成功率 14–26 个百分点。

---

## 核心贡献

1. **跨传感器触觉语料库**：收集包含 4,983 小时、464K 集数、13.3 亿帧的触觉录制数据，涵盖压阻、磁性、视触觉三类传感器，来自触觉手套和双臂遥操作，是目前最大规模触觉预训练数据集。
2. **LingBot-Touch 触觉基础模型**：引入规范指尖空间（[[Canonical Fingertip Space]]）+ 模态专用 Tokenizer + 共享 [[Haptic Transformer]]（HaT）架构，通过 [[Tactile-JEPA]] 目标在潜在空间预测稀疏触觉信号的完整表征，无需为新传感器重新训练。
3. **全链路验证**：冻结探针测试接触物理量（力、位置、面积、时序动力学、跨模态检索）、26 个真实双臂操作任务（配合 Diffusion Policy / π0.5 / LingBot-VLA / T-Rex）、12 个仿真 RL 任务，提供从表征到策略的端到端证据链及消融分析。
4. **开放发布**：推理代码、Tiny 和 Small 两个变体的检查点将开放，支持研究者直接集成到下游机器人学习系统。

## 问题背景

### 要解决的问题

现有机器人操作几乎完全依赖视觉，视觉无法感知接触力、抓取滑动或遮挡手指的状态。触觉传感器已商业化，但触觉学习无法像视觉语言一样规模化，根本原因是：

1. **无统一输入格式**：每类传感器的通道数、空间分辨率、采样率、taxel 布局各不相同，一类传感器上训练的模型对另一类毫无意义。
2. **无大规模语料库**：触觉数据来自传感器，不能跨类汇聚，每小时都需要有传感器的手与世界交互。
3. **无标准化方案**：触觉有益于机器人学习的证据分散于传感器特定研究中，缺乏共享表征进行横向比较。

### 现有方法的局限

- **Sparsh** [14]：仅针对光学触觉传感器，研究重建 / 自蒸馏 / 联合嵌入预测三种目标。
- **T3** [37]：传感器专属编码器 + 共享 Transformer，支持光学触觉迁移，不涉及磁性或压阻。
- **FTP-1** [34]：形态感知 token 空间 + 传感器专属编码器适配，需要为每个新传感器训练专属适配器；在五项探针任务上各项误差均高于 LingBot-Touch 数倍。
- **AnyTouch** [11] / **HTT** [7]：主要面向光学触觉，或仅对齐已配对传感器，泛化受限。

### 本文的动机

接触本身与记录它的传感器无关——同样的手指按压边缘，不论是磁力计、电阻网格还是凝胶后的相机记录的都是同一物理事件。因此，只要将传感器特定的物理特性从输入中剥离，接触的表征就可以跨传感器共享。规范坐标映射剥离了布局差异，[[Tactile-JEPA]] 在潜在空间预测避免了重建背景零值的陷阱。

## 方法详解

### 模型架构

LingBot-Touch 采用 **编码器–预测器分离的 JEPA** 架构（Fig. 3）：

- **输入**：归一化触觉片段 $X \in \mathbb{R}^{T \times N \times 3}$，其中 $T$ 为帧数，$N$ 为有效 taxel 总数，每个 taxel 携带 3 通道信号（法向 + 2 切向，单通道用零填充）
- **预处理**：将每个传感器的 taxel 坐标映射至 [[Canonical Fingertip Space]]（规范指尖球面空间），赋予 5 维 token 地址
- **模态专用 Tokenizer**：三条两层 MLP 分支（磁性 / 压阻 / 视触觉），将相邻两帧的一个 taxel（6 个数）嵌入为 1 个 token
- **共享 Haptic Transformer（HaT）**：12 层 Transformer 编码器，通过 5 维 [[Rotary Position Encoding|RoPE]]（时间 + 手指 + xyz 坐标）注入位置信息
- **输出**：多层特征拼接（4 层）供下游任务使用
- **参数量**：Tiny 5.46M，Small 21.76M（均含 tokenizer + HaT 骨干，不含预训练 predictor 和任务头）

### 核心模块

#### 模块1：规范指尖空间（Canonical Fingertip Space）

**设计动机**：taxel 索引仅描述传感器内部排列，不能跨传感器识别对应物理位置。通过连续 3D 坐标 + 手指标识来描述测量位置，所有传感器的坐标均置于同一规范指尖空间。

**具体实现**：
- 从每个传感器的几何资产出发，将指尖对齐规范朝向，再缩放/平移至单位半径参考球内
- 对 PaXini / XHand1：$\alpha = 1/r$，$b = -o/r$（$o$、$r$ 为 taxel 位置最小外接球的球心和半径）
- 对 Sharpa Wave：同等高度对齐归一化后，加深度平移使之匹配参考球
- 坐标原点为 $o = (u_x, c_y, u_z)$，其中 $u$ 为接触中心锚点，$y$ 为手指方向

#### 模块2：Tactile-JEPA 目标

**设计动机**：触觉信号高度稀疏（大多数 taxel 在大多数时刻无信号），直接重建信号会让优化被近乎全零的背景主导；在潜在空间预测则让目标始终由有意义的接触特征构成。

**具体实现**：
- 随机选取有效 taxel 进行遮盖，同一 taxel 在整段片段中均被遮盖（空间管状掩码）
- 上下文编码器只处理可见 token，预测器将可见特征与可学习遮盖 token 拼接后预测全部位置的 target 编码器输出
- 目标编码器为上下文编码器的 EMA（梯度停止）
- 多层次监督：从 4 个深度提取特征，分别 LayerNorm 后拼接形成目标 $\bar{z}$

#### 模块3：掩码热身（Mask Warm-up）

**设计动机**：在稀疏信号上直接使用 80% 掩码率，高概率将所有接触证据都遮盖（若接触涉及 $k$ 个 taxel，全被遮盖概率约 $0.8^k$），导致梯度爆炸和不稳定优化。

**具体实现**：掩码率从 40% 线性增长至 80%，热身期为前 300 步（总训练 200,000 步），之后固定不变（Fig. 4）。

#### 模块4：布局无关数据增广（Layout-Agnostic Augmentation）

**设计动机**：规范坐标空间只是提供了可比较的坐标，但不阻止模型记忆三种具体布局模板。

**具体实现**：
- **多分辨率采样**（磁性：24/32/48/64/76/96 taxels；视触觉：32/96/200 virtual taxels）：同一交互以多种空间分辨率呈现
- **Taxel 位置扰动**：给每个 taxel 位置加有界随机偏移（上下文和目标分支共享同一偏移），干扰对精确坐标模板的记忆

## 关键公式

### 公式1：[[Canonical Fingertip Space|规范坐标映射]]

$$
p_i = \alpha \tilde{p}_i + b
$$

**含义**：将传感器 $i$-th taxel 的朝向对齐坐标 $\tilde{p}_i$ 仿射变换到规范指尖球面空间

**符号说明**：
- $p_i \in \mathbb{R}^3$：规范坐标系下 taxel $i$ 的位置
- $\tilde{p}_i$：经朝向对齐后的原始 taxel 坐标
- $\alpha > 0$：传感器–手指模板固定的缩放系数，对 PaXini/XHand1 取 $1/r$
- $b \in \mathbb{R}^3$：平移向量，对 PaXini/XHand1 取 $-o/r$

### 公式2：[[Tactile-JEPA|5 维 Token 地址]]

$$
a_i = (t_i, f_i, p_i) \in \mathbb{R}^5, \quad A = (a_i)_{i=1}^{L}
$$

**含义**：为每个有效 token 分配时间索引、手指标识和 3D 规范位置，共同构成 5 维位置地址，仅通过 RoPE 进入模型注意力机制，无需固定 token 数目或传感器特定位置表

**符号说明**：
- $t_i$：token 所在时间窗口索引
- $f_i$：手指标识（0–4，拇指到小指）
- $p_i \in \mathbb{R}^3$：规范坐标（Eq. 1）
- $L$：有效 token 总数，$L = NT/2$（$N$ 为 taxel 数，$T$ 为帧数，相邻两帧合并为一 token）

### 公式3：[[Tactile-JEPA]] 预测与目标

$$
\hat{z} = P_\phi^{(g)}\!\left(E_\theta^{(g)}(X_C;\, A_C),\; \Delta_M;\; A\right)
$$

$$
\bar{z} = \bar{E}_{\bar{\theta}}^{(g)}(X;\, A)
$$

**含义**：上下文编码器处理可见 token $X_C$，预测器接收可见 token 表征与可学习遮盖 token $\Delta_M$，输出对全部位置（包括被遮盖位置）的预测 $\hat{z}$；目标编码器处理完整输入给出目标 $\bar{z}$

**符号说明**：
- $E_\theta^{(g)}$：传感模态 $g$ 的上下文编码器（模态专用 tokenizer + 共享 HaT）
- $P_\phi^{(g)}$：传感模态 $g$ 的预测器（模态专用投影 + 共享预测 Transformer）
- $X_C, A_C$：可见 token 的信号和地址
- $\Delta_M$：可学习遮盖 token
- $\bar{E}_{\bar{\theta}}^{(g)}$：目标编码器（上下文编码器的 EMA，梯度停止）

### 公式4：[[Tactile-JEPA|Tactile-JEPA 训练损失]]

$$
\mathcal{L} = \frac{1}{|M|D} \sum_{i \in M} \|\hat{z}_i - \mathrm{sg}(\bar{z}_i)\|_1 + \frac{\lambda}{|C|D} \sum_{i \in C} \|\hat{z}_i - \mathrm{sg}(\bar{z}_i)\|_1
$$

**含义**：对被遮盖位置施加预测损失（鼓励从可见上下文推断缺失接触信息），对可见位置施加上下文损失（鼓励保留已观测接触信息）；两项分别除以各自位置数和特征维度做归一化

**符号说明**：
- $M$：被遮盖 taxel 的 token 集合
- $C$：可见 taxel 的 token 集合
- $D$：拼接后特征维度（4 层输出拼接）
- $\mathrm{sg}(\cdot)$：停止梯度操作（stop-gradient）
- $\lambda = 0.5$：上下文损失权重

### 公式5：[[Canonical Fingertip Space|Taxel 位置扰动]]

$$
p'_i = p_i + \delta_i, \quad \|\delta_i\|_2 \leq 0.5\, d_i
$$

**含义**：在规范坐标上叠加有界随机偏移，扰动量与该 taxel 到同一手指上最近邻 taxel 的距离成比例，防止模型依赖精确坐标模板记忆布局

**符号说明**：
- $p_i$：Eq. 1 中的规范坐标
- $\delta_i$：随机扰动向量，每训练片段重采样，上下文和目标分支共享
- $d_i$：taxel $i$ 到同一手指上最近邻有效 taxel 的距离

![[LingBotTouch_fig7_scaling.png]]

**说明**：在 1K–5K 小时预训练数据上测试 Tiny 和 Small 两种尺寸编码器，分别在 Sharpa Wave（已见）和 XHand1（未见）上执行五项探针。Small 在每增加 1,000 小时时在两只手的所有任务上均改善或持平；Sharpa Wave 力误差从 1.68 N 降至 0.81 N，检索 Recall 从 42.5% 升至 72.6%。Tiny 大约在 4K 小时处饱和，5K 小时时检索 Recall 在两只手上均下降——模型容量成为瓶颈，数据量增长需要伴随模型扩容。

### Figure 8: 单来源 vs 多来源预训练

![[LingBotTouch_fig8_multisource.png]]

**说明**：在固定自有传感器数据（视触觉 331h / 磁性 228h）的条件下加入压阻数据后，8 个传感器-任务对中 7 个提升（尤其磁性侧：力误差从 4.34→2.52 N，未来力从 3.77→1.84 N）。在固定 1,000 小时总预算下，单来源模型在自有传感器上 7/8 对优于三来源混合（空间任务优势最大：中心误差 0.34 vs 0.68 mm），但多来源混合在时序预测上更好（视触觉：1.49 vs 1.67 N）。结论：强度和动力学跨换能器迁移，空间精度依赖自有传感器布局。

### Figure 9: 潜在预测 vs 信号重建

![[LingBotTouch_fig9_latent_vs_reconstruction.png]]

**说明**：同等参数（5.46M，HaT-Tiny），比较 VAE（信号重建）、MAE（信号重建，80% mask）和 LingBot-Touch（JEPA，潜在预测）在 1K 和 4K 小时上的表现，以及对 LingBot-VLA 操作成功率的影响。LingBot-Touch 在所有探针任务和两个数据规模上最优；VAE 随数据增加**变差**（接触中心误差 3.03→4.08 mm，Recall 4.4→3.1%），MAE 检索 Recall 始终低于 9%；而 LingBot-Touch 4K 时接触中心 0.32 mm、Recall 49.3%。真实操作实验中，LingBot-VLA + LingBot-Touch 在 5 个任务平均 82.2%，远超 LingBot-VLA + VAE 和 + MAE（约 65%）。

### 实现细节

- **Backbone**：LingBot-Touch-Tiny（5.46M）/ Small（21.76M），12 层 Transformer，dim 192 / 384
- **优化器**：AdamW
- **训练步数**：200,000 optimizer steps（预训练）；探针：100 epochs，lr = 1e-4，8 GPU
- **掩码**：空间 80%（全片段管状），时序 [75,75]%，热身 300 步
- **片段**：32 帧，2–4 帧/token（30 Hz 下约 1.07 s）
- **EMA 动量**：0.999→1.0（schedule）
- **下游集成**：冻结 Tiny 编码器，可训练跨注意力读出（40 token/手），线性投影到策略条件维度；对策略参数量增加 ≤ 0.16%
- **仿真触觉生成**：TacMap 方法，GPU 并行光线查询估计局部穿透深度，Sharpa Wave 96 点/finger，XHand1 120 点/finger

## 批判性思考

### 优点
1. **真正跨传感器**：规范坐标空间 + 布局无关增广使同一冻结编码器在预训练未见的 XHand1 上零样本超越 FTP-1（配有专属适配器）。
2. **规模化证明**：5,000 小时语料库提供了触觉表征学习在训练量上可受益的第一个清晰证据，且来自不同传感器的数据互相促进。
3. **插件即用**：编码器冻结后仅需线性投影即可插入现有策略（Diffusion Policy / VLA），增加 < 0.16% 参数。
4. **全链路验证**：从表征探针到 RL 再到真实操作的完整证据链，消融研究细致。

### 局限性
1. **手部种类有限**：现实和仿真实验仅覆盖两种机械手（Sharpa Wave 和 XHand1），泛化到更多手部形态的研究留待未来。
2. **缺少电容传感器**：现有电容传感录制质量不满足要求，尚未纳入预训练。
3. **仅指尖覆盖**：规范几何聚焦于指尖，手掌和手指其他部位的接触数据不足，全手覆盖是重要后续方向。
4. **仿真-真实 gap**：仿真力恢复 MAE 3.264 N 明显高于真实，绝对力估计仍面临 sim-to-real 挑战。

### 潜在改进方向
1. 扩展到电容传感器和更多手部形态
2. 从指尖扩展到全手（掌心、指节等）接触建模
3. 探索触觉与视觉/本体感受的更深度联合预训练（当前仅做跨模态检索探针）
4. 仿真中触觉信号生成质量改进以缩小 sim-to-real 力估计 gap

- [[Joint Embedding Predictive Architecture|I-JEPA]]: LingBot-Touch 的自监督目标 Tactile-JEPA 直接基于此

### 对比
- [[FTP-1]]: 最接近的异构传感器触觉基础模型，LingBot-Touch 在所有探针任务和操作任务上全面超越
- [[AnyTouch]]: 多模态触觉对齐先驱，主要面向光学触觉

### 方法相关
- [[Tactile-JEPA]]: 本文核心预训练目标（新概念）

## 速查卡片

> [!summary] LingBot-Touch
> - **核心**: 首个跨压阻/磁性/视触觉三类传感器的触觉基础模型，5,000 小时预训练数据
> - **方法**: 规范指尖球面空间 + 模态专用 Tokenizer + 共享 Haptic Transformer + Tactile-JEPA（潜在空间掩码预测）
> - **结果**: 冻结编码器将 π0.5/LingBot-VLA 在 26 真实任务上提升 ~22–25 pp；仿真 RL 均值 69.0% vs 无触觉 21.4%；无需为新传感器（XHand1）重新训练即超越 FTP-1
> - **代码**: [github.com/robbyant/lingbot-touch](https://github.com/robbyant/lingbot-touch)
